# 独立清水标定（v2.5.0）—— K2 长按 ≥3 s

- 日期：2026-11-18
- 固件：`SENSOR-NODE v2.5.0-CAL`
- 构建：`text 79860 / data 480 / bss 11376`，0 error / 0 warning（`_tmp/build_v250.log`）
- 前置：`Docs/基线质量修订_v2.4.3_20261118.md`

---

## 1. 触发

- **K2 长按 ≥3 s**（原 1.5 s 已取消）；
- 触发后立即：
  1. 中止当前自检；
  2. **作废旧基线**（避免旧 EC0 继续参与判别）；
  3. 进入独立标定流程。

短按仍是切 OLED 页；长按触发后松手不再切页。

> 串口会打印：
> `# CAL: clean-water calibration requested (flush 2~3x, keep electrode immersed)`

---

## 2. 现场流程

```
1. 排空腔体
2. 用清水冲洗 2~3 倍腔体体积（冲掉残皂/残水）
3. 注清水，淹过电极，进水不要翻腾/带气泡
4. 长按 K2 ≥3 s
5. 等 OLED 显示"校准 + Auto calib n/40"
6. 看到 # BASELINE OK 后松手/等待完成
```

标定期间阀保持排空（无合法基线），不会回收。

---

## 3. 状态机

```
KEY_CAL
  ↓
SETTLE（等浸没 + 稳定 300 ms + AO 清洁）
  ├─ 没水 → WAIT（OLED "Auto wait water"）
  ├─ 水脏/泡沫多 → DONE(base_turbid)，OLED "Auto fail"
  └─ 满足 → WET（采 2 s，OLED "校准 n/40"）
              ↓
         采后校验：|EC-EC0|≤5 mV、gate.baseline_ok
              ├─ 通过 → DONE(base_ok)，基线生效
              └─ 失败 → RETRY（最多 3 次）→ DONE(base_fail)
```

关键校验沿用 v2.4.3：

- 稳定触发：800 ms 后连续稳定 300 ms，最多等 3 s；
- 采后 5 mV 漂移 → `BASE_DRIFT`，作废重采；
- AO0-AO_DRY ≥250 mV → 否则 `BASE_TURBID`；
- 量程/CV/干湿差值仍由 pipeline/gate 校验。

---

## 4. OLED

| 阶段 | 显示 |
|---|---|
| 等水 | 待机 / `Auto wait water` |
| 检测到水、稳定中 | 待机 / `Auto water ok` |
| 采基线 | **校准** / `Auto calib n/40` / `Keep still` |
| 成功 | 恢复正常水质页 |
| 失败 | 待机 / `Auto fail` / `Send W in clean water` |

## 6. 验收

1. 启动行 `SENSOR-NODE v2.5.0-CAL`；
2. 空腔上电，正常进 `Auto wait water`；
3. 注清水，长按 K2 3 s：
   - 串口出现 `# CAL: clean-water calibration requested`；
   - OLED 出现“校准 + Auto calib n/40”；
   - 约 3~5 s 后 `# BASELINE OK ec0=…`；
4. `ec0` 应接近当前清水实际 EC（本机约 324，不是 294）；
5. 若 `BASE_DRIFT`：水还在动，自动重采；
6. 若 `BASE_TURBID`：水不够清亮/泡沫多，换清水再长按；
7. 标定成功后放清水，应稳定 `CLEAR`，不再 SOAP↔CLEAR 横跳。

---

## 7. 当前限制（重要）

**基线仍只存在 RAM，掉电/重启会丢失。**

- 本次完成的是“独立标定阶段 + 3 s 触发 + 稳定/清洁/漂移校验”；
- Flash 持久化需要 FSP `r_flash_lp` 驱动/配置，而当前工程只生成了 ADC/IIC/SCI/IOPORT 模块，**尚未包含 Flash 模块**；
- 因此每次上电仍要重新标定或走开机自检；
- 下一步接入数据 Flash 后，才能做到“标定一次、掉电保留”。

不要在没有 Flash 的情况下承诺“永久保存”；当前是 RAM 基线。

---

## 8. 与手动 W 的区别

| 方式 | 行为 |
|---|---|
| 长按 K2 3 s | 独立标定：先作废旧基线，走完整稳定/清洁/漂移校验；有进度显示 |
| 命令 `W` / `B` | 直接开始 2 s 湿态采集；仍走 `app_baseline_validate` 的清洁度/量程校验，但没有“先等稳定”的 SETTLE 阶段 |
| 命令 `Z` | 清基线，不自动重采 |

标定优先用长按 3 s；`W` 保留为串口兜底。
