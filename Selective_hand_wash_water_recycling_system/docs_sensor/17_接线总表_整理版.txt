0. 一句话总览
--------------------------------------------------------------------------------
   ① 传感器三路：
        TDS 模块（3.3V 供电）AOUT → U1-6 = P014 / ADC0_AN12（直连，0~2.3V）
        浊度模块（5V 供电）A(AO) → [1k 串联 + 2k 对地分压 + 0.1µF] → U1-5 = P013 / ADC0_AN11
        DS18B20（3.3V 供电）DQ → U1-17 = P500（4.7k 上拉到 3.3V）
   ② 板载资源（不用接线）：OLED（I2C0：P407=SDA / P408=SCL）、串口 CH340E（P109/P110）、
        LED1（P111）、按键 K2（P000）。
   ③ 执行器：
        继电器 IN → U2-8 = P104（推荐 A 型模块：拆 JD-VCC，VCC→3.3V、JD-VCC→VIN）
        继电器 COM–NO 串在独立 12V 回路：12V+ → 2A 保险丝 → 船型开关 → COM；
        NO → 阀线圈(+)；阀线圈(−) → 12V(−)；线圈并 1N4007（阴极/色环 → 线圈 +）。
   ④ 地：所有 GND（板 8 个 GND 孔、模块 GND、5V(−)、12V(−)、阀/继电器大电流地）
        只在"接线端子排"单点汇合（星形共地）；阀/继电器电流地不经过开发板。
   ⑤ 红线：P104/UA1-5/U1-6 等 3.3V 引脚不耐 5V；浊度 DO 悬空；阀必须独立 12V；
        先做极性判定再接 12V；开发板禁止割线/焊板。

2. 供电与接地（先看这一节，再接线）
--------------------------------------------------------------------------------
2.1 三路电源
    A. 板/传感器 5V：5V/2A 适配器 → Type-C → 开发板；板上 LDO 出 3.3V（U1-12）；
       VIN（U2-19/20）≈4.5~4.7V 给"5V 外设"（浊度、继电器线圈）。
       （联调时用电脑 USB 也可以；但电脑 USB 与外部 5V 不要同时给板供电。）
    B. 阀 12V：12V/3A 适配器（DC5.5×2.1，内正外负）→ 2A 慢熔保险丝 → 船型开关
       → 继电器 COM；NO → 阀线圈(+)；阀线圈(−) → 12V(−)。**只给阀，与板无电源并联。**
    C. （可选）独立 5V/≥300mA 给继电器模块：仅当 VIN 实测线圈端 <4.2V 或吸合不可靠时用；
       必须与板共地。

2.2 星形单点接地
    12V(−)、5V(−)、板 GND（8 个排针地任选/全接）、浊度 GND、继电器模块 GND、
    DS18B20 GND、TDS GND、阀/继电器大电流地 —— 全部只接到"接线端子排"的同一个 GND 点；
    阀/继电器的大电流地单独走一根线到端子排，**绝不经过开发板地线**（大电流会抬地电位、
    干扰 ADC/造成复位）。

2.3 电流预算（供判断供电是否够；以实测为准）
    3.3V 支路：TDS ≈3~6mA + DS18B20 ≈1mA + 板载 OLED/CH340E/MCU（板上已占）
    5V（VIN）支路：浊度 ≈20~40mA；继电器（A 型拆 JD-VCC）线圈 ≈62~68mA + 光耦输入 2~5mA
                   → 建议按 80~100mA/模块预留（旧文档"45~55mA"偏小）
    12V 支路：阀线圈 0.4~1.1A（按阀铭牌；4.8~13.2W），2A 保险丝。


3. 传感器接线（三路，逐根）
--------------------------------------------------------------------------------
3.1 TDS（电导率，主判据；模块 3 针）
    TDS VCC   → U1-12（3V3，第 9 孔）           ← 必须 3.3V，严禁接 5V
    TDS GND   → U1-16（或 GND 地排）            ← 必须共地
    TDS AOUT  → U1-6 = P014 / ADC0_AN12        ← 直连安全（标称 0~2.3V）
    TDS 探针  → 模块 2P XH-2.54 座，插紧；黑色连接器不可入水
    上电前量 AOUT 对 GND ≤2.4V；探头必须浸在水样中采基线（空气里是开路伪值 ≈1.6V）。

3.2 浊度（辅判据；模块 4 针 G/A/D/V，必须用 AO 模拟输出）
    模块 V（VCC）→ U2-19 或 U2-20（VIN≈4.5~4.7V） ← 只能 5V，禁止 3.3V
    模块 G（GND）→ U2-18 / GND 地排              ← 必须共地
    模块 A（AO）→ R1=1kΩ 串联 → 节点 → U1-5 = P013 / ADC0_AN11
                  节点 → R2=2kΩ → GND
                  节点 → 0.1µF → GND（与 R2 并联，滤高频）
    模块 D（DO）→ 悬空不接！                     ← 5V 比较器输出，接 3.3V 引脚会超压
    模块灵敏度电位器：只调 DO 阈值，本方案不用，保持不动。
    分压比 = R2/(R1+R2) = 2/3：AO 最高 ≈4.5~4.7V → 节点 ≈3.0~3.13V（<3.3V，安全；
    也低于固件贴轨门限）；分压后源阻抗 R1∥R2 = 667Ω ≤1kΩ（满足本板 ADC 要求）。
    上板顺序：只给模块 5V → 万用表量 A 端最大电压与方向 → 接分压 → 量节点 ≤3.2V →
              再进 U1-5；AO 方向可能因批次反相，先用清水/浑水对照，必要时改
              ntu_clear_high=false（见 08 文档 T4）。
    探头：4 线原配（1 电源− / 2 传感器− / 3 传感器out / 4 传感器+），按模块座丝印对插；
          不能配 TS-300B 3 线一体化探头。

3.3 DS18B20（水温，温度补偿必需）
    DS18B20 VDD → U1-12（3V3）                 ← 严禁 5V（DQ 会被上拉打坏 P500）
    DS18B20 GND → U1-16 / GND 地排
    DS18B20 DQ  → U1-17 = P500；同时 DQ 与 3.3V 之间 4.7kΩ 上拉（模块座自带则免）
    探头金属壳浸入水中 20~30mm、靠近 TDS 探头；全 0/全 FF 会被判无效并自动停用
    （串口可发 T24.5 手输水温兜底）。


4. 板载资源（不需要任何外部接线，也不要把这些脚挪作他用）
--------------------------------------------------------------------------------
  板载 0.96" OLED ：I2C0，P407=SDA（U1-7）/ P408=SCL（U2-7）；模块自带 4.7k 上拉；
                   固件 v1.3.0 起三页：P1 水质 / P2 执行器 / P3 详情；K2 短按切页。
  板载 CH340E 串口：UART9，P109=TXD（U2-12）/ P110=RXD（U2-13）；插 USB 即用，115200 8N1。
  用户 LED1       ：P111（U2-2），高电平点亮；亮=回收、闪=排空（判别提示）。
  用户按键 K2     ：P000（U1-14），板上 4.7k 上拉，按下=低；
                    v1.3.0 起：短按切 OLED 页；长按 ≥1.5s 重采基线；MARK 改由串口 M。
  （以上脚位禁止再配成其它外设/GPIO 输出。）


5. 执行器：SRD-05VDC-SL-C 单路继电器 + 12V 二位三通单线圈阀
--------------------------------------------------------------------------------
5.1 先判模块类型与触发极性（接线前；此时 12V 与阀都不接）
    A 型：光耦隔离型，4~6 针，带 JD-VCC 跳线（部分带 H/L 触发选择跳线）——推荐；
    B 型：三针 VCC/GND/IN，无 JD-VCC（可能带光耦，也可能只是 PNP 三极管直驱）。
    3.3V 驱动结论（要点）：
      - A 型拆 JD-VCC、VCC 接 3.3V 后，高/低触发都能可靠关断，P104 只看到 3.3V 域；
      - B 型三针：优先"光耦 + 高电平触发"款，必须实测 10/10；
        无光耦 PNP 低电平触发款 **禁止直连 P104**（IN 会被抬到约 4.3V，超 3.3V IO 耐压）；
      - 到手 30 秒判定：IN 悬空时量 IN-GND 电压（≈VCC→低触发嫌疑/内部上拉；≈0V→高触发嫌疑），
        再用导线把 IN 碰 VCC / GND 看继电器动作，最后用开发板 V1/V0 各试 10 次 + 复位 10 次。
    判定通过前不要接 12V；判错时上电瞬间阀可能误吸合（违反 fail-safe）。

5.2 控制侧接线（按模块类型二选一）
    A 型（推荐：拆掉 JD-VCC 跳线，双电源）：
      模块 VCC    → U1-12（3V3）                 ← 只给光耦输入侧（2~5mA）
      模块 JD-VCC → U2-19/20（VIN≈4.5~4.7V）     ← 给继电器线圈（62~68mA）
      模块 GND    → U2-18 / GND 地排             ← 必须共地（拆跳线后仍共地）
      模块 IN     → U2-8 = P104（3.3V 逻辑）
      模块 VCC–GND 就近并 100µF 电解 + 0.1µF 瓷片（防吸合瞬间 VIN 被拉跌）

    B 型（三针，只允许光耦输入型）：
      模块 VCC → U2-19/20（VIN）                 ← 线圈电源（≈4.5~4.7V）
      模块 GND → U2-18 / GND 地排
      模块 IN  → U2-8 = P104

    P104 下拉/上拉（两种都要，二选一按触发极性）：
      高电平触发（默认 high 版固件）：P104 ── 10kΩ ── GND
      低电平触发（low 版固件）：       P104 ── 10kΩ ── 3.3V（U1-12）
      作用：复位/配置完成前引脚高阻，用电阻强制"继电器不动作"；软件不能替代。

5.3 功率侧：独立 12V 回路（先不接阀，只接继电器空载验证）
    12V 适配器（内正外负，空载 11.4~12.6V）
      └─(+)─ 2A 慢熔保险丝 ─ 船型开关 ─ 继电器 COM
                                          继电器 NO ── 阀线圈(+)
                                          阀线圈(−) ── 12V(−)
      1N4007：阳极→线圈(−)，阴极（色环）→线圈(+)，紧贴阀线圈端子安装（引线 ≤50mm）
      继电器 NC：悬空不接（接 NC 会变成"断电=通电"，破坏 fail-safe）
    说明：
      - 用 COM–NO：继电器释放（断电/复位/程序未初始化）→ 线圈失电 → 弹簧复位排空口；
        继电器吸合 → 回收口（断电=排空，fail-safe）；
      - 1N4007 反接 = 12V 短路（烧保险丝/电源），接线前用二极管档确认方向；
      - 阀必须选"单线圈弹簧复位、直动式、通径≥4mm、断电=排空口通"的型号；
        双线圈两位自锁阀单继电器驱动不了（需 2 路继电器），且不满足断电 fail-safe。
      - 阀电流 0.4~1.1A；12V 必须独立供电，严禁从开发板 5V/3V3 取电。
      - 阀/继电器大电流地单独一根到端子排，不经过开发板地线。

5.4 空载验证（不接 12V 时做；接 12V 前必须过）
      ① 只接控制侧，上电/复位 10 次：继电器不应吸合；
      ② 串口 V1（强制回收）/V0（强制释放）各 10 次：10/10 动作；
      ③ 万用表量 COM–NO：吸合导通、释放断开；
      ④ 以上通过后，按 5.3 接 12V（先只接继电器、不接阀）：V1/V0 听 10 次咔哒；
      ⑤ 最后接阀 + 1N4007，先不通水空载听 10 次，再按 15 文档做阀方向/断电 fail-safe 验收。


6. 无源件/耗材清单（接线时对照）
--------------------------------------------------------------------------------

  2A 慢熔保险丝+座     12V 阀回路                               1 套

  接线端子排          星形单点地；阀/继电器大电流地汇合         1 只

  5V/2A 适配器/Type-C  给板与传感器（联调可用电脑 USB）         1 只
  杜邦线/端子线       建议：P104/IN 红、VCC 橙、GND 黑、3V3 黄、

  防水盒/热缩管/扎带  湿电分离、线束固定                        若干
  水路件（另见 12/硬件方案）：Y 型滤网、8mm 软管、卡箍、回收/废液桶、溢流旁通等。


7. 施工顺序（断电接线；每一步做完量一遍再下一步）
--------------------------------------------------------------------------------
    ① 断电：拔掉 5V/12V 两个适配器，船型开关断开，阀不接。
    ② 只接 USB 烧好 v1.3.0 固件（按继电器极性选 high/low），核对 boot 行/on_level。
    ③ 板载资源确认：OLED 亮、串口有输出、LED1 快闪 3 下（不需要接线）。
    ④ 接 TDS：VCC→U1-12、GND→U1-16、AOUT→U1-6；量 AOUT≤2.4V。
    ⑤ 接浊度分压网络：R1/R2/0.1µF 焊在洞洞板或端子上，节点→U1-5；
       V→U2-19/20、G→GND、D 悬空；量节点≤3.2V 后才插 U1-5。
    ⑥ 接 DS18B20：VDD→U1-12、GND→U1-16、DQ→U1-17 + 4.7k 上拉。
    ⑦ 接继电器控制侧：IN→U2-8、GND→U2-18、A 型拆 JD-VCC 后 VCC→U1-12、
       JD-VCC→U2-19/20；P104 10k 方向按触发极性；并 100µF+0.1µF。
    ⑧ 极性/动作验证（不接 12V）：上电/复位 10 次不吸合；V1/V0 各 10 次 10/10；
       串口 # VALVE 与 P 状态核对 count/relay。
    ⑨ 接 12V 功率侧（先不接阀）：12V+→保险丝→船型开关→COM；NO 空着；
       船型开关断开再插 12V 适配器，V1/V0 空载听触点 10 次。
    ⑩ 接阀 + 1N4007 + 星形地：先空载动作 10 次，再通水做 15 文档 T5（阀方向）/
       T6（断电 fail-safe）验收；最后接水试漏、闭环演示。


8. 上电前检查（逐项打勾，缺一不上电）
--------------------------------------------------------------------------------
  ☐ 1. 断电接线完成，端子/排针无松动，无铜丝外露/短路
  ☐ 2. 3V3（U1-12）对 GND：3.25~3.35V
  ☐ 3. VIN（U2-19/20）对 GND：4.5~4.7V
  ☐ 4. TDS AOUT 对 GND ≤2.4V；TDS VCC 是 3.3V（不是 5V）
  ☐ 5. 浊度 AO 最大电压已量；分压节点对 GND ≤3.2V；D（DO）确认悬空
  ☐ 6. DS18B20 VDD=3.3V；DQ 上拉 4.7k 到 3.3V
  ☐ 7. 继电器 IN→P104；P104 与 GND/3.3V 的 10k 方向与固件极性一致
  ☐ 8. 1N4007 方向：阴极（色环）→ 线圈 +（二极管档反向不通）
  ☐ 9. 12V 回路：保险丝已装、船型开关在断开位、COM=12V+、NO→线圈+、NC 悬空
  ☐ 10. 星形地：四路 GND 只在端子排一点汇合；阀地不经过开发板；防水盒/湿电分离到位
  上电顺序：先开 5V（板+传感器）→ 自检/量电压 → 再开 12V（继电器/阀）；
            断电顺序相反。首次上电先不接阀、先空载听继电器。


9. 常见接错点速查
--------------------------------------------------------------------------------
  现象/错误                       原因                                处理
  -----------------------------  ----------------------------------  ----------------------------
  浊度读数固定 0 或满量程          AO/D 接反；分压没接；节点超 3.2V    只接 G/A/V，D 悬空；量节点电压
  ADC 引脚可能损坏                 AO 直连（未分压，最高 4.7V）        必须 1k+2k 分压后再进 U1-5
  上电/复位继电器动一下            10k 方向错 / 模块极性与固件不符     按 5.1/5.2 重判；改用对应 hex
  继电器完全不吸合                 模块不是 3.3V 触发/没共地/IN 线断   量 IN/VCC/GND；V1 时看串口 pin fault
  继电器吸合但阀不动               12V 没到/保险丝断/COM-NO 接反/       量 12V、保险丝、触点；查 1N4007 方向
                                   1N4007 反接短路
  阀动作但水流方向反               阀常开/常闭口接反                   断电吹气测试；换接管口或换阀
  MCU 复位/OLED 花屏（阀动作时）    无续流二极管/共地不良/12V 从板取     加 1N4007；星形地；12V 独立供电

--------------------------------------------------------------------------------
10.1 烧哪个（按继电器模块触发极性）

    low  版：Debug\Selective_hand_wash_water_recycling_system_v1.3.0_low.hex
              161880 B，SHA-256 EBE26BFCEE42AE05B52DC1E754B89F518428B755F359512C703C0AE0505CA025
              boot "… build Nov 13 2026 19:24:29"
    默认 Debug\Selective_hand_wash_water_recycling_system.hex 与 high 版逐字节相同。
    （旧版 v1.2.0 hex 仍在 Debug\，boot 行为 v1.2.0-VALVE，不要烧混。）

10.2 上电自检（串口 115200 8N1）
    "# [BOOT] SENSOR-NODE v1.3.0-OLED …"
    "# actuator: valve ready (P104 locked at relay-OFF/drain, on_level=HIGH|LOW)"
    "# display: … 3 pages: P1 water / P2 exec / P3 info"
    发 P 看基线/阈值/执行器状态；发 V1/V0/VA 手动驱动阀；发 M 打 MARK；发 B 重采基线。

10.3 OLED（v1.3.0）与按键
    K2 短按：P1 水质（清水/污水/待机/冲洗/故障）→ P2 执行器（回收/排空/手动 + RLY/CNT/ON）
             → P3 详情（事件/STATE/LEVEL/VALVE/RLY/MODE/CNT/dEC/g/dNTU/T/EC0/σ/d1/d2）→ 回 P1
    K2 长按 ≥1.5s：重采基线（原功能保留）
    OLED 只是现场指示，不是安全路径；显示失效只打印一次 WARN，判别/CSV/阀照常。


11. 与旧文档的差异（以本表为准）
--------------------------------------------------------------------------------
  ① 继电器模块电流：旧 12 文档 §3.2 写 45~55mA 偏小；按 5V/69.4Ω 线圈约 72mA，
     本工程按 65~80mA（建议 80~100mA 预留）。
  ② 继电器推荐接法：优先 A 型（拆 JD-VCC：VCC=3.3V、JD-VCC=VIN）；B 型三针仅限光耦输入，
     无光耦 PNP 低触发禁止直连 P104。
  ③ 浊度模块：4 针 G/A/D/V，只用 A(AO) 模拟输出，D(DO) 悬空；旧 TS-300B 3 针文档为历史版本。
  ④ K2：v1.3.0 起短按切 OLED 页（不再打 MARK），长按仍重采基线；MARK 用串口 M。
  ⑤ 旧文档中的"阀预留/APP_USE_VALVE=0/继电器不接"等描述是 v1.1 历史口径，已由 15 文档取代。
