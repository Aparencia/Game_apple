【0】这个文件解决什么问题
   板载 0.96" OLED 是"现场指示器"：用 32x32 大字显示 清水/污水/待机/冲洗/故障，
   再配两行小字显示状态串与关键数值（EC0、σ、水温、ΔEC、g、ΔNTU%）。
   它解决两个现场问题：
     ① 答辩/演示时不用开电脑，一眼看到"现在判成什么"；
     ② 脱机演示（5V 适配器供电、没有串口）时仍然能看状态。
   它不是安全执行路径，也不是数据来源：
     - OLED 坏了/掉线，判别、CSV、LED/阀照常工作（display_task 只返回 false，不控阀）；
     - 数据留痕与答辩引用以 115200 串口 CSV 为准（见 07 文档）；
     - 屏幕显示口径与 CSV/报告一致：只写"清水/污水/待机/冲洗/故障"+相对量，
       不写 NTU、不写绝对 ppm、不声称"识别出污染物"（红线见 00 §8 / 08 §15）。

【1】硬件事实与接线（板载器件，不需要任何外部接线）
   ┌────────────┬──────────────────────────────────────────────────────┐
   │ 器件        │ 板载 0.96" OLED（SSD1306 兼容，128x64 单色）            │
   │ 接口        │ I2C0（硬件 IIC0）                                       │
   │ 引脚        │ P407 = IIC0_SDA、P408 = IIC0_SCL（板载已连，不占用排针） │
   │ 从机地址    │ 0x3C（7-bit）                                          │
   │ 上拉        │ OLED 模块自带 4.7kΩ（板载 I2C 没有额外上拉，也不需要）   │
   │ 供电        │ 板载 3.3V（与 MCU 同开同关）                            │
   └────────────┴──────────────────────────────────────────────────────┘
   ⚠ 不要用杜邦线把 OLED 再接到别处：它已经焊在板上；禁止拆焊/遮挡丝印（板子是借的，
     赛后收回，见 00 文档红线）。
   ⚠ P407/P408 只给 OLED 用：不要再把这两脚分配给其它外设，也不要在 Pins 里改成 GPIO。
   ⚠ 若上电 OLED 不亮，先看 §7 排查表，不要拆板子——最常见原因是 RASC 里没加 I2C 栈。

【2】页面规格（128x64，4 层，坐标全部 8 像素对齐）
   实际显示（以真实字库渲染核对过；字体为 6x8 / 8x16 ASCII + 32x32 汉字）：

     ┌──────────────────────────────────────────────────────────────┐
     │ y=0   EC0=1490 s1.5 T25.3                                    │  6x8，≤21 字符
     │ y=8          [ 清 水 ]  或  [ 污 水 ](反显) 或 [待机] ...     │  32x32 x2，x=32/64
     │ y=40  CLEAR  RECOVER                                         │  8x16，≤16 字符
     │ y=56  dEC+12mV g1.008 N+5                                    │  6x8，≤21 字符
     └──────────────────────────────────────────────────────────────┘

   ① 页头 y=0（6x8）：
      有基线时 "EC0=<4位mV> s<σ一位小数> T<温度一位小数>"，例 "EC0=1490 s1.5 T25.3"；
      无基线时用占位符 "EC0=---- s--- T25.3"（温度仍然显示）。
   ② 大字 y=8（32x32 两个，x=32 与 x=64，共占 64x32 居中）：
      ┌──────┬──────────────┬──────────┬──────────┬────────────────────┐
      │ 判别  │ 大字          │ 显示方式  │ 第二行    │ 说明                │
      ├──────┼──────────────┼──────────┼──────────┼────────────────────┤
      │ CLEAR │ 清水          │ 正显（黑底白字） │ "CLEAR  RECOVER" │ 只有 L0 才出现      │
      │ UNCERTAIN │ 污水      │ 反显（白底黑字） │ "L1 UNCERTAIN"  │ L1 拿不准=排空      │
      │ SOAP  │ 污水          │ 反显（白底黑字） │ "L2 SOAP  DRAIN"│ L2 含皂液特征=排空  │
      │ WAIT  │ 待机          │ 正显      │ "WAIT   EV:OFF"│ 无事件；不是水质结论 │
      │ FLUSH │ 冲洗          │ 正显      │ "FLUSH  DRAIN" │ 事件开头强制排空段   │
      │ 无基线│ 故障          │ 正显      │ "L1 NO_BASELINE"│ 按 B 重采（探头浸水）│
      │ 传感器故障 │ 故障     │ 正显      │ "L1 SENSOR_FAULT"│ ADC/贴轨/数据不可信 │
      └──────┴──────────────┴──────────┴──────────┴────────────────────┘
      注：L1 与 L2 的大字都是"污水"（先做到"清水/污水"两分），区别在第二行状态串；
          反显只用于"污水"——现场一眼能看出"这水该排"。
   ③ 第二行 y=40（8x16，≤16 字符）：
      WAIT "WAIT   EV:OFF" / FLUSH "FLUSH  DRAIN" / CLEAR "CLEAR  RECOVER" /
      L1 "L1 UNCERTAIN" / L2 "L2 SOAP  DRAIN" / 无基线 "L1 NO_BASELINE" /
      故障 "L1 SENSOR_FAULT"；基线采集中 "BASELINE  8/20"（8 为已采点数，总数 20）。
   ④ 第三行 y=56（6x8，≤21 字符）：
      正常 "dEC%+dmV g%d.%03d N%+d"（例 "dEC+12mV g1.008 N+5"；N=方向归一化 ΔNTU%，限幅 ±99）；
      基线采集中 "hold probe in water"；
      无基线 "send B in water"（提示按 B 重采）；
      传感器故障 "note=ADC_TIMEOUT" / "note=TDS_RAIL" ...（取流水线 note，≤13 字符）。
   ⑤ 开机页（display_init 内画，保持约 800 ms 后切状态页）：
      "RA4M2 WATER JUDGE" / "OLED OK"（8x16）/ "SSD1306 128x64" /
      "I2C0 0x3C 400kHz" / "SENSOR-NODE v1.1"
   ⚠ 字库只有 9 个 32x32 汉字（清 水 污 待 机 冲 洗 故 障），不能显示任意中文；
     其余信息一律用 ASCII 缩写，不要试图在代码里写中文串（会显示成空格/乱码）。
   ⚠ 文本函数要求 y 是 8 的倍数（页对齐）：不要写 y=34 这种坐标，否则字符跨页错位。

【3】刷新策略、时间预算与失败处理
   - 差异刷新：只有内容变化的区域重画（状态/大字/状态串变化立即画；数值最快 200 ms 一次）；
   - 1 s 心跳：即使内容没变也整屏重画一次（掉帧/上电残影自恢复，也是"屏还活着"的证据）；
   - 只刷脏页：SSD1306 按页（8 页 ×128 字节）写入，一页 ≈3 ms@400 kHz，整屏 ≈25 ms；
   - 时间预算：display_init 约 150 ms（含 oled_init 的 100 ms 上电延时 + 清屏）；
     display_task 平时 <6 ms（1 页），最坏 25 ms（心跳整屏）；在 50 ms tick 内可接受；
   - 失败处理：任何 I2C 失败只返回 false，不打印/不死机/不 assert；连续 3 帧失败后
     display_task 返回 false → app_main 只打印一次 "# WARN: OLED lost ..."，之后继续用串口；
     之后刷新直接返回（不再占主循环），判别/CSV/LED/阀完全不受影响。
   - 为什么按页刷/为什么节流：50 ms 主循环里整屏 25 ms 的阻塞会挤占 ADC 采样；现场最常见的
     更新只是第三行数值，只脏 1 页，所以必须"变化才刷 + 数值节流"。

【4】RASC 配置（新增 I2C Master，只需做一次）
   4.1 添加栈：Stacks 页 → New Stack → Connectivity → I2C Master (r_iic_master)；
       不要选成 "I2C Master (r_sci_i2c)"，也不要用 "I2C Slave"。
   4.2 属性（Generate 前逐项核对）：
       ┌────────────────────────┬──────────────────────────────┐
       │ Name                   │ g_i2c_master0                │
       │ Channel                │ 0                            │
       │ Rate                   │ Fast-mode，400000 Hz（400 kHz）│
       │ Rise/Fall Time (ns)    │ 120 / 120                    │
       │ Duty Cycle             │ 50                           │
       │ Slave Address          │ 0x3C                         │
       │ Address Mode           │ 7-bit                        │
       │ Timeout Mode           │ Short                        │
       │ Timeout SCL Low        │ Enabled                      │
       │ Callback               │ i2c_master_callback          │
       │ Interrupt Priority     │ Priority 12                  │
       └────────────────────────┴──────────────────────────────┘
   4.3 引脚：Pins 页 → Connectivity: IIC0 → 勾选 IIC0，SDA0 = P407、SCL0 = P408
       （多数情况下加栈后会自动落位；若仍是 "None"，手动在下拉里选 P407/P408）。
   4.4 生成：点右上角 "Generate Project Content"（绿色箭头）。
   4.5 生成后校验（三处必须都对，否则不是 RASC 没生效，而是没点到生成）：
       - ra_gen/hal_data.h：出现 extern const i2c_master_instance_t g_i2c_master0;
         以及 g_i2c_master0_ctrl / g_i2c_master0_cfg 声明；
       - ra_gen/hal_data.c：出现 i2c_master_on_iic 与 g_i2c_master0 实例；
       - ra_gen/pin_data.c：P407/P408 出现 IOPORT_PERIPHERAL_IIC。
   ⚠ Callback 名必须正好是 i2c_master_callback（由 oled.c 提供）；写错会链接时报
     undefined reference to 'xxx_callback'，或运行时回调不进、显示一直不刷新。
   ⚠ 若 RASC 版本界面文字略有差异（6.x 各小版本），按"模块类别=I2C Master(r_iic_master)、
     Channel=0、Slave=0x3C、Callback=i2c_master_callback"这四项核对即可。

【6】验收要点（对应 08 文档 T10；记录表见 08 13.4 的 T10 表与 §18 通用模板）
   □ 上电：OLED 亮、开机页 5 行清晰 → 约 0.8 s 后进入待机页/基线进度页；
   □ 基线：显示 "BASELINE  n/20" 且 n 递增，采满后转待机页（EC0 有值）；
   □ 按 R：大字"冲洗"、第二行 "FLUSH  DRAIN" → 2 s 后清水 → "清水 / CLEAR  RECOVER"；
   □ 探头入 1.0 mL/L 皂液水：大字变"污水"（反显白底黑字），状态串 "L2 SOAP  DRAIN"；
   □ 探头回自来水：恢复"清水"；按 E：回"待机"；
   □ 设备注（板载焊死，不拆线）：把 OLED_I2C_ADDR 临时改成 0x3D 重烧 → 串口出现
      "# WARN: OLED not usable ..." 与一次 "# WARN: OLED lost ..."，CSV/判别/阀不受影响；
           改回 0x3C 重新烧录后恢复（原理与步骤见 08 文档 13.4）；
   □ 目检：5 个汉字（清水/污水/待机/冲洗/故障）清晰无缺笔画、无花屏、无撕裂。

【8】红线与已知限制（报告口径，逐条遵守）
   ① 屏幕只显示"清水/污水/待机/冲洗/故障"和相对量；禁止在 OLED 上写 NTU、禁止写
      "TDS=xxx ppm 达标"、禁止写"识别出皂液/污染物种类"；
   ② OLED 是现场指示器，不是数据来源：答辩数据一律引用串口 CSV（07 文档格式）；
   ③ 字库只有 9 个 32x32 汉字，不能显示任意中文；第二/三行用 ASCII 缩写；
   ④ 刷新率：状态变化立即、数值最慢 5 Hz；I2C0 只挂这一块屏（不要再挂第二个 I2C 从机
      到 P407/P408）；
   ⑤ 无事件时显示"待机"——这不是水质结论（阀在安全侧排空）；水质结论只在事件内出现；
   ⑥ OLED 失效不影响判别/CSV/LED/阀（安全侧不依赖显示）；WARN 只打印一次，避免刷屏；
    ⑦ 第三行是固定宽度 6x8 数值串：极端值（例如 ΔEC 超 ±999 mV 的非常规读数）会被
       6x8 写函数在屏边安全截断一两个字符——不越界、不影响判别；真实工况远小于该量级。

/* ===== FILE: src/oled.h ===== */
/*
 * oled.h —— 板载 0.96" OLED（SSD1306 兼容，128x64，I2C0）驱动接口
 * ---------------------------------------------------------------------------
 * 硬件事实（板卡原理图 V1.2.1 / 硬件方案 §1.2）：
 *   - 板载 0.96" OLED 直接连在 I2C0：P407 = IIC0_SDA、P408 = IIC0_SCL；
 *     模块自带 4.7kΩ 上拉，地址 0x3C（7-bit），无需任何外部接线；
 *   - 3.3V 供电，与 MCU 同开同关；禁止拆焊（开发板赛后收回）。
 *
 * 本驱动的定位：
 *   - 只做"现场指示器"：把判别结果画成大字（清水/污水/待机/冲洗/故障）+ 两行数值；
 *   - 不是安全执行路径：I2C 失败、屏幕丢失都不能影响判别/串口 CSV/LED/阀；
 *   - 不打印、不依赖浮点 printf、不用动态内存；显存 1 KB 静态数组，按页刷屏。
 *
 * 刷新模型（与 oled.c 实现一致）：
 *   - 1 KB 显存按 SSD1306 页式组织：gram[page][x]，bit0 = 页内最上一行；
 *   - 所有绘图函数只改显存并置脏页位；oled_flush() 只把脏页写到屏上；
 *   - 文本/汉字必须 8 像素对齐（y % 8 == 0），否则字符会跨页错位；
 *   - 一页 = 2 次 I2C 传输（3 条地址命令 + 1 控制字节 + 128 字节数据），
 *     400 kHz 下约 3 ms；全屏 8 页约 25 ms，所以上层必须节流（见 display.c）。
 *
 * 回调约定（RASC 里配错名字会链接失败，见 00 文档 §4.3）：
 *   - I2C Master 的 Callback 必须填 i2c_master_callback；
 *   - 该函数由本文件提供：只记录 TX_COMPLETE/ABORTED 事件，不打印、不做业务。
 */
#ifndef OLED_H
#define OLED_H

#include <stdbool.h>
#include <stdint.h>

#ifdef __cplusplus
extern "C" {
#endif

#define OLED_WIDTH          128U   /* 像素宽 */
#define OLED_HEIGHT         64U    /* 像素高（8 页） */
#define OLED_PAGE_COUNT     8U     /* 64 / 8 */
#define OLED_I2C_ADDR       0x3CU  /* SSD1306 7-bit 地址 */
#define OLED_MAX_FAIL       3U     /* 连续失败帧数达到后判"屏幕丢失" */

/* 32x32 汉字索引：与 oledfont.h 的 oled_hz32[] 顺序一一对应（改顺序必须两边一起改）。
 * 字库只有这 9 个字（现场指示够用；不要指望显示任意中文——字库只有 9 个字形）。 */
typedef enum e_oled_hz32_id
{
    OLED_HZ32_QING = 0,   /* 清 */
    OLED_HZ32_SHUI,       /* 水 */
    OLED_HZ32_WU,         /* 污 */
    OLED_HZ32_DAI,        /* 待 */
    OLED_HZ32_JI,         /* 机 */
    OLED_HZ32_CHONG,      /* 冲 */
    OLED_HZ32_XI,         /* 洗 */
    OLED_HZ32_GU,         /* 故 */
    OLED_HZ32_ZHANG,      /* 障 */
    OLED_HZ32_COUNT
} oled_hz32_id_t;

/*
 * 函数名：oled_init
 * 作用：打开 I2C0、初始化 SSD1306、清屏（全黑）、点亮显示。
 * 参数：无。
 * 返回：true=初始化成功（后续可刷新）；false=任何一步失败（I2C Open 失败/无应答/超时）。
 * 时序/边界：上电调用一次，内部含 100 ms 上电延时 + 约 25 ms 清屏，总耗时约 130 ms；
 *             必须在 UART 初始化之后调用（先保证串口能报告失败）。
 * 注意：失败不是致命错误：上层打印 WARN 后继续用串口，判别/阀不受影响。
 */
bool oled_init(void);

/* 当前驱动是否可用（初始化成功且未连续失败到"丢失"阈值）。 */
bool oled_ready(void);

/* 屏幕是否已判丢失（连续 OLED_MAX_FAIL 帧刷新失败；用于上层只报一次 WARN）。 */
bool oled_lost(void);

/* 清空显存（全黑）并把 8 页全部标脏（下次 oled_flush 全屏刷新）。 */
void oled_clear(void);

/*
 * 函数名：oled_draw_pixel
 * 作用：显存画点（不立即写屏，等 oled_flush）。
 * 参数：x/y 像素坐标；on=true 点亮。越界自动忽略。
 * 时序/边界：O(1)，只置 dirty 位。
 * 注意：坐标必须满足 x<128、y<64；不做错误返回（现场指示器，画错不致命）。
 */
void oled_draw_pixel(uint8_t x, uint8_t y, bool on);

/*
 * 函数名：oled_fill_rect
 * 作用：显存填充矩形（不立即写屏）。
 * 参数：x/y 左上角；w/h 宽高；on=true 涂白、false 涂黑。
 * 时序/边界：O(w*h)，越界部分被裁掉；用于清空文本区域，避免旧内容残留。
 * 注意：只改显存 + 脏页位，不产生 I2C 传输。
 */
void oled_fill_rect(uint8_t x, uint8_t y, uint8_t w, uint8_t h, bool on);

/*
 * 函数名：oled_text_6x8
 * 作用：在显存写 6x8 ASCII 字符串（小号字，21 字符/行）。
 * 参数：x/y 起点（y 必须 8 对齐）；p_text 以 '\0' 结尾（NULL 视为空串）。
 * 返回：无。
 * 时序/边界：每字符 6x6 像素、字宽 6；x 越界自动停止；非 ASCII(<32 或 >126) 按空格画。
 * 注意：直接覆写该页对应 6 列的背景，不会清除行尾更右侧的旧内容——需要清整行时
 *       上层先 oled_fill_rect。
 */
void oled_text_6x8(uint8_t x, uint8_t y, const char *p_text);

/*
 * 函数名：oled_text_8x16
 * 作用：在显存写 8x16 ASCII 字符串（大号字，16 字符/行）。
 * 参数：x/y 起点（y 必须 8 对齐）；p_text 以 '\0' 结尾（NULL 视为空串）。
 * 返回：无。
 * 时序/边界：每字符占 8x16（两页），x 越界自动停止。
 * 注意：字模存储为"上 8 行 + 下 8 行"（见 oledfont.h），本函数按页拆分写入。
 */
void oled_text_8x16(uint8_t x, uint8_t y, const char *p_text);

/*
 * 函数名：oled_hz32
 * 作用：在显存写一个 32x32 汉字（x 必须 8 对齐、y 必须 8 对齐；占 4 页）。
 * 参数：x/y 左上角；id 汉字索引；inverse=false 正显（黑底白字），true 反显（白底黑字）。
 * 返回：无。
 * 时序/边界：占 32 列 x 4 页；整块覆写（含背景），所以切换正/反显不需要先清屏。
 * 注意：反显时整块背景涂白，适合"污水"这类需要抓眼球的提示。
 */
void oled_hz32(uint8_t x, uint8_t y, oled_hz32_id_t id, bool inverse);

/*
 * 函数名：oled_flush
 * 作用：把脏页写到屏幕（每页 2 次 I2C 传输：地址命令 + 数据块）。
 * 参数：无。
 * 返回：true=所有脏页写成功（脏页位清零）；false=至少一页失败（保留脏页位，累计失败计数）。
 * 时序/边界：单页约 3 ms（400 kHz），全屏约 25 ms；在 50 ms 主循环里调用必须节流。
 * 注意：连续 OLED_MAX_FAIL 帧失败 → oled_lost()=true，之后所有刷新直接返回 false；
 *       此时上层只需打印一次 WARN，继续用串口（显示不是安全路径）。
 */
bool oled_flush(void);

#ifdef __cplusplus
}
#endif
#endif /* OLED_H */

/* ===== FILE: src/oled.c ===== */
/*
 * oled.c —— 板载 0.96" OLED（SSD1306，128x64，I2C0）驱动实现
 * ---------------------------------------------------------------------------
 * 本文件只做三件事：
 *   1) I2C0 + SSD1306 初始化（Open → 上电延时 → 初始化命令序列 → 清屏）；
 *   2) 1 KB 页式显存 + 画点/矩形/6x8 ASCII/8x16 ASCII/32x32 汉字（全部只改显存）；
 *   3) 脏页刷新：只把改过的页写屏，一页 = 地址命令 + 128 字节数据两次传输。
 *
 * 为什么按页刷而不是每次整屏刷：
 *   - 50 ms 主循环里，全屏 8 页约 25 ms 的 I2C 阻塞会明显挤占采样与判别；
 *   - 现场最常见的更新是第三行数值（ΔEC/g/ΔNTU），只脏第 7 页，约 3 ms；
 *     状态/大字变化时才刷第 0~6 页，且由 display.c 节流（状态变化立即、数值 200 ms）。
 *
 * 为什么用 FSP 的 IIC Master（而不是 GPIO 模拟 I2C）：
 *   - 板载 OLED 本来就接在 I2C0（P407/P408），RASC 里加一个 IIC Master 栈即可；
 *   - FSP 驱动处理起始/停止/ACK/超时，代码量小；轮询等待只等"本帧完成"事件，
 *     有硬上限（每页 30 ms），不会死等——屏幕坏线也只损失这一帧显示。
 *
 * 错误处理原则（显示不是安全路径）：
 *   - 任何一次 I2C 失败只返回 false，不打印、不死机、不 assert、不 __BKPT；
 *   - 连续 OLED_MAX_FAIL 帧失败 → 判"屏幕丢失"（oled_lost()=true），以后刷新直接返回；
 *   - 上层（display.c/app_main.c）负责打印一次 "# WARN: OLED lost ..."。
 *
 * 依赖：RASC 配置 I2C Master（r_iic_master / IIC0）：
 *   Name=g_i2c_master0、Channel=0、Fast-mode 400 kHz、Slave=0x3C、7-bit、
 *   Timeout=short、Callback=i2c_master_callback（本文件提供该回调）。
 */
#include "oled.h"

#include <stddef.h>
#include <string.h>

#include "hal_data.h"

/* 点阵字库（6x8 / 8x16 ASCII + 9 个 32x32 汉字），只允许本文件 include。
 * 字库用 static 数组放在头文件里：只有本编译单元生成一份，不占 Flash 之外的空间。 */
#include "oledfont.h"

/* ============================ 内部常量 ============================ */

/* SSD1306 128x64 初始化命令序列（每条单独一次 2 字节传输：控制字 0x00 + 命令）。
 * 各命令含义：
 *   0xAE 关显示；0xD5/0x80 时钟分频；0xA8/0x3F 复用率 1/64；0xD3/0x00 显示偏移 0；
 *   0x40 起始行 0；0x8D/0x14 开电荷泵；0x20/0x00 页寻址模式；
 *   0xA0 列重映射（由 oled.h 的 OLED_SEG_REMAP_CMD 决定：本板必须 0xA0，
 *        写成 0xA1 时整屏文字左右镜像 —— v1.1.2 修掉的现象）；
 *   0xC8 行重映射（上下正装）；0xDA/0x12 COM 引脚配置；0x81/0xCF 对比度；
 *   0xD9/0xF1 预充电周期；0xDB/0x40 VCOMH；0xA4 显存内容显示；0xA6 正显；0xAF 开显示。
 * 说明：顺序来自 SSD1306 数据手册的典型初始化流程；除列重映射按实测面板取 0xA0 外，
 *       其余参数与常见 0.96" 模块一致。换屏后若左右反了，只改 OLED_SEG_REMAP_CMD。 */
static const uint8_t g_oled_init_cmds[] =
{
    0xAEU,
    0xD5U, 0x80U,
    0xA8U, 0x3FU,
    0xD3U, 0x00U,
    0x40U,
    0x8DU, 0x14U,
    0x20U, 0x00U,
    OLED_SEG_REMAP_CMD,
    0xC8U,
    0xDAU, 0x12U,
    0x81U, 0xCFU,
    0xD9U, 0xF1U,
    0xDBU, 0x40U,
    0xA4U,
    0xA6U,
    0xAFU
};

#define OLED_CTRL_CMD       0x00U   /* 控制字：后续字节是命令 */
#define OLED_CTRL_DATA      0x40U   /* 控制字：后续字节是显存数据 */
#define OLED_CMD_BUF_SIZE   4U      /* 一页的地址命令：0x00 + B0/p + 00 + 10 */
#define OLED_DATA_BUF_SIZE  (1U + OLED_WIDTH)  /* 0x40 + 128 字节数据 */
#define OLED_WAIT_LOOPS     300U    /* 单次传输等待上限：300 * 100 µs = 30 ms */
#define OLED_WAIT_STEP_US   100U    /* 等待步长（µs） */

/* ============================ 内部状态 ============================ */

/* 1 KB 显存：gram[page][x]，bit0 = 该页最上一行（SSD1306 页式格式）。 */
static uint8_t g_oled_gram[OLED_PAGE_COUNT][OLED_WIDTH];

/* 脏页位图：bit p = 第 p 页需要刷新。绘图函数只置位，oled_flush 成功后清零。 */
static uint8_t g_oled_dirty;

/* I2C 传输完成标志：由 i2c_master_callback（中断上下文）写，主循环读。
 * 注意 volatile：主循环必须每次从内存重新读取，不能缓存在寄存器里。 */
static volatile bool              g_oled_tx_done;
static volatile i2c_master_event_t g_oled_tx_event;

/* 驱动状态 */
static bool    g_oled_ready;        /* 初始化成功且未判丢失 */
static bool    g_oled_lost;         /* 连续失败达到阈值，判屏幕丢失 */
static uint8_t g_oled_fail_count;   /* 连续失败帧数 */

/* 传输缓冲：静态分配（不用动态内存；也避免每帧把 133 字节压到主循环栈上）。 */
static uint8_t g_oled_cmd_buf[OLED_CMD_BUF_SIZE];
static uint8_t g_oled_data_buf[OLED_DATA_BUF_SIZE];

/* ============================ I2C 底层 ============================ */

/*
 * 函数名：i2c_master_callback
 * 作用：FSP IIC Master 完成/异常回调（RASC 里 Callback 必须配成这个名字）。
 * 参数：p_args —— 事件参数；event=TX_COMPLETE 表示本帧发送完成，ABORTED 表示异常中止。
 * 返回：无。
 * 时序/边界：中断上下文调用；只记录事件并置完成标志，绝不在中断里打印/延时。
 * 注意：本回调是"整帧"级别的；oled_flush 用 g_oled_tx_done 轮询等待。
 */
void i2c_master_callback(i2c_master_callback_args_t *p_args)
{
    if (NULL != p_args)
    {
        g_oled_tx_event = p_args->event;
    }
    else
    {
        g_oled_tx_event = I2C_MASTER_EVENT_ABORTED;
    }
    g_oled_tx_done = true;
}

/*
 * 函数名：oled_i2c_write
 * 作用：发起一次 I2C 写并等待整帧完成（有硬超时，不死等）。
 * 参数：p_buf/len —— 待发送字节（首字节是控制字 0x00 或 0x40）。
 * 返回：true=TX_COMPLETE；false=驱动报错/超时/被中止。
 * 时序/边界：单帧 133 字节 @400 kHz 约 3 ms；等待上限 30 ms。
 * 注意：失败后不清 g_oled_ready（上层按连续失败帧数判丢失），也不重试——
 *       重试会拉长主循环阻塞时间，交给下一帧自然重试（脏页位保留）。
 */
static bool oled_i2c_write(const uint8_t *p_buf, uint32_t len)
{
    fsp_err_t err;
    uint32_t  i;

    if ((NULL == p_buf) || (0U == len))
    {
        return false;
    }

    /* 清完成标志必须在发起传输之前：否则可能把上一帧的事件当成本帧的。 */
    g_oled_tx_done  = false;
    g_oled_tx_event = I2C_MASTER_EVENT_ABORTED;

    /* FSP 6.6 的 R_IIC_MASTER_Write 形参是 uint8_t*（非 const），这里强转；
     * 驱动只读缓冲区，调用期间 p_buf 有效（静态缓冲或调用方栈上数组）。 */
    err = R_IIC_MASTER_Write(&g_i2c_master0_ctrl, (uint8_t *)p_buf, len, false);
    if (FSP_SUCCESS != err)
    {
        return false;
    }

    for (i = 0U; i < OLED_WAIT_LOOPS; i++)
    {
        if (g_oled_tx_done)
        {
            break;
        }
        R_BSP_SoftwareDelay(OLED_WAIT_STEP_US, BSP_DELAY_UNITS_MICROSECONDS);
    }

    if (!g_oled_tx_done)
    {
        /* 超时：主动 Abort，避免下一帧发不出去（Abort 失败也不管，下一帧会自然暴露）。 */
        (void)R_IIC_MASTER_Abort(&g_i2c_master0_ctrl);
        return false;
    }

    return (I2C_MASTER_EVENT_TX_COMPLETE == g_oled_tx_event);
}

/*
 * 函数名：oled_write_cmd
 * 作用：发一条 SSD1306 命令（控制字 0x00 + 1 字节命令）。
 * 参数：cmd —— 命令字节。
 * 返回：true=发送成功。
 * 时序/边界：约 0.1 ms/条；初始化序列共 25 条约 3 ms。
 * 注意：只用于初始化与页地址设置；显存数据用 oled_write_page。
 */
static bool oled_write_cmd(uint8_t cmd)
{
    uint8_t buf[2];

    buf[0] = OLED_CTRL_CMD;
    buf[1] = cmd;
    return oled_i2c_write(buf, 2U);
}

/*
 * 函数名：oled_flush_page
 * 作用：把显存第 page 页写到屏幕。
 * 参数：page —— 0~7。
 * 返回：true=成功（清该页脏位）；false=失败（保留脏位，等下一帧重试）。
 * 时序/边界：两次传输（4 字节命令 + 129 字节数据），约 3 ms。
 * 注意：页地址命令必须连续设置 B0/p、低列 0x00、高列 0x10，否则列指针会错位。
 */
static bool oled_flush_page(uint8_t page)
{
    if (page >= OLED_PAGE_COUNT)
    {
        return false;
    }

    /* 1) 地址命令：页地址 + 列地址 0（低 4 位/高 4 位）。 */
    g_oled_cmd_buf[0] = OLED_CTRL_CMD;
    g_oled_cmd_buf[1] = (uint8_t)(0xB0U | page);   /* 页地址 */
    g_oled_cmd_buf[2] = 0x00U;                     /* 低列地址 0 */
    g_oled_cmd_buf[3] = 0x10U;                     /* 高列地址 0 */
    if (!oled_i2c_write(g_oled_cmd_buf, OLED_CMD_BUF_SIZE))
    {
        return false;
    }

    /* 2) 数据块：0x40 + 128 字节该页显存。 */
    g_oled_data_buf[0] = OLED_CTRL_DATA;
    (void)memcpy(&g_oled_data_buf[1], g_oled_gram[page], OLED_WIDTH);
    return oled_i2c_write(g_oled_data_buf, OLED_DATA_BUF_SIZE);
}

/* ============================ 对外初始化 ============================ */

/*
 * 函数名：oled_init
 * 作用：打开 I2C0、上电延时、初始化 SSD1306、清屏并点亮。
 * 参数：无。
 * 返回：true=成功；false=失败（上层只打印 WARN，继续用串口）。
 * 时序/边界：约 130 ms（100 ms 上电延时 + 初始化命令 + 清屏 8 页）；
 *             必须在 UART 初始化之后调用，保证失败信息打得出。
 * 注意：上电延时 100 ms 是必要的——OLED 的电荷泵/复位需要稳定时间，
 *       太早发初始化命令会出现"花屏/半亮"的经典现象。
 */
bool oled_init(void)
{
    fsp_err_t err;
    uint32_t  i;
    bool      ok = true;

    g_oled_ready      = false;
    g_oled_lost       = false;
    g_oled_fail_count = 0U;
    g_oled_dirty      = 0U;
    (void)memset(g_oled_gram, 0, sizeof(g_oled_gram));

    /* 1) 打开 IIC0。回调/中断优先级来自 RASC 生成的 g_i2c_master0_cfg。 */
    err = R_IIC_MASTER_Open(&g_i2c_master0_ctrl, &g_i2c_master0_cfg);
    if (FSP_SUCCESS != err)
    {
        return false;
    }

    /* 2) 显式设一次从机地址（7-bit 0x3C）。FSP 的 Open 会按 cfg 设置，
     *    这里再设一次是防御性动作：以后若在 RASC 里改了 cfg.slave，也不会静默用错地址。 */
    err = R_IIC_MASTER_SlaveAddressSet(&g_i2c_master0_ctrl, OLED_I2C_ADDR,
                                       I2C_MASTER_ADDR_MODE_7BIT);
    if (FSP_SUCCESS != err)
    {
        return false;
    }

    /* 3) 上电稳定延时（见"注意"）。 */
    R_BSP_SoftwareDelay(100U, BSP_DELAY_UNITS_MILLISECONDS);

    /* 4) 初始化命令序列（任何一条失败即判初始化失败）。 */
    for (i = 0U; i < (uint32_t)(sizeof(g_oled_init_cmds) / sizeof(g_oled_init_cmds[0])); i++)
    {
        if (!oled_write_cmd(g_oled_init_cmds[i]))
        {
            ok = false;
            break;
        }
    }

    if (!ok)
    {
        return false;
    }

    /* 5) 清屏：显存清零 + 8 页全标脏 → 全屏刷黑，避免上电显存随机内容。 */
    g_oled_ready = true;
    oled_clear();
    if (!oled_flush())
    {
        g_oled_ready = false;
        return false;
    }

    return true;
}

bool oled_ready(void)
{
    return g_oled_ready;
}

bool oled_lost(void)
{
    return g_oled_lost;
}

/* ============================ 显存绘图 ============================ */

/* 把 (x, y) 所在页标脏。 */
static void oled_mark_page(uint8_t y)
{
    g_oled_dirty |= (uint8_t)(1U << (y >> 3));
}

void oled_clear(void)
{
    (void)memset(g_oled_gram, 0, sizeof(g_oled_gram));
    g_oled_dirty = (uint8_t)((1U << OLED_PAGE_COUNT) - 1U);   /* 8 页全脏 */
}

void oled_draw_pixel(uint8_t x, uint8_t y, bool on)
{
    uint8_t page;
    uint8_t mask;

    if ((x >= OLED_WIDTH) || (y >= OLED_HEIGHT))
    {
        return;
    }

    page = (uint8_t)(y >> 3);
    mask = (uint8_t)(1U << (y & 7U));
    if (on)
    {
        g_oled_gram[page][x] |= mask;
    }
    else
    {
        g_oled_gram[page][x] &= (uint8_t)(~mask);
    }
    oled_mark_page(y);
}

void oled_fill_rect(uint8_t x, uint8_t y, uint8_t w, uint8_t h, bool on)
{
    uint8_t xx;
    uint8_t yy;

    for (yy = y; (yy < OLED_HEIGHT) && ((uint16_t)yy < ((uint16_t)y + h)); yy++)
    {
        for (xx = x; (xx < OLED_WIDTH) && ((uint16_t)xx < ((uint16_t)x + w)); xx++)
        {
            oled_draw_pixel(xx, yy, on);
        }
    }
}

void oled_text_6x8(uint8_t x, uint8_t y, const char *p_text)
{
    uint8_t page;
    uint8_t cx;
    uint8_t code;
    uint8_t col;

    if (NULL == p_text)
    {
        return;
    }

    /* 只支持 8 像素对齐：不做跨页移位，保证实现简单、时序可控（文档已约定）。 */
    page = (uint8_t)(y >> 3);
    if (page >= OLED_PAGE_COUNT)
    {
        return;
    }

    cx = x;
    while ('\0' != *p_text)
    {
        code = (uint8_t)*p_text;
        p_text++;

        if ((code < OLED_FONT_FIRST_ASCII) || (code >= (OLED_FONT_FIRST_ASCII + OLED_FONT_ASCII_COUNT)))
        {
            code = (uint8_t)' ';   /* 非可打印 ASCII 按空格处理，避免读越界 */
        }

        if ((uint16_t)cx + 6U > OLED_WIDTH)
        {
            break;                 /* 行尾放不下：截断，不折行 */
        }

        for (col = 0U; col < 6U; col++)
        {
            g_oled_gram[page][cx + col] = oled_asc6x8[code - OLED_FONT_FIRST_ASCII][col];
        }
        oled_mark_page(y);
        cx = (uint8_t)(cx + 6U);
    }
}

void oled_text_8x16(uint8_t x, uint8_t y, const char *p_text)
{
    uint8_t page;
    uint8_t cx;
    uint8_t code;
    uint8_t col;
    const uint8_t *p_glyph;

    if (NULL == p_text)
    {
        return;
    }

    page = (uint8_t)(y >> 3);
    if ((page + 1U) >= OLED_PAGE_COUNT)
    {
        return;
    }

    cx = x;
    while ('\0' != *p_text)
    {
        code = (uint8_t)*p_text;
        p_text++;

        if ((code < OLED_FONT_FIRST_ASCII) || (code >= (OLED_FONT_FIRST_ASCII + OLED_FONT_ASCII_COUNT)))
        {
            code = (uint8_t)' ';
        }

        if ((uint16_t)cx + 8U > OLED_WIDTH)
        {
            break;
        }

        /* 8x16 字模格式：前 8 字节 = 上半 8 列，后 8 字节 = 下半 8 列（见 oledfont.h）。 */
        p_glyph = oled_asc8x16[code - OLED_FONT_FIRST_ASCII];
        for (col = 0U; col < 8U; col++)
        {
            g_oled_gram[page][cx + col]     = p_glyph[col];
            g_oled_gram[page + 1U][cx + col] = p_glyph[col + 8U];
        }
        oled_mark_page(y);
        oled_mark_page((uint8_t)(y + 8U));
        cx = (uint8_t)(cx + 8U);
    }
}

void oled_hz32(uint8_t x, uint8_t y, oled_hz32_id_t id, bool inverse)
{
    uint8_t page;
    uint8_t p;
    uint8_t c;
    uint8_t data;
    const uint8_t *p_glyph;

    if ((id >= OLED_HZ32_COUNT) || (x > (OLED_WIDTH - 32U)))
    {
        return;
    }

    page = (uint8_t)(y >> 3);
    if ((page + 3U) >= OLED_PAGE_COUNT)
    {
        return;
    }

    /* 32x32 字模：page p (0..3) 的第 c 列 = 第 p*8+0..7 行的 8 个像素（bit0=上）。
     * 反显 = 按位取反：整块 32x32 的背景也一起变白（"白底黑字"标签效果）。 */
    p_glyph = oled_hz32_bitmaps[id];
    for (p = 0U; p < 4U; p++)
    {
        for (c = 0U; c < 32U; c++)
        {
            data = p_glyph[(uint16_t)p * 32U + c];
            if (inverse)
            {
                data = (uint8_t)(~data);
            }
            g_oled_gram[page + p][x + c] = data;
        }
        oled_mark_page((uint8_t)(y + p * 8U));
    }
}

/* ============================ 刷屏 ============================ */

bool oled_flush(void)
{
    uint8_t page;
    bool    ok = true;

    if (!g_oled_ready || g_oled_lost)
    {
        return false;
    }

    for (page = 0U; page < OLED_PAGE_COUNT; page++)
    {
        if (0U == (g_oled_dirty & (uint8_t)(1U << page)))
        {
            continue;
        }

        if (!oled_flush_page(page))
        {
            ok = false;
            break;   /* 先停：I2C 异常时连续重试只会拖长主循环阻塞 */
        }
        g_oled_dirty &= (uint8_t)(~(uint8_t)(1U << page));
    }

    if (!ok)
    {
        g_oled_fail_count++;
        if (g_oled_fail_count >= OLED_MAX_FAIL)
        {
            /* 连续失败达到阈值：判"屏幕丢失"，以后刷新直接返回 false，不再占用主循环。 */
            g_oled_lost  = true;
            g_oled_ready = false;
        }
        return false;
    }

    g_oled_fail_count = 0U;
    return true;
}

/*
 * display.h —— 板载 0.96" OLED 状态页：把判别结果画成现场可读的一屏
 * ---------------------------------------------------------------------------
 * 定位（与 oled.h 一致）：
 *   - 这是"现场指示器"，不是安全执行路径：屏幕坏了/不刷新，判别、串口 CSV、
 *     LED/阀都不受影响；app_main 只在连续失败时打印一次 WARN；
 *   - 只画"本工程定义的量"：清水/污水/待机/冲洗/故障 + EC0/σ/水温/ΔEC/g/ΔNTU%，
 *     不画 NTU 读数、不画绝对 ppm、不说"识别出污染物"（红线见 00 文档）；
 *   - 不用动态内存、不用变长数组、不用浮点 printf；最多 1 KB 静态显存。

 * 页面规格（128x64，坐标 8 像素对齐；详见 10 文档 §3）：
 *     y=0   (6x8)  : 页头  "EC0=1490 s1.5 T25.3"（无基线时 EC0=---- s---）
 *     y=8   (32x32): 大字两个，x=32 与 x=64（共 64x32，居中）
 *     y=40  (8x16) : 状态串 "CLEAR  RECOVER" 等
 *     y=56  (6x8)  : 数值串 "dEC+12mV g1.008 N+5"

 * 大字映射（契约 §3，"先区分清水和污水"就落在这里）：
 *     CLEAR                → 清水（正显）
 *     UNCERTAIN / SOAP     → 污水（反显，白底黑字，抓眼球）
 *     WAIT                 → 待机
 *     FLUSH                → 冲洗
 *     无基线/传感器故障     → 故障
 * 注意：无事件（WAIT）时显示的"待机"不是水质结论——此时阀按安全侧排空（DRAIN）；
 *       水质结论只在事件内由判别器给出（CLEAR/UNCERTAIN/SOAP）。

 * 刷新模型（实现见 display.c）：
 *   - 状态/大字/状态串变化 → 立即重画对应区域；
 *   - 数值（页头/数值串）→ 最快 200 ms 一次（避免每 50 ms tick 都占 I2C）；
 *   - 1 s 心跳整屏重画（掉帧/上电残影自恢复，也是"屏还活着"的证据）；
 *   - 只刷脏页（oled_flush 内部实现），一页约 3 ms@400 kHz。
 */

/*
 * display.c —— 判别结果 → 板载 0.96" OLED 状态页（128x64，I2C0）
 * ---------------------------------------------------------------------------
 * 作用
 *   本文件把 sensor_pipeline_t 的流水线输出（EC0/σ/水温/ΔEC/g/ΔNTU%）与
 *   decision_out_t 的判别输出（state/level/action）翻译成一屏"现场可读"的状态页：
 *   大字显示 清水/污水/待机/冲洗/故障，两行小字显示状态串与关键数值。
 *
 * 页面规格（与 10 文档 §3、契约 CONTRACT_v1.1 §3 逐条对应）：
 *     ┌──────────────────────────────────────────────┐
 *     │ y=0  : EC0=1490 s1.5 T25.3                   │  6x8，最多 21 字符
 *     │ y=8  :        [清 水] / [污 水] / [待 机] ... │  32x32 x2（x=32/64）
 *     │ y=40 : CLEAR  RECOVER                        │  8x16，最多 16 字符
 *     │ y=56 : dEC+12mV g1.008 N+5                   │  6x8，最多 21 字符
 *     └──────────────────────────────────────────────┘
 *
 * 大字映射（契约 §3）：
 *     CLEAR            → 清水（正显）
 *     UNCERTAIN / SOAP → 污水（反显：白底黑字，现场一眼能看出"该排")
 *     WAIT             → 待机（无事件；不等于水质结论，阀在安全侧）
 *     FLUSH            → 冲洗（事件开头的强制排空段）
 *     无基线/传感器故障 → 故障
 *
 * 为什么这么设计（工程取舍）：
 *   - 现场演示需要"一眼看懂"：4 个 32x32 汉字比一行英文有效得多；但字库只有 9 个
 *     字形（清/水/污/待/机/冲/洗/故/障），不能显示任意中文，所以第二行用英文；
 *   - 刷新必须避开 50 ms 主循环：状态/大字变化立即重画，数值最快 200 ms 一次，
 *     1 s 整屏心跳（掉帧自恢复），只刷脏页（一页约 3 ms@400 kHz，整屏约 25 ms）；
 *   - 显示不是安全路径：任何 I2C 失败只返回 false，不打印、不死机、不 assert；
 *     连续 3 帧失败后 display_task 返回 false，由 app_main 打印一次 WARN 后继续用串口；
 *   - 不动态内存、不浮点 printf：所有数值先手工换算成整数再格式化（snprintf 只用
 *     %u/%d/%+d/%s），避免 newlib 浮点格式化把 Flash/RAM 拉大。
 *
 * 与判别器的一致性：
 *   故障判定与 decision.c 完全一致：
 *     fault = adc_timeout || tds_status != SENSOR_OK || ntu_status != SENSOR_OK
 *   无基线（baseline_valid=false）时按"基线采集中 / 无基线"两态分别显示：
 *     - 采集中（baseline_n 在 1..19）：大字"待机" + "BASELINE  n/20"（进度）；
 *     - 无基线（n=0 或结算无效）：大字"故障" + "L1 NO_BASELINE"（提示按 B 重采）。
 *
 * 依赖：oled.h/oled.c（SSD1306 驱动 + 字库）；RASC 里必须有 g_i2c_master0。
 */

/*
 * 函数名：disp_round_i
 * 作用：浮点四舍五入到 int32（对称舍入，负值也按绝对值进舍）。
 * 参数：v —— 待舍入值（本工程量级远小于 int32 范围，不做溢出保护）。
 * 返回：舍入后的整数。
 * 时序/边界：纯计算，无副作用。
 * 注意：不用 lroundf/roundf（会拉进 libm，本工程禁 libm）。
 */
static int32_t disp_round_i(float v)
{
    if (v >= 0.0f)
    {
        return (int32_t)(v + 0.5f);
    }
    return (int32_t)(v - 0.5f);
}

/*
 * 函数名：disp_copy
 * 作用：安全字符串拷贝（带长度上限，保证 '\0' 结尾）。
 * 参数：p_dst/cap —— 目标与容量；p_src —— 源（NULL 视为空串）。
 * 返回：无。
 * 时序/边界：O(n)；截断而不是溢出。
 * 注意：本工程字符串都是静态字面量或固定缓冲，不会出现超长动态串。
 */
static void disp_copy(char *p_dst, uint32_t cap, const char *p_src)
{
    uint32_t i = 0U;

    if ((NULL == p_dst) || (0U == cap))
    {
        return;
    }

    while ((NULL != p_src) && ('\0' != *p_src) && ((i + 1U) < cap))
    {
        p_dst[i] = *p_src;
        i++;
        p_src++;
    }
    p_dst[i] = '\0';
}

/*
 * 函数名：disp_fmt_temp
 * 作用：把水温格式化成一位小数（如 "25.3"、"-3.0"），不带单位。
 * 参数：p_buf/cap —— 输出缓冲；temp_c —— 水温（℃）。
 * 返回：无。
 * 时序/边界：缓冲 ≥ 7 字节（"-99.9" + '\0'）。
 * 注意：负温度需要保留符号；本工程水温正常在 5~40 ℃，但 DS18B20 故障/冬天也不能
 *       让符号位丢失（否则 -0.5 ℃ 会显示成 0.5 ℃，温补方向就反了）。
 */
static void disp_fmt_temp(char *p_buf, uint32_t cap, float temp_c)
{
    int32_t  t10;
    uint32_t a;
    uint32_t whole;
    uint32_t i = 0U;

    if ((NULL == p_buf) || (0U == cap))
    {
        return;
    }

    t10 = disp_round_i(temp_c * 10.0f);
    if (t10 > 9999)
    {
        t10 = 9999;       /* 显示上限 999.9 ℃（实际水温不可能到，纯防格式化溢出） */
    }
    if (t10 < -9999)
    {
        t10 = -9999;
    }
    a     = (uint32_t)((t10 < 0) ? (-t10) : t10);
    whole = a / 10U;      /* 整数部分（0~999） */
    if (cap < 5U)
    {
        p_buf[0] = '\0';
        return;
    }

    /* 手工拼 "[-]<whole>.<一位小数>"：不用 snprintf，避免 -Wformat-truncation */
    if (t10 < 0)
    {
        p_buf[i] = '-';
        i++;
    }
    if (whole >= 100U)
    {
        p_buf[i] = (char)('0' + (whole / 100U));
        i++;
        whole %= 100U;
        p_buf[i] = (char)('0' + (whole / 10U));
        i++;
        p_buf[i] = (char)('0' + (whole % 10U));
        i++;
    }
    else if (whole >= 10U)
    {
        p_buf[i] = (char)('0' + (whole / 10U));
        i++;
        p_buf[i] = (char)('0' + (whole % 10U));
        i++;
    }
    else
    {
        p_buf[i] = (char)('0' + whole);
        i++;
    }
    p_buf[i] = '.';
    i++;
    p_buf[i] = (char)('0' + (a % 10U));
    i++;
    p_buf[i] = '\0';
}

/*
 * 函数名：disp_fmt_header
 * 作用：格式化页头 "EC0=<4位mV> s<σ.一位> T<温度.一位>"；无基线时用 ---- / --- 占位。
 * 参数：p_buf/cap —— 输出；p_out —— 流水线输出。
 * 返回：无。
 * 时序/边界：缓冲 ≥ 22 字节。
 * 注意：EC0 用整数 mV（四舍五入），与 CSV 的 ec0 字段同源；σ 只显示一位小数，
 *       够现场判断"噪声大不大"，精确值看串口 CSV。
 */
static void disp_fmt_header(char *p_buf, uint32_t cap, const pipeline_out_t *p_out)
{
    char    tbuf[8];
    int32_t sig10;

    if ((NULL == p_buf) || (0U == cap) || (NULL == p_out))
    {
        return;
    }

    disp_fmt_temp(tbuf, (uint32_t)sizeof(tbuf), p_out->water_temp_c);

    if (p_out->baseline_valid)
    {
        sig10 = disp_round_i(p_out->ec_sigma_mv * 10.0f);
        if (sig10 < 0)
        {
            sig10 = 0;
        }
        if (sig10 > 999)
        {
            sig10 = 999;   /* 显示上限 99.9 mV，够用；真这么大说明探头/流动池有问题 */
        }
        (void)snprintf(p_buf, (size_t)cap, "EC0=%4u s%u.%u T%s",
                       (unsigned)disp_round_i(p_out->ec0_mv25),
                       (unsigned)((uint32_t)sig10 / 10U),
                       (unsigned)((uint32_t)sig10 % 10U),
                       tbuf);
    }
    else
    {
        (void)snprintf(p_buf, (size_t)cap, "EC0=---- s--- T%s", tbuf);
    }
}

/*
 * 函数名：disp_fmt_numbers
 * 作用：格式化数值串 "dEC%+dmV g%d.%03d N%+d"（例："dEC+12mV g1.008 N+5"）。
 * 参数：p_buf/cap —— 输出；p_out —— 流水线输出。
 * 返回：无。
 * 时序/边界：缓冲 ≥ 22 字节；N 限幅到 ±99（6x8 一行最多 21 字符，不能无限长）。
 * 注意：g 用"千分位整数"打印（g_milli=1008 → "g1.008"），避免浮点 printf；
 *       ΔEC 用四舍五入整数 mV（与 08 文档记录表的量级一致）。
 */
static void disp_fmt_numbers(char *p_buf, uint32_t cap, const pipeline_out_t *p_out)
{
    int32_t d_ec;
    int32_t g_milli;
    int32_t n;

    if ((NULL == p_buf) || (0U == cap) || (NULL == p_out))
    {
        return;
    }

    d_ec    = disp_round_i(p_out->d_ec_mv);
    g_milli = disp_round_i(p_out->g_ec * 1000.0f);
    n       = disp_round_i(p_out->d_ntu_pct);

    if (g_milli < 0)
    {
        g_milli = 0;           /* g 理论上 >0；异常值兜底，防止出现 "g-1.000" */
    }
    if (g_milli > 99999)
    {
        g_milli = 99999;       /* 防止一行超长（现场指示器，超限按上限显示） */
    }
    if (n > 99)
    {
        n = 99;
    }
    if (n < -99)
    {
        n = -99;
    }

    (void)snprintf(p_buf, (size_t)cap, "dEC%+dmV g%d.%03d N%+d",
                   (int)d_ec, (int)(g_milli / 1000), (int)(g_milli % 1000), (int)n);
}

/*
 * 函数名：disp_fmt_note
 * 作用：把流水线 note（ADC_TIMEOUT / TDS_RAIL / ...）拼成 "note=xxx" 供故障页显示。
 * 参数：p_buf/cap —— 输出；p_note —— note 字符串（可能为 NULL）。
 * 返回：无。
 * 时序/边界：手动逐字符拼，不用 "%.13s"（避免 -Wformat-truncation 告警）。
 * 注意：note 已由 pipeline 限长 28 字节，这里再按输出缓冲截断。
 */
static void disp_fmt_note(char *p_buf, uint32_t cap, const char *p_note)
{
    static const char prefix[] = "note=";
    uint32_t i = 0U;

    if ((NULL == p_buf) || (0U == cap))
    {
        return;
    }

    while ((prefix[i] != '\0') && ((i + 1U) < cap))
    {
        p_buf[i] = prefix[i];
        i++;
    }
    while ((NULL != p_note) && ('\0' != *p_note) && ((i + 1U) < cap))
    {
        p_buf[i] = *p_note;
        i++;
        p_note++;
    }
    p_buf[i] = '\0';
}

/* ============================ 页面内容 ============================ */

/*
 * 函数名：disp_is_fault
 * 作用：判断本 tick 是否处于"传感器故障"（与 decision.c 的安全侧判据完全一致）。
 * 参数：p_out —— 流水线输出。
 * 返回：true=故障（ADC 超时 / 任一路状态非 OK）。
 * 时序/边界：纯函数。
 * 注意：故障优先于一切显示——即使 state 是 CLEAR 也必须显示"故障"，
 *       因为 CLEAR 的前提是传感器健康。
 */
static bool disp_is_fault(const pipeline_out_t *p_out)
{
    return p_out->adc_timeout
        || (SENSOR_OK != p_out->tds_status)
        || (SENSOR_OK != p_out->ntu_status);
}

/*
 * 函数名：disp_build_page
 * 作用：根据流水线/判别输出算出一屏的完整目标内容（不画屏）。
 * 参数：p_out/p_dec —— 输入；p_page —— 输出（调用前无需清零，函数内部会 memset）。
 * 返回：无。
 * 时序/边界：纯计算；每 50 ms tick 调用一次，开销可忽略。
 * 注意：优先级 = 故障 > 无基线 > 判别状态；这样"拿不准/坏了"永远显示安全侧语义。
 */
static void disp_build_page(const pipeline_out_t *p_out, const decision_out_t *p_dec,
                            disp_page_t *p_page)
{
    (void)memset(p_page, 0, sizeof(*p_page));
    disp_fmt_header(p_page->header, (uint32_t)sizeof(p_page->header), p_out);

    /* ---------- ① 故障：优先于一切（与 decision.c 的 fault 判据一致） ---------- */
    if (disp_is_fault(p_out))
    {
        p_page->big0    = (uint8_t)OLED_HZ32_GU;      /* 故 */
        p_page->big1    = (uint8_t)OLED_HZ32_ZHANG;   /* 障 */
        p_page->inverse = false;                      /* 故障用正显（反显留给"污水"） */
        disp_copy(p_page->line2, (uint32_t)sizeof(p_page->line2), "L1 SENSOR_FAULT");
        disp_fmt_note(p_page->line3, (uint32_t)sizeof(p_page->line3), p_out->note);
        return;
    }

    /* ---------- ② 无基线：基线采集中显示进度，否则提示重采 ---------- */
    if (!p_out->baseline_valid)
    {
        uint16_t n = p_out->baseline_n;

        if ((n > 0U) && (n < DISPLAY_BASELINE_TOTAL))
        {
            /* 采集中：大字"待机"，第二行给进度（这是"屏还活着"的实时证据） */
            p_page->big0 = (uint8_t)OLED_HZ32_DAI;    /* 待 */
            p_page->big1 = (uint8_t)OLED_HZ32_JI;     /* 机 */
            (void)snprintf(p_page->line2, (size_t)sizeof(p_page->line2),
                           "BASELINE %2u/%u", (unsigned)n,
                           (unsigned)DISPLAY_BASELINE_TOTAL);
            disp_copy(p_page->line3, (uint32_t)sizeof(p_page->line3),
                      "hold probe in water");
        }
        else
        {
            /* n=0（还没开始）或结算无效（EC0<50 mV）：按"故障"提示，避免误回收 */
            p_page->big0 = (uint8_t)OLED_HZ32_GU;
            p_page->big1 = (uint8_t)OLED_HZ32_ZHANG;
            disp_copy(p_page->line2, (uint32_t)sizeof(p_page->line2), "L1 NO_BASELINE");
            disp_copy(p_page->line3, (uint32_t)sizeof(p_page->line3),
                      "send B in water");
        }
        return;
    }

    /* ---------- ③ 正常：按判别状态映射大字/状态串，第三行给数值 ---------- */
    disp_fmt_numbers(p_page->line3, (uint32_t)sizeof(p_page->line3), p_out);

    switch (p_dec->state)
    {
        case DEC_STATE_CLEAR:
            /* 清水：正显。只有判别器明确给出 L0/可回收 时才出现 */
            p_page->big0 = (uint8_t)OLED_HZ32_QING;   /* 清 */
            p_page->big1 = (uint8_t)OLED_HZ32_SHUI;   /* 水 */
            disp_copy(p_page->line2, (uint32_t)sizeof(p_page->line2), "CLEAR  RECOVER");
            break;

        case DEC_STATE_UNCERTAIN:
            /* 污水（L1 拿不准）：反显，颜色与"清水"区分 */
            p_page->big0    = (uint8_t)OLED_HZ32_WU;  /* 污 */
            p_page->big1    = (uint8_t)OLED_HZ32_SHUI;
            p_page->inverse = true;
            disp_copy(p_page->line2, (uint32_t)sizeof(p_page->line2), "L1 UNCERTAIN");
            break;

        case DEC_STATE_SOAP:
            /* 污水（L2 含皂液特征）：反显（与 L1 同大字，状态串区分等级） */
            p_page->big0    = (uint8_t)OLED_HZ32_WU;
            p_page->big1    = (uint8_t)OLED_HZ32_SHUI;
            p_page->inverse = true;
            disp_copy(p_page->line2, (uint32_t)sizeof(p_page->line2), "L2 SOAP  DRAIN");
            break;

        case DEC_STATE_FLUSH:
            /* 冲洗：事件开头的强制排空段（不是水质结论） */
            p_page->big0 = (uint8_t)OLED_HZ32_CHONG;  /* 冲 */
            p_page->big1 = (uint8_t)OLED_HZ32_XI;     /* 洗 */
            disp_copy(p_page->line2, (uint32_t)sizeof(p_page->line2), "FLUSH  DRAIN");
            break;

        case DEC_STATE_WAIT:
        default:
            /* 无事件：待机。注意这不是水质结论（阀按安全侧排空） */
            p_page->big0 = (uint8_t)OLED_HZ32_DAI;
            p_page->big1 = (uint8_t)OLED_HZ32_JI;
            disp_copy(p_page->line2, (uint32_t)sizeof(p_page->line2), "WAIT   EV:OFF");
            break;
    }
}

/* ============================ 区域重画 ============================ */

/*
 * 函数名：disp_redraw_header
 * 作用：重画页头（先清该 8 行带，再写 6x8 文本，避免旧串尾部残留）。
 * 参数：p_page —— 目标内容。
 * 返回：无。
 * 时序/边界：O(128*8) 显存写，无 I2C。
 * 注意：6x8 文本函数只覆写字符所在列，所以必须自己清整行。
 */
static void disp_redraw_header(const disp_page_t *p_page)
{
    oled_fill_rect(DISP_HEAD_X, DISP_HEAD_Y, OLED_WIDTH, 8U, false);
    oled_text_6x8(DISP_HEAD_X, DISP_HEAD_Y, p_page->header);
}

/*
 * 函数名：disp_redraw_big
 * 作用：重画大字带（y=8..39 整带清黑，再画两个 32x32 汉字）。
 * 参数：p_page —— 目标内容。
 * 返回：无。
 * 时序/边界：清带 128*32 像素 + 两个汉字各 128 字节，无 I2C。
 * 注意：为什么要整带清：开机页在 y=8~23 有 "OLED OK"，大字只覆盖 x=32..95，
 *       若不清带，切换后左侧会残留 "OL" 半个字（现场很容易被误读成屏坏）。
 */
static void disp_redraw_big(const disp_page_t *p_page)
{
    oled_fill_rect(0U, DISP_BIG_Y, OLED_WIDTH, DISP_BIG_BAND_H, false);
    oled_hz32(DISP_BIG_X0, DISP_BIG_Y, (oled_hz32_id_t)p_page->big0, p_page->inverse);
    oled_hz32(DISP_BIG_X1, DISP_BIG_Y, (oled_hz32_id_t)p_page->big1, p_page->inverse);
}

/*
 * 函数名：disp_redraw_line2
 * 作用：重画状态串（先清 16 行带，再写 8x16 文本）。
 * 参数：p_page —— 目标内容。
 * 返回：无。
 * 时序/边界：O(128*16) 显存写，无 I2C。
 * 注意：8x16 文本函数不负责清行尾，必须先 fill_rect，否则 "CLEAR  RECOVER" 变
 *       "L1 UNCERTAIN" 时会残留 "VER" 尾巴。
 */
static void disp_redraw_line2(const disp_page_t *p_page)
{
    oled_fill_rect(DISP_LINE2_X, DISP_LINE2_Y, OLED_WIDTH, 16U, false);
    oled_text_8x16(DISP_LINE2_X, DISP_LINE2_Y, p_page->line2);
}

/*
 * 函数名：disp_redraw_line3
 * 作用：重画数值串（先清该 8 行带，再写 6x8 文本）。
 * 参数：p_page —— 目标内容。
 * 返回：无。
 * 时序/边界：O(128*8) 显存写，无 I2C。
 * 注意：6x8 文本函数只写字符列，行尾旧字符必须靠清行带掉。
 */
static void disp_redraw_line3(const disp_page_t *p_page)
{
    oled_fill_rect(DISP_LINE3_X, DISP_LINE3_Y, OLED_WIDTH, 8U, false);
    oled_text_6x8(DISP_LINE3_X, DISP_LINE3_Y, p_page->line3);
}

/* ============================ 对外接口 ============================ */

/*
 * 函数名：display_init
 * 作用：初始化 OLED 并画开机页（证明 I2C/驱动/字库整条链路可用）。
 * 参数：无。
 * 返回：true=可用；false=不可用（上层只打印一次 WARN）。
 * 时序/边界：约 150 ms（oled_init 上电延时 100 ms + 初始化命令 + 清屏 + 开机页）。
 * 注意：开机页会在屏上保持约 DISPLAY_BOOT_HOLD_MS（800 ms），由 display_task 负责
 *       计时切换，这样上电自检时人能看清 "OLED OK"。
 */
bool display_init(void)
{
    g_shown_once  = false;
    g_first_seen  = false;
    g_first_ms    = 0U;
    g_last_num_ms = 0U;
    g_last_full_ms = 0U;
    g_fail_count  = 0U;
    (void)memset(g_shown_header, 0, sizeof(g_shown_header));
    (void)memset(g_shown_line2, 0, sizeof(g_shown_line2));
    (void)memset(g_shown_line3, 0, sizeof(g_shown_line3));
    g_shown_big0    = 0U;
    g_shown_big1    = 0U;
    g_shown_inverse = false;

    if (!oled_init())
    {
        return false;
    }

    /* 开机页：5 行固定文案，全部 8 像素对齐（字库/文本函数只支持页对齐） */
    oled_clear();                                            /* 全屏黑 + 8 页全脏 */
    oled_text_6x8(0U, 0U,  "RA4M2 WATER JUDGE");
    oled_text_8x16(0U, 8U, "OLED OK");
    oled_text_6x8(0U, 24U, "SSD1306 128x64");
    oled_text_6x8(0U, 32U, "I2C0 0x3C 400kHz");
    oled_text_6x8(0U, 40U, "SENSOR-NODE v1.1");

    if (!oled_flush())
    {
        /* 初始化已成功但首帧失败：按"不可用"返回，让 app 打印 WARN（显示不是安全路径） */
        return false;
    }

    return true;
}

/*
 * 函数名：display_task
 * 作用：把当前判别结果画到屏上（差异刷新 + 200 ms 数值节流 + 1 s 心跳）。
 * 参数：now_ms —— app 时基；p_out/p_dec —— 流水线与判别输出。
 * 返回：true=正常（含本 tick 无需刷新）；false=连续 3 帧失败/屏已丢失。
 * 时序/边界：每 50 ms 调一次；最坏约 25 ms（心跳整屏）；单次失败不阻塞主循环。
 * 注意：本函数不打印——WARN 由 app_main 在第一次收到 false 时打印，避免刷屏。
 */
bool display_task(uint32_t now_ms, const pipeline_out_t *p_out, const decision_out_t *p_dec)
{
    disp_page_t page;
    bool        need_full;
    bool        need_num;
    bool        big_changed;

    /* 屏幕不可用/已丢失：直接返回 false，让 app 的一次性 WARN 生效；不占主循环时间 */
    if (!oled_ready())
    {
        return false;
    }

    if ((NULL == p_out) || (NULL == p_dec))
    {
        return true;   /* 防御：上层还没准备好数据，本 tick 不画 */
    }

    /* 开机页保持：第一次调用记录基准时刻，之后 800 ms 内不覆盖开机页 */
    if (!g_first_seen)
    {
        g_first_seen = true;
        g_first_ms   = now_ms;
    }
    if ((now_ms - g_first_ms) < DISPLAY_BOOT_HOLD_MS)
    {
        return true;
    }

    /* ① 算目标内容，并与上一屏比较，决定重画哪些区域 */
    disp_build_page(p_out, p_dec, &page);

    need_full = (!g_shown_once) || ((now_ms - g_last_full_ms) >= DISPLAY_HEARTBEAT_MS);
    need_num  = need_full || ((now_ms - g_last_num_ms) >= DISPLAY_NUM_PERIOD_MS);
    big_changed = (page.big0 != g_shown_big0) || (page.big1 != g_shown_big1)
               || (page.inverse != g_shown_inverse);

    if (need_full)
    {
        /* 心跳/首帧：整屏重画（顺带清掉开机页残留；也是"屏还活着"的自恢复手段） */
        oled_clear();
        disp_redraw_header(&page);
        disp_redraw_big(&page);
        disp_redraw_line2(&page);
        disp_redraw_line3(&page);
        g_last_full_ms = now_ms;
        g_last_num_ms  = now_ms;
    }
    else
    {
        /* 大字/状态串变化：现场最关心的信息，立即重画（不等 200 ms 节流） */
        if (big_changed)
        {
            disp_redraw_big(&page);
        }
        if (0 != strcmp(page.line2, g_shown_line2))
        {
            disp_redraw_line2(&page);
        }
        /* 数值行：最快 200 ms 一次，避免 50 ms tick 每帧都占 I2C */
        if (need_num)
        {
            disp_redraw_header(&page);
            disp_redraw_line3(&page);
            g_last_num_ms = now_ms;
        }
    }

    /* 缓存"已画出"的内容，供下一帧比较 */
    disp_copy(g_shown_header, (uint32_t)sizeof(g_shown_header), page.header);
    disp_copy(g_shown_line2, (uint32_t)sizeof(g_shown_line2), page.line2);
    disp_copy(g_shown_line3, (uint32_t)sizeof(g_shown_line3), page.line3);
    g_shown_big0    = page.big0;
    g_shown_big1    = page.big1;
    g_shown_inverse = page.inverse;
    g_shown_once    = true;

    /* ② 只刷脏页（oled_flush 内部实现）；连续失败 3 帧才报给上层 */
    if (!oled_flush())
    {
        g_fail_count++;
        if (g_fail_count >= DISPLAY_FAIL_LIMIT)
        {
            return false;
        }
        return true;   /* 前两帧失败先不打扰上层：脏页位保留，下一帧自动重试 */
    }

    g_fail_count = 0U;
    return true;
}

/*
 * 函数名：display_ok
 * 作用：查询显示是否可用。
 * 参数：无。
 * 返回：true=oled 已初始化且未判丢失。
 * 时序/边界：O(1)。
 * 注意：与 oled_ready() 同义，保留此接口是为了让 app_main 不直接依赖 oled.h。
 */
bool display_ok(void)
{
    return oled_ready();
}
