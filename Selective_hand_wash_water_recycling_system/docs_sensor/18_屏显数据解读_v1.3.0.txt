0. 先读这一页：三页怎么切、每个位置是什么
--------------------------------------------------------------------------------
0.1 按键与页码
    K2 短按：P1 水质页 → P2 执行器页 → P3 详情页 → P1（循环）；串口打印
              "# DISPLAY page=n/3 (K2)"。
    K2 长按 ≥1.5 s：重采基线（原功能保留）。
    页号：P1/P2 画在大字带右上角 "1/3"、"2/3"；P3 在首行行首 "P3/3"。
    上电先显示开机页约 0.8 s（含初始化总约 1.6 s），随后默认停在 P1。

0.2 三页分工（演示时的用法）
    P1：给观众/评委看"现在判成什么水"（大字）+ 关键相对量；
    P2：解释"阀到底在回收还是排空、继电器有没有真的吸合、动作了几次、通电多久"；
    P3：被问"依据是什么/阈值多少/事件多久"时切过去；调试与记录时也用 P3。
    屏只是现场指示器，不是安全路径；数据以串口 CSV 与事件行为准。

0.3 读屏顺序（建议）
    先看 P1 大字 → 再看 P2 大字/RLY → 需要解释再切 P3 看 STATE/LEVEL/数值/阈值。
    任何"故障"字样优先于其它内容（故障时判别层强制排空，安全侧）。


1. P1 水质页逐段解读
--------------------------------------------------------------------------------
     ┌──────────────────────────────────────────────┐
     │ EC0=1490 s1.5 T25.3                          │ 页头（6x8）
     │              清 水 / 污 水 / 待 机 ...        │ 大字（32x32 x2）
     │ CLEAR  RECOVER                               │ 第二行（8x16）
     │ dEC+12mV g1.008 N+5                          │ 第三行（6x8）
     └──────────────────────────────────────────────┘

1.1 页头 "EC0=1490 s1.5 T25.3"
    字段     含义                                              单位/说明
    -------  ------------------------------------------------  ----------------------------
    EC0=1490 本底基线 EC0：干净本底水在 25℃ 下的 TDS 电压      mV（整数，四舍五入）
             （温度已补偿到 25℃；不是 ppm！）                 无基线时显示 "EC0=----"
    s1.5     本底噪声 σ（20 点基线的标准差，EC 通道）          mV，一位小数；下限 1.5 mV
                                                              越小越稳；>5 mV 说明水流/接触不稳
    T25.3    当前采用的水温（DS18B20 实测；没有则手输/兜底）   ℃，一位小数；兜底 25.0
    读法：先确认 EC0 是有效数字且 σ 不大，再看后面的 dEC/g/N；EC0=---- 时一切
          相对量都不可信（屏幕会显示故障/无基线提示）。
    注意：屏上不显示"温度来源"；CSV 的 src 列才区分 DS（实测）/MAN（手输）/FIX（兜底）。

1.2 大字（结论层，最重要）
    大字        触发条件（判别层 state）        含义
    ----------  ------------------------------  --------------------------------------------
    清水         CLEAR（L0）                    判定为可回收（本次事件内）
    污水（反显） UNCERTAIN（L1）或 SOAP（L2）   L1 拿不准→排空；L2 含皂液特征→排空；
                                                 反显是为了"一眼看出该排"
    待机         WAIT                           无事件（没按 R/没有自动开始）；此时阀在安全侧排空
    冲洗         FLUSH                          手动 R 后的强制排空段（2 s，冲掉滞留水）
    故障         SENSOR_FAULT / NO_BASELINE     传感器故障或无基线，强制安全侧
    口诀："清水=可收，污水=该排，待机=没开始，冲洗=先放掉，故障=查接线/重采基线"。

1.3 第二行（8x16，状态串）
    字符串              含义
    ------------------  ------------------------------------------------------------
    WAIT   EV:OFF       无事件（与大字待机对应）
    FLUSH  DRAIN        强制排空段（事件开始后 2 s）
    CLEAR  RECOVER      L0：可回收 → 执行器请求回收
    L1 UNCERTAIN        L1：拿不准 → 排空
    L2 SOAP  DRAIN      L2：含皂液特征 → 排空
    BASELINE  8/20      正在采基线：已采 8/20 点（1 s 采完；探头要在本底水中）
    L1 NO_BASELINE      无有效基线 → 故障大字 + 提示按 B/K2 长按重采
    L1 SENSOR_FAULT     传感器故障（ADC 超时/TDS/浊度状态异常）
    注意：这一行是"判别结论 + 动作请求"，不是"阀的实际位置"（实际位置看 P2/P3）。

1.4 第三行 "dEC+12mV g1.008 N+5"（数值组）
    字段        含义                                          单位/缩放
    ----------  --------------------------------------------  --------------------------------
    dEC+12mV    ΔEC = 当前温补 TDS 电压 − EC0                 mV（整数，带符号）
                >0 表示比本底"更导电"（离子更多，常见于皂液/汗液）
    g1.008      g = 当前温补 TDS 电压 / EC0                    1.000=与本底一致；×1000 显示 3 位小数
    N+5         ΔNTU：方向归一化后的浊度相对变化               %（整数，带符号）
                >0=比本底更脏（更浑）；<0=更清；不是 NTU 浊度值
    判读：清水段 dEC 应在 ±几 mV 内、g≈1.000、N 在 ±几 % 内；
          皂液段 dEC 明显正偏（十几~几十 mV）、N 正偏（十几~几十 %）；
          具体门限随本底噪声自适应（见 §4），不要拿固定数字当标尺。


2. P2 执行器页逐段解读
--------------------------------------------------------------------------------
     ┌──────────────────────────────────────────────┐
     │ P2/3 EXEC  MODE:AUTO                         │ 页头
     │              回 收 / 排 空 / 手 动 ...        │ 大字
     │ RECOVER  RLY:ON                              │ 第二行
     │ AUTO CNT:12 ON:5s                            │ 第三行
     └──────────────────────────────────────────────┘

2.1 页头 "P2/3 EXEC MODE:..."
    页头取值              含义
    -------------------  ------------------------------------------------------------
    P2/3 EXEC  MODE:AUTO 自动模式：阀位置由判别结果决定
    P2/3 EXEC MODE:MANUAL 手动覆盖（V1=强制回收 / V0=强制排空）
    P2/3 EXEC  MODE:FAULT 执行器引脚故障（P104 写/回读失败）
    P2/3 EXEC NO VALVE   显示任务没拿到阀数据（旧集成/异常；正常看不到）
    注意：MODE 自动/手动是"请求来源"，大字是"已经执行到的位置"，两者通常一致；
          手动 V1/V0 时以大字/RLY 为准。

2.2 大字（阀的实际位置）
    大字        条件                                    含义
    ----------  --------------------------------------  ------------------------------------
    回收（反显） 阀已执行到回收位（position=RECOVER）     继电器吸合，12V 到阀线圈，换向回收口
    排空        阀已执行到排空位（position=DRAIN）       继电器释放，阀断电，弹簧复位排空口
    手动（反显） 处于手动 V1/V0 覆盖                   方向看第二行 RECOVER/DRAIN 与第三行 V1/V0
    故障        传感器故障 / 引脚故障 / 无基线           安全侧；具体原因看第二行
    待机        基线采集中                            第二行 BASELINING
    优先级：引脚故障 > 传感器故障 > 无基线 > 正常位置显示。

2.3 第二行（8x16）
    字符串              含义
    ------------------  ------------------------------------------------------------
    RECOVER  RLY:ON     实际位置=回收，继电器实际吸合（12V 到阀）
    DRAIN    RLY:OFF    实际位置=排空，继电器实际释放（断电=排空，fail-safe）
    PIN_FAULT           执行器引脚写/回读失败（第三行给 check P104 count=N）
    SENSOR_FAULT        传感器故障（第三行给 note=...，如 ADC_TIMEOUT/TDS_RAIL）
    BASELINING          基线采集中（第三行 hold probe in water）
    NO_BASELINE         无有效基线（第三行 send B in water）
    VALVE NO DATA       没拿到执行器数据（检查 display_task 第 4 参数）
    注意：RLY 是"实际回读后的继电器状态"，不是请求；写失败时不会假装成功。

2.4 第三行（6x8）
    字段              含义                                         单位
    ----------------  --------------------------------------------  ----------------------
    AUTO / V1 / V0    当前模式（V1=手动强制回收，V0=手动强制排空）  —
    CNT:12            累计吸合次数（每次进入回收位 +1；掉电清零）  次
    ON:5s             本次连续吸合已持续时长                        s（整秒）
    故障分支时第三行变成 "check P104 count=N" / "note=..." / "hold probe in water"。
    注意：ON 到 120 s 会被固件强制释放到排空并冷却 10 s（防阀线圈过热）；
          若看到 ON 一直超过 120 s，说明不是本版固件或引脚异常，需排查。

2.5 P2 与判别结论为什么会"不一致"
    - 手动模式（V1/V0）：阀按手动命令，P1 仍显示判别结论；
    - 连续吸合超时（MAX_ON）冷却期：阀被强制排空，判别可能仍要求回收；
    - 传感器故障/无基线：阀在安全侧排空，大字显示故障/待机；
    - 引脚故障：阀可能停在原位置（软件不再写），P2 显示故障。
    答辩口径：P2/P3 的 VALVE/RLY 与串口 "# VALVE" 事件行是"阀实际状态"的权威记录。


3. P3 详情页逐行解读（8 行 6x8；被问参数时切到这页）
--------------------------------------------------------------------------------
    行  屏幕示例                        含义
    --  ------------------------------  ------------------------------------------------------------
    1   P3/3 INFO EV:ON 4.2s           事件状态：ON=事件进行中，后面是已持续时间（0.1 s 精度）；
                                        EV:OFF=当前无事件（待机）。事件从 R 开始或强偏离自动开始，
                                        30 s 超时会自动结束并排空。
    2   STATE:CLEAR LEVEL:L0            判别状态/等级：WAIT/FLUSH/CLEAR/UNCERT/SOAP + L0/L1/L2
    3   VALVE:RECOVER RLY:ON            阀实际逻辑位置 / 继电器实际状态（与 P2 大字/第二行一致）
    4   MODE:AUTO CNT:12                自动或手动（V1/V0）+ 累计吸合次数
    5   dEC:+12mV g:1.008               ΔEC（mV，带符号）/ g（×1000 三位小数，1.000=本底）
    6   dNTU:+5.0% T:25.3C              ΔNTU 相对基线（%，带符号一位小数）/ 水温（℃）
    7   EC0:1490mV s:1.5                本底基线（mV25）/ 本底噪声 σ（mV，一位小数）
    8   d1:8/8% d2:20/25%               当前生效阈值：d1（EC mV / 浊度 %）、d2（EC mV / 浊度 %）
    故障时第 8 行会变成 note=...（如 ADC_TIMEOUT/TDS_RAIL/NTU_RAIL），无基线时变成
    "send B in water"；第 7 行无基线时显示 "EC0:----mV s:---"。
    注意：屏幕数值是"四舍五入后的整数/一位小数"；CSV 里是缩放整数（更精确），
          报告引用以 CSV 为准，屏值只用于现场判断。

3.1 d1/d2 是什么、为什么会变
    - d1 = 进入"可回收"的门限；d2 = 判"明显含皂液"的门限；
    - EC 通道自适应：d1 = max(4σ, 8 mV)，d2 = max(8σ, 20 mV)（σ=本底噪声）；
      本底越稳，门限越低；本底噪声大，门限自动抬高（防止误报）；
    - 浊度通道：d1 = 8%，d2 = 25%（相对基线 AO 电压变化，方向归一化后）；
    - 还有 25% 迟滞：进入/退出用不同阈值，防止阈值附近反复切换；
    - P3 显示的 d1/d2 是"当前生效值"（四舍五入到整数），会随基线 σ 变化——
      如果发现 d2 很大（如 40 mV），先去查 σ 是否过大（水流/气泡/接触）。
    - L0/L1/L2 判定（简化）：
        dEC < d1 且 ΔNTU% < d1_ntu          → L0（CLEAR，可回收）
        dEC > d2 或 ΔNTU% > d2_ntu 或变化率抢先 → L2（SOAP，放弃）
        其余                                 → L1（UNCERTAIN，拿不准，排空）
      再叠加 200 ms 块内 4 采样 3 一致消抖，以及 25% 迟滞。


4. 数值是怎么来的（看懂公式就不容易被"数字跳动"吓到）
--------------------------------------------------------------------------------
    EC0       = 基线采集期间 tds_mv25 的均值（20 点，1 s）；       显示为整数 mV
    σ(EC)     = 基线期间的标准差（有下限 1.5 mV）；                 显示一位小数
    TDS mV25  = 实测 TDS 电压 / (1 + 0.02 × (T − 25))；            屏上不直接显示
    dEC       = EMA 后的 mV25 − EC0；                               显示整数 mV（带符号）
    g         = EMA 后的 mV25 / EC0 × 1000；                        显示 g1.008（3 位小数）
    ΔNTU%     = 方向归一化后的浊度偏离 / ntu0 × 100；               显示整数 %（带符号）
                (方向：清水时 AO 高还是低由模块批次决定，固件用 ntu_clear_high 归一化)
    上面所有量在计算前都做了：每通道 5 次中值 + EMA(α=0.30) 平滑，降低跳动。
    重要：这些都是"相对本底"的量，会随本底水（自来水）不同而变化；
          不是 NTU、不是绝对 ppm；不能写"达标"（红线见 00/08 文档）。

  CNT 增长很快                    阈值附近反复切换/水流波动                  看 P3 d1/d2 与波形；加缓冲/稳定水流

  P1 与 P2 结论不一致              手动覆盖/超时冷却/故障                     看 P2 MODE 与串口 # VALVE；属正常

7. 演示与报告口径（重要）
--------------------------------------------------------------------------------
    ① 屏上"清水/污水"是"本次事件内的判别结论"；"待机"不是水质结论（只是没开始）。
    ② 所有数值都是相对本底：dEC 是 mV 差、N 是相对 %；不写 NTU、不写绝对 ppm、
       不写"达到饮用水/排放标准"。
    ③ P1=判别结论，P2=阀实际执行；两者在手动/冷却/故障时可能不同，答辩以串口
       "# VALVE" 事件行与 CSV 为准。
    ④ 屏只是现场指示器，不是安全路径；屏坏/掉线不影响判别、CSV、LED、阀。
    ⑤ 数据留痕以 115200 串口 CSV（17 列）为准；屏上的数值是四舍五入后的现场读数。


8. 速查表（字段 → 含义 → 单位/范围 → 去向）
--------------------------------------------------------------------------------
  字段/缩写      含义                                单位/范围            看哪里
  -------------  ----------------------------------  ------------------  ----------------
  EC0            本底 TDS 电压（25℃补偿）            mV（整数）          P1 页头、P3 第 7 行
  s / σ          本底噪声（EC）                      mV（一位小数）      P1 页头、P3 第 7 行
  T              水温                                ℃（一位小数）       P1 页头、P3 第 6 行
  dEC            ΔEC（相对本底）                     mV（整数，±999）    P1 第 3 行、P3 第 5 行
  g              EC 比值                             1.000=本底          P1 第 3 行、P3 第 5 行
  N / dNTU       ΔNTU（方向归一化相对变化）          %（整数/一位小数）  P1 第 3 行、P3 第 6 行
  STATE          WAIT/FLUSH/CLEAR/UNCERT/SOAP        —                   P1 第 2 行、P3 第 2 行
  LEVEL          L0/L1/L2                            —                   P3 第 2 行
  ACTION         RECOV/DRAIN（判别动作）             —                   P1 第 2 行、CSV
  VALVE          阀实际位置 RECOVER/DRAIN             —                   P2 大字/第 2 行、P3 第 3 行
  RLY            继电器实际 ON/OFF                   —                   P2 第 2 行、P3 第 3 行
  MODE           AUTO/V1/V0/FAULT                    —                   P2 页头/第 3 行、P3 第 4 行
  CNT            累计吸合次数                        次（0~9999 显示）   P2 第 3 行、P3 第 4 行

  EV             事件状态 + 已持续时长               ON x.xs / OFF       P3 第 1 行
  d1/d2          当前生效的进入/放弃门限             EC mV / 浊度 %      P3 第 8 行
  note           故障/提示代码                      字符串              P3 第 8 行（故障时）
  完整精度/原始值  —                                 缩放整数           串口 CSV（17 列）

9. 快速自问自答（现场最常被问的 5 个问题）
--------------------------------------------------------------------------------
    Q1 "现在算清水还是污水？"        → 看 P1 大字（清水/污水）；污水反显=该排。
    Q2 "阀现在在回收还是排空？"      → 切 P2 看大字与 RLY；P3 第 3 行同义。
    Q3 "为什么判污水？"              → 切 P3：L1 拿不准 / L2 超 d2 / 变化率抢先；
                                       dEC 与 N 超过 d2 是主因。
    Q4 "阈值是多少？"                → P3 第 8 行 d1/d2；EC 自适应（4σ/8σ），浊度 8%/25%。
    Q5 "动作了几次/阀通电多久？"      → P2 第 3 行 CNT/ON；P 状态与 # VALVE 行有更详细记录。
