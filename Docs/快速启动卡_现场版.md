# 快速启动卡（现场版）· 洗手水选择性回收装置

> 打印 A5 放箱内；评委/现场同学按此操作。串口 **115200 8N1**。

## 0. 上电前（30 秒）

- [ ] 腔体**排空**、电极擦干（不要带水冷启动）。
- [ ] 阀断电→排空位；12 V / 5 V 接好；USB-TTL 接好。
- [ ] 下桶/回收桶放好；回收桶贴**绿色**标签，排空桶贴**灰色**标签。

## 1. 上电与自检

1. 上电。OLED 出现 `SELFCHK DRY n/200`；串口 `# AUTOCAL state=DRY`。
2. 等约 10 s：`# DRY OK` → `# AUTOCAL state=WAIT WATER`；OLED `SELFCHK WAIT WATER`。**阀不应吸合。**
3. 注清水，**淹过电极**。约 1 s 后 `# BASELINE start` → `# BASELINE OK ec0=… ratio=…`；OLED `SELFCHK CALIB`。
4. 再等约 8 s：`# GATE regime=MEASURE`；清水约 1.2 s 后 `# STATE to=CLEAR`、`# ACTION RECOV`、`# VALVE pos=RECOVER`。
5. 若显示 `CALIB FAIL: SEND W`：确认电极浸没、水干净，按 **`W`**（或 `B`）手动采基线。

## 2. 演示（每段 30~60 s，大腔体慢）

| 段 | 操作 | 期望 |
|---|---|---|
| 1 | 清水流过 30~60 s | `CLEAR/L0`，阀回收（绿桶） |
| 2 | 加皂液/搓手 30~60 s | `SOAP/L2`，阀排空（灰桶）；串口 `dEC` 上升 |
| 3 | 清水冲洗 30~60 s | `dEC` 回落，`CLEAR/L0`，阀回收 |
| 4 | 关水 | **手动排空**腔体（拔立管/开阀/按 `V0`），等 `DRY`、阀排空 |

> 演示前先跑一遍，确认阀方向：`V1`=回收、`V0`=排空、`VA`=自动。方向反了不要演示，先查继电器极性/换 high/low hex。

## 3. 常用命令

| 命令 | 作用 |
|---|---|
| `H` | 帮助 |
| `G` | 打印工况（regime/valid/浸没/稳定） |
| `P` | 打印实时值（EC/浊度/温度/Δ） |
| `D` | 手动干态指纹（腔体必须空，60 s） |
| `W` / `B` | 手动水中基线（电极必须浸没，2 s） |
| `Z` | 清基线（需重新 `W` 或上电） |
| `V1` / `V0` / `VA` | 手动回收 / 排空 / 自动 |
| `R` / `E` | 事件标记（只影响日志） |

## 4. 故障速查

| 现象 | 先做什么 |
|---|---|
| 一直 `DRY`，注水也不变 | 电极没淹到/水位低；抬高水位；检查电极线；按 `W` |
| `CALIB FAIL: SEND W` | 水没淹到/水在晃/EC0 超 1600；静置后按 `W`；换干净水 |
| 一直 `CLEAR`，但已关水 | 腔体存水、电极仍浸没；**手动排空**；这是大腔体的已知限制 |
| 阀方向反 | 断电；检查继电器 high/low 极性；换对应 hex；不要带反方向演示 |
| 串口无输出 | 检查 USB-TTL/波特率 115200；按 `H`；换线 |
| OLED 花屏/无显示 | 检查 I²C 线；不影响串口演示，先保串口 |

## 5. 一句话口径

> **"没有水中基线就不回收；拿不准就排空。"** 这是安全侧，也是本作品的底线。
