## 二、今晚只有三个优先级（其余都可以不做）

1. **冻版 + 备份 hex**：`v2.8.0-LEVEL-M2g` 与兜底 `v2.7.6-B3` 各拷 3 份（U 盘 / 手机 / 网盘）。→ 见 `04` 第 1 条。
2. **上板 6 条验收**：10 分钟内跑完；任一条不过就换 B3。→ 见 `04` 第 3 条的表。
3. **打印**：报告 ×2、讲稿 ×2、数据卡 ×2、清单 ×1。→ 见 `04` 第 4 条。

> 液位回波排查最多给 25 分钟，恢复不了就接受"液位无效自动回退"，**今晚不改接线、不飞线、不重编**。

## 三、20 分钟能读完的读法

- 前 5 分钟：`01` 的"计时总表" + 第 1 节逐字稿，出声念一遍，掐表。
- 接着 5 分钟：`01` 第 5 节的 10 个数字，遮住右列回忆一遍。
- 再 5 分钟：`05` 的 Q1–Q5 与"禁说清单"，这是最容易被问穿的地方。
- 最后 5 分钟：`04` 的"14:00–17:00 怎么打这一仗"和"A/B/C 预案"。

  - 讲稿 ⑥ 段第 3 条改成"液位是下一步"；

- **P6 曲线来自 M2g 的 00:06 日志**；换 B3 上台时不要用它讲"液位门控"，但可以讲"同一批判据的实测"。

## 六、如果评委只给你 3 分钟

按这个顺序删：先删 P4 的阈值公式细节 → 再删 P5 的工况机细节 → 保留 P2（问题）、P6（证据）、P8（边界）、P9（三句话）。
**证据页和边界页永远不要删**——评委记得住的就这两页。

## 七、这套材料里，哪些话是"不能改"的

| 可以改 | 不能改 |
|---|---|
| 队名、成员、日期、页眉颜色 | 数字（258/305/333、−13~0 mV、+33 mV、1.2 s、500 ms） |
| 讲稿的措辞、口头语 | "相对基线"而不是"绝对阈值"这个说法 |
| PPT 的排版、顺序微调 | "52% 是时间占比不是水量""未标定不说 NTU""不声称达标" |

> 这三条口径是本作品最容易被追问、也最容易加分的地方：**主动说边界，比被问出来强。**
