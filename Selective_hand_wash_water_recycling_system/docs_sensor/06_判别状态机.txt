本文件交付"判别状态机"：把 sensor_pipeline 每 50 ms 给出的一组特征
（ΔEC、ΔNTU%、EC 变化率、基线 σ、ADC/传感器状态）翻译成三个等级和一个动作，
再由 app_main 用它驱动 LED 假执行器 / P104 阀。decision.c 是纯逻辑文件：
不碰 ADC、不碰 1-Wire、不打印、不控阀，因此可以脱离硬件做单元测试
（手工填一个 pipeline_out_t 即可验证状态迁移）。

为什么是"三级"而不是"回收/不回收"两档：
  把"拿不准"单独设为 L1 并一律排空，是本项目最重要的安全侧设计。
  真实洗手水里皂液引起的电导率增量只有数十 μS/cm 量级（实验报告口径：
  小幅、非数量级），一旦阈值附近来回跳，就可能把皂液水送进回收桶；
  所以宁可多排一点，也不赌"大概能回收"。
    L0 = 可回收   → 状态 CLEAR，动作 RECOVER（唯一允许回收的组合）
    L1 = 拿不准   → 状态 UNCERTAIN，动作 DRAIN
    L2 = 含皂液特征 → 状态 SOAP，动作 DRAIN（只讲"含皂液特征的偏离"，不识别成分）

判据（与 spec_design.md 第 6 节逐条对应，代码里每条都有注释）：
  1) 传感器故障 / ADC 超时 / 无基线 → 直接 L1（安全侧），并且"抢先"不等消抖；
  2) 变化率抢先：ec_rate > 40 mV/s 且 |ΔEC| > 5 mV，或浊度变化率 > 50 %/s
     → 立即 L2（皂液到来是阶跃，等 200 ms 消抖就晚了；负向阶跃也按安全侧判 L2）；
  3) 否则按迟滞双阈值分类（浊度方向已由 pipeline 归一化：>0 = 更脏）：
       ΔEC > d2 或 ΔNTU% > d2_ntu            → L2
       ΔEC < d1 且 ΔNTU% < d1_ntu            → L0
       其余（中间带）                          → L1
  4) 块内一致消抖：200 ms 块内 4 个候选、至少 3 个相同才采纳，否则 L1；
     block_samples/block_agree 可配置（上限 8），配置非法时 decision_init 会限幅；
  5) 阈值自适应：σ_ec 由 pipeline 在基线采集时算出，
       d1 = max(4σ, 8 mV)，d2 = max(8σ, 20 mV)，并强制 d2 > d1；
     浊度用相对基线的固定百分比 8% / 25% + 迟滞（没有 NTU 标定，见红线）；
  6) 双阈值迟滞：已经处于 L0 时把 d1 放宽 25% 才离开，已经处于 L2 时把 d2
     收紧 25% 才离开，阈值附近的小抖动只会停在 L1（排空）。

事件（决定"这一次洗手"的边界；无流量计，只能用命令 + 超时）：
  - 手动：串口 R 开始 → 先进入 FLUSH 强制排空 2 s（锈水/滞留水/初始气泡），
    再开始判别；串口 E 结束 → 回 WAIT，动作排空；
  - 自动：auto_start_enable && 无事件 && 基线有效 && 候选 L2 时自动开始；
    直接进判别（不做 FLUSH——没有流量计就无法识别"刚开龙头的 1~2 s"）；
  - 超时：事件超过 30 s 强制结束并排空（防忘关水/积水）。
  WAIT 状态（无事件）一律排空；也就是说，没有手动 R 的场合永远不会回收。

时序与时间预算（项目设想 6.2.1）：
  主循环 tick 50 ms；消抖块 200 ms（4 采样 / 3 一致）；首段排空 2000 ms；
  事件超时 30000 ms；端到端判定延迟争取 ≤1.5 s（报告用实测值，不写"实时"）。

怎么验证这一层（不接水也能做）：
  上电后串口发 P 看状态/阈值/基线；发 R 看 FLUSH→判别，CSV 的 state/level/action
  三列与 PC 端脚本对齐；发 E 回 WAIT；把探头拔出水面应看到 NO_BASELINE（L1）；
  短接/悬空 ADC 通道应看到 SENSOR_FAULT（L1）——所有异常都必须落在"排空"。

已知限制（报告口径，禁止写成能力）：
  - 没有流量计：事件边界靠人按 R/E + 30 s 超时，自动模式只在强偏离时兜底；
  - 阈值默认值全部"待标定"，必须按 08 文档做受控梯度实验后再写死；
  - 变化率抢先用 |ΔEC|，所以"突然变干净"的负向阶跃也会短暂判 L2（安全侧）；
  - 自动事件结束后若水样仍为 L2，下一个 200 ms 块可能重新自动开始事件（设计行为）；
  - 本层不做"识别污染物种类/达标判定"，也不输出 NTU 或绝对 ppm。

/*
 * decision.h —— 三级判别状态机（L0 回收 / L1 拿不准排空 / L2 含皂液排空）
 * ---------------------------------------------------------------------------
 * 判据（与《项目设想》第 6.2 节一致，参数待本队实验标定）：
 *   ① ΔEC（主判据）：ΔEC > d2 → L2；ΔEC < d1 → 可清；中间 → L1；
 *   ② ΔNTU（辅判据）：相对基线偏离百分比，浊度突增同样判 L2；
 *   ③ 变化率抢先：|dΔEC/dt| 超限且绝对跳变足够 → 不等消抖，立即 L2（皂液是阶跃）；
 *   ④ 块内一致：候选等级在 200 ms 块内 4 个采样中 3 个一致才动作（不用长窗口）；
 *   ⑤ 双阈值迟滞：进入/退出用不同阈值，防阈值附近反复切换；
 *   ⑥ 安全侧：无基线、传感器故障、ADC 超时、拿不准 → 一律 L1 排空。
 *
 * 状态：
 *   WAIT       无事件（默认排空；只有"事件"内才可能回收）
 *   FLUSH      手动开始事件后的强制排空段（模拟"刚开龙头 1~2 s 锈水/滞留水"）
 *   CLEAR      L0 可回收
 *   UNCERTAIN  L1 拿不准，排空
 *   SOAP       L2 判定含皂液特征，排空
 *
 * 事件（决定"这次洗手"的边界）：
 *   - 手动：串口 R 开始 / E 结束（无流量计时演示用）；
 *   - 自动：auto_start_enable && 强偏离（L2 候选）时自动开始，直接进判别（不做 FLUSH）；
 *   - 超时：事件持续超过 event_timeout_ms（默认 30 s）强制结束并排空（防积水/忘关）。
 */
#ifndef DECISION_H
#define DECISION_H

#include "sensor_common.h"
#include "sensor_pipeline.h"

#ifdef __cplusplus
extern "C" {
#endif

#define DECISION_MAX_BLOCK_SAMPLES  8U

typedef enum e_decision_state
{
    DEC_STATE_WAIT = 0,   /* 无事件 */
    DEC_STATE_FLUSH,      /* 强制排空段 */
    DEC_STATE_CLEAR,      /* L0 可回收 */
    DEC_STATE_UNCERTAIN,  /* L1 拿不准，排空 */
    DEC_STATE_SOAP        /* L2 含皂液特征，排空 */
} decision_state_t;

typedef enum e_decision_level
{
    DEC_LEVEL_L0 = 0,     /* 可回收 */
    DEC_LEVEL_L1,         /* 拿不准 → 排空（安全侧） */
    DEC_LEVEL_L2          /* 应放弃 → 排空 */
} decision_level_t;

typedef enum e_decision_action
{
    DEC_ACTION_DRAIN = 0, /* 排空（阀不动作/默认位） */
    DEC_ACTION_RECOVER    /* 回收（阀动作位） */
} decision_action_t;

/* 配置：所有默认值在 app_main.c 里给出并附标定说明 */
typedef struct st_decision_cfg
{
    /* EC 阈值（σ 倍数 + 绝对下限，取较大者，单位 mV） */
    float    ec_d1_sigma;        /* 进入"可清"的 σ 倍数，默认 4.0 */
    float    ec_d2_sigma;        /* 判定"含皂液"的 σ 倍数，默认 8.0 */
    float    ec_d1_min_mv;       /* d1 绝对下限，默认 8.0 mV */
    float    ec_d2_min_mv;       /* d2 绝对下限，默认 20.0 mV */
    float    ec_hyst_ratio;      /* EC 回差比例，默认 0.25 */
    /* 浊度阈值（相对基线百分比） */
    float    ntu_d1_pct;         /* 浊度"可清"上限，默认 8.0 % */
    float    ntu_d2_pct;         /* 浊度"明显变脏"阈值，默认 25.0 % */
    float    ntu_hyst_ratio;     /* 浊度回差比例，默认 0.25 */
    /* 变化率抢先触发 */
    float    ec_rate_th_mv_s;    /* ΔEC 变化率阈值，默认 40.0 mV/s */
    float    ec_rate_min_jump_mv;/* 触发所需最小绝对跳变，默认 5.0 mV */
    float    ntu_rate_th_pct_s;  /* 浊度变化率阈值，默认 50.0 %/s */
    /* 时序 */
    uint32_t first_flush_ms;     /* 手动开始事件后的强制排空时长，默认 2000 ms */
    uint32_t block_ms;           /* 消抖时间块长度，默认 200 ms */
    uint8_t  block_samples;      /* 时间块内采样数，默认 4（50 ms × 4） */
    uint8_t  block_agree;        /* 块内一致所需个数，默认 3 */
    uint32_t event_timeout_ms;   /* 事件超时强制结束，默认 30000 ms */
    bool     auto_start_enable;  /* 是否允许强偏离自动开始事件，默认 true */
} decision_cfg_t;

/* 判别器输出（app 打印/控阀用） */
typedef struct st_decision_out
{
    decision_state_t  state;
    decision_level_t  level;
    decision_action_t action;
    bool              event_active;   /* 事件是否进行中 */
    bool              changed;        /* 本次 state/level/action 是否变化（用于打印） */
    float             d1_ec_mv;       /* 当前生效的 d1（随 σ 自适应） */
    float             d2_ec_mv;       /* 当前生效的 d2 */
    float             d1_ntu_pct;     /* 当前生效的浊度 d1 */
    float             d2_ntu_pct;     /* 当前生效的浊度 d2 */
    const char       *reason;         /* 静态原因字符串（见 decision.c） */
} decision_out_t;

/* 判别器句柄（app_main 分配） */
typedef struct st_decision
{
    decision_cfg_t cfg;
    decision_out_t out;
    uint32_t       state_since_ms;
    uint32_t       event_since_ms;
    uint32_t       block_start_ms;
    uint8_t        verdict_ring[DECISION_MAX_BLOCK_SAMPLES];
    uint8_t        verdict_pos;
    uint8_t        verdict_len;
    bool           event_active;
} decision_t;

/* 初始化（p_cfg 必须非 NULL；内部限幅）。 */
void decision_init(decision_t *p_dec, const decision_cfg_t *p_cfg);

/* 手动开始一次事件（命令 R / 演示用）：进入 FLUSH 强制排空段。 */
void decision_start_event(decision_t *p_dec, uint32_t now_ms);

/* 手动结束事件（命令 E）。 */
void decision_end_event(decision_t *p_dec, uint32_t now_ms);

/* 每 50 ms tick 调用一次：输入流水线输出，更新状态/等级/动作。 */
void decision_update(decision_t *p_dec, const sensor_pipeline_t *p_pipe, uint32_t now_ms);

/* 读取最近一次输出（只读）。 */
const decision_out_t *decision_get_out(const decision_t *p_dec);

/* 状态/等级/动作 → 静态字符串（CSV 与日志用）。 */
const char *decision_state_str(decision_state_t state);
const char *decision_level_str(decision_level_t level);
const char *decision_action_str(decision_action_t action);

#ifdef __cplusplus
}
#endif
#endif /* DECISION_H */

/*
 * decision.c —— 三级判别状态机实现（L0 可回收 / L1 拿不准排空 / L2 含皂液特征排空）
 * ---------------------------------------------------------------------------
 * 数据来源：只读 sensor_pipeline 产生的 pipeline_out_t（每个 50 ms tick 一份）。
 *           本文件不碰 ADC / 1-Wire / UART，也不打印——纯逻辑，便于脱离硬件测试
 *           （手工填一个 pipeline_out_t 就能验证状态迁移）。
 * 对外输出：decision_out_t（state / level / action / event_active / changed /
 *           自适应阈值 / reason 静态字符串），app_main 用它控阀、打 LED、写日志。
 *
 * 为什么需要"候选等级 + 块内一致"两段判定：
 *   - 单点判断会被气泡/泡沫/ADC 抖动带偏（实验 2 观察到泡沫段噪声可达 2%）；
 *   - 200 ms 块内 4 个采样、≥3 一致才采纳：既能压掉单点毛刺，又比"长窗口滤波"
 *     延迟小（项目设想 6.2.1 的时间预算：端到端判定争取 ≤1.5 s）；
 *   - 变化率抢先单独处理：皂液到来是"阶跃"，如果等 200 ms 消抖，阀门动作就晚了，
 *     所以 |dΔEC/dt| 超限且跳变足够时立即判 L2（安全侧：先排空再说）。
 *
 * 双阈值迟滞（防阈值附近反复切换）：
 *   - 进入"可清"用 d1、进入"含皂液"用 d2（d1 < d2，中间是 L1 拿不准）；
 *   - 但"保持"当前等级时把边界各放宽 hyst_ratio：
 *       已经是 L0：ΔEC 要涨过 d1*(1+ratio) 才算离开 L0；
 *       已经是 L2：ΔEC 要跌回 d2*(1-ratio) 以下才算离开 L2；
 *   - 这样阈值附近的抖动只会落在 L1（排空，安全侧），不会 CLEAR↔SOAP 来回跳。
 *
 * 阈值自适应（为什么不用死数）：
 *   - σ_ec 由 pipeline 在基线采集时算出来（本底噪声）；d1=max(4σ, 8 mV)、
 *     d2=max(8σ, 20 mV)：水质/探头/供电不同，噪声也不同，死数会要么误报要么漏报；
 *   - 绝对下限防"基线过干净（σ≈0）导致阈值退化为 0"；同时保证 d2 > d1；
 *   - 浊度阈值用相对基线的百分比（固定 8%/25% + 迟滞），因为浊度没有 NTU 标定
 *     （红线：禁止写 NTU / 禁止对标国标），只能做"本底相对变化"。
 *
 * 状态与事件的语义：
 *   WAIT      无事件：动作恒为排空。没有流量计时无法自动识别"刚开龙头的 1~2 s"，
 *             强制排空段只在手动事件里生效，所以没有手动 R 的场合永远不回收。
 *   FLUSH     手动事件开始后的 2 s 强制排空段（锈水/滞留水/初始气泡）；期间排空。
 *   CLEAR     L0：唯一允许"回收"的状态（action=RECOVER）。
 *   UNCERTAIN L1：拿不准/传感器故障/无基线 → 排空（安全侧）。
 *   SOAP      L2：判定为"含皂液特征的偏离" → 排空（不识别污染物种类，红线）。
 *
 * 事件边界：
 *   - 手动：串口 R 开始（进 FLUSH）、E 结束（回 WAIT 排空）；
 *   - 自动：auto_start_enable && 无事件 && 基线有效 && 候选 L2 时自动开始，
 *     直接进判别（不经过 FLUSH，因为没有流量计判断"龙头刚开"）；
 *   - 超时：事件超过 event_timeout_ms（默认 30 s）强制结束并排空（防忘关/积水）。
 *
 * 时序：app_main 每 50 ms 调用一次 decision_update()；
 *       块消抖 200 ms（4 采样）、首段排空 2000 ms、事件超时 30000 ms。
 *
 * 安全侧原则（本文件最重要的设计约定）：
 *   任何"不知道"的情况一律 L1 → UNCERTAIN → DRAIN：
 *     ADC 超时 / 传感器状态非 OK / 基线未建立 / 块内投票不通过 → 全部 L1。
 *   唯一会让阀门回收的是：事件内、块内≥3 票 L0、且传感器与基线都正常。
 * ---------------------------------------------------------------------------
 * 参考：spec_design.md 第 6 节判据表；spec_headers.md 第 6 节接口；
 *       硬件搭建方案 §5.2（上电先排空 / 超时保护）、§7.5（前 1~2 s 排空）。
 */

/* ---------- 小工具 ---------- */
/*
 * 函数名：decision_state_from_level
 * 作用：把"等级"映射成"状态"（L0→CLEAR、L2→SOAP、L1→UNCERTAIN）。
 * 参数：level —— 已采纳的等级。
 * 返回：对应状态；未知值按安全侧返回 UNCERTAIN。
 * 时序/边界：纯函数，无状态。
 * 注意：状态只是对外语义，是否回收由 action 决定（只有 CLEAR→RECOVER）。
 */
static decision_state_t decision_state_from_level(decision_level_t level)
{
    switch (level)
    {
        case DEC_LEVEL_L0:
            return DEC_STATE_CLEAR;

        case DEC_LEVEL_L2:
            return DEC_STATE_SOAP;

        case DEC_LEVEL_L1:
        default:
            return DEC_STATE_UNCERTAIN;
    }
}

/*
 * 函数名：decision_reason_from_level
 * 作用：按采纳等级给出原因字符串（块投票通过时用，避免用"单点样本的原因"误导日志）。
 * 参数：level —— 已采纳的等级。
 * 返回：静态字符串 CLEAN / SOAP_HIGH / UNCERTAIN。
 * 时序/边界：纯函数。
 * 注意：返回的是 static const char *，别处只读。
 */
static const char *decision_reason_from_level(decision_level_t level)
{
    switch (level)
    {
        case DEC_LEVEL_L0:
            return g_reason_clean;

        case DEC_LEVEL_L2:
            return g_reason_soap_high;

        case DEC_LEVEL_L1:
        default:
            return g_reason_uncertain;
    }
}

/*
 * 函数名：decision_reset_block
 * 作用：清空消抖块（投票环形缓冲 + 长度 + 块起点）。
 * 参数：p_dec —— 判别器句柄；now_ms —— 新块的起始时间戳（新块从这里开始计时）。
 * 返回：无。
 * 时序/边界：O(8)，可在 50 ms tick 里随意调用。
 * 注意：事件开始/结束、故障立即切换时都要清块，避免用"旧情境的票"做新决定。
 */
static void decision_reset_block(decision_t *p_dec, uint32_t now_ms)
{
    uint8_t i;

    for (i = 0U; i < (uint8_t)DECISION_MAX_BLOCK_SAMPLES; i++)
    {
        p_dec->verdict_ring[i] = 0U;
    }
    p_dec->verdict_pos    = 0U;
    p_dec->verdict_len    = 0U;
    p_dec->block_start_ms = now_ms;
}

/*
 * 函数名：decision_apply_output
 * 作用：把新计算出的 state/level/action 写入 out，并维护 changed / state_since_ms。
 * 参数：p_dec —— 判别器句柄；state/level/action —— 本次结果；
 *       reason —— 静态原因字符串（可为 NULL，NULL 时用 IDLE）；now_ms —— 当前时间。
 * 返回：无。
 * 时序/边界：changed 只在 state / level / action 三者任一变化时置 true（接口契约）。
 * 注意：state_since_ms 只在"状态"变化时刷新（FLUSH 的 2 s 计时靠它，不能每 tick 重置）。
 */
static void decision_apply_output(decision_t *p_dec, decision_state_t state, decision_level_t level,
                                  decision_action_t action, const char *reason, uint32_t now_ms)
{
    bool changed = false;

    if (p_dec->out.state != state)
    {
        changed = true;
    }
    if (p_dec->out.level != level)
    {
        changed = true;
    }
    if (p_dec->out.action != action)
    {
        changed = true;
    }

    if (p_dec->out.state != state)
    {
        p_dec->state_since_ms = now_ms;   /* 只有状态变化才重新计"当前状态已持续多久" */
    }

    p_dec->out.state       = state;
    p_dec->out.level       = level;
    p_dec->out.action      = action;
    p_dec->out.event_active = p_dec->event_active;
    p_dec->out.changed     = changed;
    p_dec->out.reason      = (NULL != reason) ? reason : g_reason_idle;
}

/*
 * 函数名：decision_update_thresholds
 * 作用：按本底噪声 σ_ec 计算本 tick 生效的 d1/d2（EC 自适应阈值），
 *       并写入 out 供 app_main 打印、供 P 命令查看。
 * 参数：p_dec —— 判别器句柄；p_out —— 流水线输出（提供 ec_sigma_mv）。
 * 返回：无。
 * 时序/边界：每 tick 调用；σ 只在基线有效时有意义（基线无效时流水线给 0，阈值退到下限）。
 * 注意：d1 取 max(ec_d1_sigma*σ, ec_d1_min_mv)，d2 同理且强制 d2 > d1；
 *       浊度阈值固定为配置的百分比（相对基线），同样保证 d2_ntu > d1_ntu。
 */
static void decision_update_thresholds(decision_t *p_dec, const pipeline_out_t *p_out)
{
    float sigma = p_out->ec_sigma_mv;
    float d1;
    float d2;
    float gap;
    float d1_ntu;
    float d2_ntu;

    if (sigma < 0.0f)
    {
        sigma = 0.0f;   /* 防御：σ 为负只可能是上游异常，按 0 处理 */
    }

    /* EC 主判据：相对本底噪声的 σ 倍数 + 绝对下限 */
    d1 = p_dec->cfg.ec_d1_sigma * sigma;
    if (d1 < p_dec->cfg.ec_d1_min_mv)
    {
        d1 = p_dec->cfg.ec_d1_min_mv;
    }

    d2 = p_dec->cfg.ec_d2_sigma * sigma;
    if (d2 < p_dec->cfg.ec_d2_min_mv)
    {
        d2 = p_dec->cfg.ec_d2_min_mv;
    }

    if (d2 <= d1)
    {
        /* 极端配置（σ 很大或下限配置反了）时仍要留出迟滞带，否则 d1/d2 重叠、
         * 迟滞算法会退化；至少留 max(1 mV, d1*迟滞比例) 的间隔。 */
        gap = d1 * p_dec->cfg.ec_hyst_ratio;
        if (gap < 1.0f)
        {
            gap = 1.0f;
        }
        d2 = d1 + gap;
    }

    p_dec->out.d1_ec_mv = d1;
    p_dec->out.d2_ec_mv = d2;

    /* 浊度辅判据：无 NTU 标定，只做"相对本底的百分比变化"（红线：不写 NTU） */
    d1_ntu = p_dec->cfg.ntu_d1_pct;
    d2_ntu = p_dec->cfg.ntu_d2_pct;
    if (d2_ntu <= d1_ntu)
    {
        d2_ntu = d1_ntu + 1.0f;
    }
    p_dec->out.d1_ntu_pct = d1_ntu;
    p_dec->out.d2_ntu_pct = d2_ntu;
}

/*
 * 函数名：decision_classify
 * 作用：用（已按迟滞放宽/收紧的）双阈值对当前特征做三级分类。
 * 参数：p_out —— 流水线输出（ΔEC、ΔNTU%）；
 *       e1_ec/e2_ec —— 本 tick 生效的 EC 下/上边界（可能是放宽后的 d1 / 收紧后的 d2）；
 *       e1_ntu/e2_ntu —— 浊度下/上边界（百分比）；
 *       p_reason —— 输出：本次分类的原因字符串（静态）。
 * 返回：候选等级 L0 / L1 / L2。
 * 时序/边界：纯函数，无状态；输入来自同一 tick 的 pipeline_out_t。
 * 注意：判定顺序是"先脏后净"——只要任一路越过上边界就 L2；两路都在下边界内才 L0；
 *       其余（一路高一路低、或都在中间带）一律 L1（拿不准=排空）。
 */
static decision_level_t decision_classify(const pipeline_out_t *p_out,
                                          float e1_ec, float e2_ec,
                                          float e1_ntu, float e2_ntu,
                                          const char **p_reason)
{
    /* ① 先判"明显脏"：EC 或浊度任一越过上边界 → L2（安全侧，宁可排空） */
    if ((p_out->d_ec_mv > e2_ec) || (p_out->d_ntu_pct > e2_ntu))
    {
        *p_reason = g_reason_soap_high;
        return DEC_LEVEL_L2;
    }

    /* ② 再判"可清"：两路都必须落在下边界内（ΔEC 小 且 ΔNTU 小）→ L0 */
    if ((p_out->d_ec_mv < e1_ec) && (p_out->d_ntu_pct < e1_ntu))
    {
        *p_reason = g_reason_clean;
        return DEC_LEVEL_L0;
    }

    /* ③ 其余是中间带（例如 EC 略高但浊度正常、或两路都只是轻微偏离）→ L1 */
    *p_reason = g_reason_uncertain;
    return DEC_LEVEL_L1;
}

/*
 * 函数名：decision_block_update
 * 作用：块内一致消抖——把本 tick 的候选等级压入 200 ms 块，块满/到时后投票，
 *       某一等级票数 ≥ block_agree 才采纳；否则返回 L1（拿不准=排空）。
 * 参数：p_dec —— 判别器句柄（内部维护环形缓冲与块计时）；
 *       cand —— 本 tick 的候选等级；
 *       now_ms —— 当前时间（块计时、跨 tick 回绕安全）；
 *       p_evaluated —— 输出：本 tick 是否完成了一次块投票（供上层更新 reason）；
 *       p_split —— 输出：本 tick 是否"投票不通过"（供上层写 BLOCK_SPLIT 原因）。
 * 返回：采纳等级（块未结束时返回上一次采纳值，保持输出稳定、不每 tick 抖）。
 * 时序/边界：app_main 每 50 ms 调一次；默认 block_ms=200、block_samples=4、agree=3，
 *             即"4 个样本里 3 个一致"，最坏多等 200 ms（在 1.5 s 预算内）。
 * 注意：环形缓冲上限 DECISION_MAX_BLOCK_SAMPLES=8，decision_init 会把配置限幅到 ≤8；
 *       块计时从"块内第一个样本"开始，避免空闲很久后第一个样本就立即到期。
 */
static decision_level_t decision_block_update(decision_t *p_dec, decision_level_t cand,
                                              uint32_t now_ms, bool *p_evaluated, bool *p_split)
{
    uint8_t i;
    uint8_t count_l0;
    uint8_t count_l1;
    uint8_t count_l2;
    uint8_t best_count;
    decision_level_t best_level;
    bool evaluate = false;

    *p_evaluated = false;
    *p_split     = false;

    if (0U == p_dec->verdict_len)
    {
        p_dec->block_start_ms = now_ms;   /* 新块：从第一个样本开始计 200 ms */
    }

    if (p_dec->verdict_pos >= (uint8_t)DECISION_MAX_BLOCK_SAMPLES)
    {
        p_dec->verdict_pos = 0U;   /* 防御：正常流程到不了（上限 8 且满即投票） */
    }

    p_dec->verdict_ring[p_dec->verdict_pos] = (uint8_t)cand;
    p_dec->verdict_pos++;
    p_dec->verdict_len++;

    if ((p_dec->verdict_len >= p_dec->cfg.block_samples) ||
        ((uint32_t)(now_ms - p_dec->block_start_ms) >= p_dec->cfg.block_ms))
    {
        evaluate = true;
    }

    if (!evaluate)
    {
        return p_dec->out.level;   /* 块未结束：保持上次采纳等级（输出稳定） */
    }

    /* 投票：块内 block_samples 个候选里数票 */
    count_l0 = 0U;
    count_l1 = 0U;
    count_l2 = 0U;
    for (i = 0U; i < p_dec->verdict_len; i++)
    {
        switch (p_dec->verdict_ring[i])
        {
            case DEC_LEVEL_L0:
                count_l0++;
                break;

            case DEC_LEVEL_L2:
                count_l2++;
                break;

            case DEC_LEVEL_L1:
            default:
                count_l1++;   /* 非法值也按"拿不准"计票（安全侧） */
                break;
        }
    }

    best_level = DEC_LEVEL_L1;
    best_count = count_l1;
    if (count_l0 > best_count)
    {
        best_level = DEC_LEVEL_L0;
        best_count = count_l0;
    }
    if (count_l2 > best_count)
    {
        best_level = DEC_LEVEL_L2;
        best_count = count_l2;
    }

    /* 块结束：无论通过与否都要清块，下一块重新投票 */
    p_dec->verdict_len    = 0U;
    p_dec->verdict_pos    = 0U;
    p_dec->block_start_ms = now_ms;
    *p_evaluated          = true;

    if (best_count >= p_dec->cfg.block_agree)
    {
        return best_level;
    }

    /* 票数不够（例如 2:2 或 1:1:1）→ 拿不准 → L1 排空（安全侧） */
    *p_split = true;
    return DEC_LEVEL_L1;
}

/* ---------- 对外接口 ---------- */
/*
 * 函数名：decision_init
 * 作用：保存/限幅配置，清零运行时状态，把输出置为安全初值（WAIT / L1 / DRAIN）。
 * 参数：p_dec —— 判别器句柄（app_main 静态分配，禁止 NULL）；
 *       p_cfg —— 配置（可为 NULL，NULL 时用本文件的默认配置）。
 * 返回：无。
 * 时序/边界：上电调用一次即可；可重复调用（会重置全部运行时状态）。
 * 注意：这里对配置做"防御性限幅"——即使有人在 app_main 里写错参数（0、负数、
 *       block_agree > block_samples），也必须保证状态机不会"永远触发/永远不触发"。
 */
void decision_init(decision_t *p_dec, const decision_cfg_t *p_cfg)
{
    decision_cfg_t *p_c;
    uint8_t i;

    if (NULL == p_dec)
    {
        return;
    }

    p_dec->cfg = (NULL != p_cfg) ? *p_cfg : g_default_cfg;
    p_c = &p_dec->cfg;

    /* --- EC 阈值参数：全部限幅到"物理上说得通"的区间 --- */
    p_c->ec_d1_sigma   = sensor_clampf(p_c->ec_d1_sigma, 0.5f, 20.0f);
    p_c->ec_d2_sigma   = sensor_clampf(p_c->ec_d2_sigma, 1.0f, 40.0f);
    if (p_c->ec_d2_sigma <= p_c->ec_d1_sigma)
    {
        p_c->ec_d2_sigma = p_c->ec_d1_sigma * 2.0f;
    }

    p_c->ec_d1_min_mv  = sensor_clampf(p_c->ec_d1_min_mv, 0.5f, 1000.0f);
    p_c->ec_d2_min_mv  = sensor_clampf(p_c->ec_d2_min_mv, 1.0f, 2000.0f);
    if (p_c->ec_d2_min_mv <= p_c->ec_d1_min_mv)
    {
        p_c->ec_d2_min_mv = p_c->ec_d1_min_mv * 2.0f;
    }
    p_c->ec_hyst_ratio = sensor_clampf(p_c->ec_hyst_ratio, 0.0f, 0.8f);

    /* --- 浊度阈值（相对基线的百分比）：同样保证 d2 > d1 --- */
    p_c->ntu_d1_pct    = sensor_clampf(p_c->ntu_d1_pct, 0.5f, 200.0f);
    p_c->ntu_d2_pct    = sensor_clampf(p_c->ntu_d2_pct, 1.0f, 500.0f);
    if (p_c->ntu_d2_pct <= p_c->ntu_d1_pct)
    {
        p_c->ntu_d2_pct = p_c->ntu_d1_pct * 2.0f;
    }
    p_c->ntu_hyst_ratio = sensor_clampf(p_c->ntu_hyst_ratio, 0.0f, 0.8f);

    /* --- 变化率抢先阈值：必须为正，否则等于每个 tick 都触发 --- */
    p_c->ec_rate_th_mv_s     = sensor_clampf(p_c->ec_rate_th_mv_s, 1.0f, 100000.0f);
    p_c->ec_rate_min_jump_mv = sensor_clampf(p_c->ec_rate_min_jump_mv, 0.5f, 1000.0f);
    p_c->ntu_rate_th_pct_s   = sensor_clampf(p_c->ntu_rate_th_pct_s, 1.0f, 100000.0f);

    /* --- 时序参数：块长至少覆盖 block_samples 个 50 ms tick，否则永远凑不齐一致票 --- */
    if (p_c->block_ms < 50U)
    {
        p_c->block_ms = 50U;
    }
    if (p_c->block_ms > 5000U)
    {
        p_c->block_ms = 5000U;
    }
    if (p_c->block_samples < 1U)
    {
        p_c->block_samples = 1U;
    }
    if (p_c->block_samples > (uint8_t)DECISION_MAX_BLOCK_SAMPLES)
    {
        p_c->block_samples = (uint8_t)DECISION_MAX_BLOCK_SAMPLES;
    }
    if (p_c->block_agree < 1U)
    {
        p_c->block_agree = 1U;
    }
    if (p_c->block_agree > p_c->block_samples)
    {
        p_c->block_agree = p_c->block_samples;
    }
    if ((uint32_t)p_c->block_samples * 50U > p_c->block_ms)
    {
        p_c->block_ms = (uint32_t)p_c->block_samples * 50U;   /* 前提：decision_update 每 50 ms 一次 */
    }

    if (p_c->first_flush_ms > 60000U)
    {
        p_c->first_flush_ms = 60000U;
    }
    if (p_c->event_timeout_ms < 1000U)
    {
        p_c->event_timeout_ms = 1000U;
    }
    if (p_c->event_timeout_ms > 600000U)
    {
        p_c->event_timeout_ms = 600000U;
    }
    if (p_c->event_timeout_ms <= p_c->first_flush_ms)
    {
        p_c->event_timeout_ms = p_c->first_flush_ms + 1000U;   /* 超时必须晚于首段排空 */
    }

    /* --- 运行时状态清零 --- */
    p_dec->state_since_ms = 0U;
    p_dec->event_since_ms = 0U;
    p_dec->event_active   = false;
    p_dec->verdict_pos    = 0U;
    p_dec->verdict_len    = 0U;
    p_dec->block_start_ms = 0U;
    for (i = 0U; i < (uint8_t)DECISION_MAX_BLOCK_SAMPLES; i++)
    {
        p_dec->verdict_ring[i] = 0U;
    }

    /* --- 输出初值：安全侧 WAIT/L1/DRAIN；changed=true 让上电第一帧日志可打印 --- */
    p_dec->out.state        = DEC_STATE_WAIT;
    p_dec->out.level        = DEC_LEVEL_L1;
    p_dec->out.action       = DEC_ACTION_DRAIN;
    p_dec->out.event_active = false;
    p_dec->out.changed      = true;
    p_dec->out.d1_ec_mv     = p_c->ec_d1_min_mv;
    p_dec->out.d2_ec_mv     = p_c->ec_d2_min_mv;
    p_dec->out.d1_ntu_pct   = p_c->ntu_d1_pct;
    p_dec->out.d2_ntu_pct   = p_c->ntu_d2_pct;
    p_dec->out.reason       = g_reason_idle;
}

/*
 * 函数名：decision_start_event
 * 作用：手动开始一次"洗手事件"（串口 R）：进入 FLUSH 强制排空段。
 * 参数：p_dec —— 判别器句柄；now_ms —— 当前时间（事件计时起点）。
 * 返回：无。
 * 时序/边界：下一次 decision_update 起，FLUSH 保持 first_flush_ms（默认 2000 ms）；
 *             若事件已在进行中，本函数等价于"重新开始"（重新计 2 s 与 30 s 超时）。
 * 注意：FLUSH 期间 level 固定 L1、action 固定 DRAIN（还没判别，绝不允许回收）。
 */
void decision_start_event(decision_t *p_dec, uint32_t now_ms)
{
    if (NULL == p_dec)
    {
        return;
    }

    p_dec->event_active   = true;
    p_dec->event_since_ms = now_ms;
    decision_reset_block(p_dec, now_ms);

    decision_apply_output(p_dec, DEC_STATE_FLUSH, DEC_LEVEL_L1, DEC_ACTION_DRAIN,
                          g_reason_manual_start, now_ms);

    /* 重复按 R 时 state 已经是 FLUSH，apply 不会刷新 state_since_ms；
     * 手动重启必须重新计 2 s 排空，所以这里显式重置。 */
    p_dec->state_since_ms = now_ms;
}

/*
 * 函数名：decision_end_event
 * 作用：手动结束事件（串口 E）：回 WAIT，动作排空；清块避免旧票干扰下一次事件。
 * 参数：p_dec —— 判别器句柄；now_ms —— 当前时间。
 * 返回：无。
 * 时序/边界：幂等——没有事件时调用也只会把状态压回 WAIT/L1/DRAIN。
 * 注意：结束事件不等于"关阀"：WAIT 本来就是排空位（fail-safe 默认）。
 */
void decision_end_event(decision_t *p_dec, uint32_t now_ms)
{
    if (NULL == p_dec)
    {
        return;
    }

    p_dec->event_active   = false;
    p_dec->event_since_ms = now_ms;
    decision_reset_block(p_dec, now_ms);
    decision_apply_output(p_dec, DEC_STATE_WAIT, DEC_LEVEL_L1, DEC_ACTION_DRAIN,
                          g_reason_event_end, now_ms);
}

/*
 * 函数名：decision_update
 * 作用：每 50 ms 调用一次的判别主函数：读 pipeline 输出 → 健康检查 → 变化率抢先
 *       → 迟滞分类 → 块内一致 → 事件管理 → 状态/动作输出。
 * 参数：p_dec —— 判别器句柄；p_pipe —— 流水线句柄（只读，用 pipeline_get_out 取输出）；
 *       now_ms —— 当前时间（时基 ms，跨回绕安全）。
 * 返回：无（结果在 p_dec->out，app_main 用 decision_get_out 读取）。
 * 时序/边界：一个 tick 内最多一次块投票；抢先路径（故障/无基线/变化率）不等消抖；
 *             事件超时从 event_since_ms 起算（不受状态切换影响）。
 * 注意：本函数不做任何硬件操作、不打印；所有"不知道"的情况都走 L1（安全侧）。
 *       自动开始只在 auto_start_enable && 无事件 && 基线有效 && 采纳等级 L2 时发生。
 */
void decision_update(decision_t *p_dec, const sensor_pipeline_t *p_pipe, uint32_t now_ms)
{
    const pipeline_out_t *p_out;
    decision_level_t cand;
    decision_level_t adopted;
    decision_state_t new_state;
    decision_level_t new_level;
    decision_action_t new_action;
    const char *reason;
    bool fault;
    bool preempt;
    float d1_ec;
    float d2_ec;
    float d1_ntu;
    float d2_ntu;
    float e1_ec = 0.0f;
    float e2_ec = 0.0f;
    float e1_ntu = 0.0f;
    float e2_ntu = 0.0f;
    float ntu0_mv = 0.0f;
    float ntu_rate_pct_s = 0.0f;

    if ((NULL == p_dec) || (NULL == p_pipe))
    {
        return;
    }

    p_out = pipeline_get_out(p_pipe);
    if (NULL == p_out)
    {
        return;
    }

    /* ---------- ① 自适应阈值（每 tick 更新：σ 变了阈值跟着变） ---------- */
    decision_update_thresholds(p_dec, p_out);
    d1_ec  = p_dec->out.d1_ec_mv;
    d2_ec  = p_dec->out.d2_ec_mv;
    d1_ntu = p_dec->out.d1_ntu_pct;
    d2_ntu = p_dec->out.d2_ntu_pct;

    /* ---------- ② 传感器/基线健康检查（安全侧，优先于一切判据） ---------- */
    /* 任何一路状态非 OK（ADC 贴轨/开路/数据不可信）或本 tick ADC 超时 → 立即 L1。 */
    fault = p_out->adc_timeout
         || (SENSOR_OK != p_out->tds_status)
         || (SENSOR_OK != p_out->ntu_status);

    preempt = false;
    cand    = DEC_LEVEL_L1;
    reason  = g_reason_idle;

    if (fault)
    {
        /* 故障不等消抖：等 200 ms 可能已经处于回收状态，这是安全侧问题 */
        cand    = DEC_LEVEL_L1;
        reason  = g_reason_sensor_fault;
        preempt = true;
    }
    else if (!p_out->baseline_valid)
    {
        /* 没有本底基线，就不知道"现在比本底脏多少"：上电校准/命令 B 期间一律排空 */
        cand    = DEC_LEVEL_L1;
        reason  = g_reason_no_baseline;
        preempt = true;
    }
    else
    {
        /* ---------- ③ 变化率抢先（皂液/突发污水是阶跃，值得抢在消抖之前动作） ---------- */
        ntu0_mv        = (float)p_out->ntu0_ao_mv;
        ntu_rate_pct_s = 0.0f;
        if (ntu0_mv > 1.0f)
        {
            /* pipeline 的 ntu_rate 单位是 mV/s；换算成"相对基线的 %/s"与配置单位统一。
             * 方向已在 pipeline 归一化（>0 = 越来越脏），所以正向速率才触发。 */
            ntu_rate_pct_s = (p_out->ntu_rate_mv_s * 100.0f) / ntu0_mv;
        }

        if ((p_out->ec_rate_mv_s > p_dec->cfg.ec_rate_th_mv_s) &&
            (sensor_absf(p_out->d_ec_mv) > p_dec->cfg.ec_rate_min_jump_mv))
        {
            /* 注意：按接口约定用 |ΔEC|，所以"突然变干净"的负向阶跃也会抢判 L2。
             * 这是故意的安全侧取舍（宁可排空）；若实测扰民，调大
             * ec_rate_min_jump_mv（或抬高 ntu_rate 阈值），见 08 文档标定步骤。 */
            cand    = DEC_LEVEL_L2;
            reason  = g_reason_rate_jump;
            preempt = true;
        }
        else if (ntu_rate_pct_s > p_dec->cfg.ntu_rate_th_pct_s)
        {
            cand    = DEC_LEVEL_L2;
            reason  = g_reason_rate_jump;
            preempt = true;
        }
        else
        {
            /* ---------- ④ 双阈值迟滞分类 ---------- */
            /* 保持当前等级时放宽"离开边界"：已在 L0 则 d1 放大，已在 L2 则 d2 收缩；
             * 阈值附近的小抖动只会让结果停在 L1（排空），不会 CLEAR↔SOAP 反复跳。 */
            bool hold_clean = p_dec->event_active && (DEC_STATE_CLEAR == p_dec->out.state);
            bool hold_soap  = p_dec->event_active && (DEC_STATE_SOAP == p_dec->out.state);

            e1_ec  = hold_clean ? (d1_ec * (1.0f + p_dec->cfg.ec_hyst_ratio)) : d1_ec;
            e2_ec  = hold_soap  ? (d2_ec * (1.0f - p_dec->cfg.ec_hyst_ratio)) : d2_ec;
            e1_ntu = hold_clean ? (d1_ntu * (1.0f + p_dec->cfg.ntu_hyst_ratio)) : d1_ntu;
            e2_ntu = hold_soap  ? (d2_ntu * (1.0f - p_dec->cfg.ntu_hyst_ratio)) : d2_ntu;

            /* 交叉保护：极端配置下放宽后的边界可能越过另一侧，夹回来保证 e1<=e2 */
            if (e1_ec > e2_ec)
            {
                e1_ec = e2_ec;
            }
            if (e1_ntu > e2_ntu)
            {
                e1_ntu = e2_ntu;
            }

            cand = decision_classify(p_out, e1_ec, e2_ec, e1_ntu, e2_ntu, &reason);
        }
    }

    /* ---------- ⑤ 块内一致消抖 ---------- */
    /* 故障/无基线/变化率抢先三条路径都不进消抖（spec §6 规则 1/2 的"立即"要求）。 */
    if (preempt)
    {
        adopted = cand;
        decision_reset_block(p_dec, now_ms);   /* 新块从下一个 tick 重新投票 */
    }
    else
    {
        bool evaluated = false;
        bool split     = false;

        adopted = decision_block_update(p_dec, cand, now_ms, &evaluated, &split);
        if (evaluated)
        {
            if (split)
            {
                reason = g_reason_block_split;   /* 块内不一致 → L1，原因单独标注 */
            }
            else
            {
                /* 块投票通过时用"采纳等级"的原因，避免拿单点样本的原因误导日志 */
                reason = decision_reason_from_level(adopted);
            }
        }
    }

    /* ---------- ⑥ 事件管理与状态映射 ---------- */
    new_state  = DEC_STATE_WAIT;
    new_level  = DEC_LEVEL_L1;
    new_action = DEC_ACTION_DRAIN;

    if (p_dec->event_active)
    {
        if ((uint32_t)(now_ms - p_dec->event_since_ms) >= p_dec->cfg.event_timeout_ms)
        {
            /* 超时兜底：防忘关水/积水；结束事件并强制排空 */
            p_dec->event_active = false;
            decision_reset_block(p_dec, now_ms);
            new_state  = DEC_STATE_WAIT;
            new_level  = DEC_LEVEL_L1;
            new_action = DEC_ACTION_DRAIN;
            reason     = g_reason_timeout;
        }
        else if ((DEC_STATE_FLUSH == p_dec->out.state) &&
                 ((uint32_t)(now_ms - p_dec->state_since_ms) < p_dec->cfg.first_flush_ms))
        {
            /* 强制排空段还没走完：保持 FLUSH + 排空，不做判别 */
            new_state  = DEC_STATE_FLUSH;
            new_level  = DEC_LEVEL_L1;
            new_action = DEC_ACTION_DRAIN;
            reason     = g_reason_flush;
        }
        else
        {
            /* 事件内：等级→状态；只有 CLEAR 允许回收，其余（含 L1）一律排空 */
            new_state  = decision_state_from_level(adopted);
            new_level  = adopted;
            new_action = (DEC_STATE_CLEAR == new_state) ? DEC_ACTION_RECOVER : DEC_ACTION_DRAIN;
        }
    }
    else
    {
        /* 无事件：默认排空。自动模式只对"强偏离 L2"自动开始，且直接进判别（不 FLUSH） */
        if (p_dec->cfg.auto_start_enable && (!fault) && p_out->baseline_valid &&
            (DEC_LEVEL_L2 == adopted))
        {
            p_dec->event_active   = true;
            p_dec->event_since_ms = now_ms;
            decision_reset_block(p_dec, now_ms);
            new_state  = DEC_STATE_SOAP;
            new_level  = DEC_LEVEL_L2;
            new_action = DEC_ACTION_DRAIN;
            reason     = g_reason_auto_start;
        }
        else
        {
            /* WAIT 时 level 只作"候选诊断"上报（CSV 可看），动作恒为排空；
             * 没有手动 R 的场合永远不回收（没有流量计识别不了"刚开龙头"）。 */
            new_state  = DEC_STATE_WAIT;
            new_level  = adopted;
            new_action = DEC_ACTION_DRAIN;
            /* reason 沿用上面的分类结果（CLEAN/UNCERTAIN/SOAP_HIGH/...） */
        }
    }

    /* ---------- ⑦ 输出：changed 只在 state/level/action 变化时置 true ---------- */
    decision_apply_output(p_dec, new_state, new_level, new_action, reason, now_ms);
}

/*
 * 函数名：decision_get_out
 * 作用：返回最近一次判别输出的只读指针。
 * 参数：p_dec —— 判别器句柄。
 * 返回：指向内部 out 的指针；p_dec 为 NULL 时返回 NULL。
 * 时序/边界：只读；调用方不得修改内容，也不得在 p_dec 生命周期外保存该指针。
 * 注意：app_main 每个 tick 用它打印 CSV / 事件日志。
 */
const decision_out_t *decision_get_out(const decision_t *p_dec)
{
    if (NULL == p_dec)
    {
        return NULL;
    }
    return &p_dec->out;
}

/*
 * 函数名：decision_state_str
 * 作用：状态 → 静态字符串，供 CSV 的 state 列与日志使用。
 * 参数：state —— 状态枚举。
 * 返回："WAIT" / "FLUSH" / "CLEAR" / "UNCERT" / "SOAP"（未知值按 UNCERT）。
 * 时序/边界：纯函数；字符串是只读常量，绝不返回 NULL。
 * 注意：这里刻意用短词 UNCERT（不是枚举名 UNCERTAIN），与 00/07 文档约定的
 *       CSV 取值（WAIT/FLUSH/CLEAR/UNCERT/SOAP）逐字一致，PC 端脚本直接匹配。
 */
const char *decision_state_str(decision_state_t state)
{
    switch (state)
    {
        case DEC_STATE_WAIT:
            return "WAIT";

        case DEC_STATE_FLUSH:
            return "FLUSH";

        case DEC_STATE_CLEAR:
            return "CLEAR";

        case DEC_STATE_SOAP:
            return "SOAP";

        case DEC_STATE_UNCERTAIN:
        default:
            return "UNCERT";
    }
}

/*
 * 函数名：decision_level_str
 * 作用：等级 → 静态字符串 L0/L1/L2（CSV 的 level 列、日志用）。
 * 参数：level —— 等级枚举。
 * 返回："L0" / "L1" / "L2"（未知值按 L1 安全侧）。
 * 时序/边界：纯函数，不返回 NULL。
 * 注意：与文档字段取值一致，PC 端脚本按 "L0"/"L1"/"L2" 解析。
 */
const char *decision_level_str(decision_level_t level)
{
    switch (level)
    {
        case DEC_LEVEL_L0:
            return "L0";

        case DEC_LEVEL_L2:
            return "L2";

        case DEC_LEVEL_L1:
        default:
            return "L1";
    }
}

/*
 * 函数名：decision_action_str
 * 作用：动作 → 静态字符串（CSV 的 action 列、# ACTION 事件行用）。
 * 参数：action —— 动作枚举。
 * 返回："RECOV" / "DRAIN"（未知值按 DRAIN 安全侧）。
 * 时序/边界：纯函数，不返回 NULL。
 * 注意：刻意用短词 RECOV（不是枚举名 RECOVER），与 CSV 协议取值逐字一致。
 */
const char *decision_action_str(decision_action_t action)
{
    switch (action)
    {
        case DEC_ACTION_RECOVER:
            return "RECOV";

        case DEC_ACTION_DRAIN:
        default:
            return "DRAIN";
    }
}
