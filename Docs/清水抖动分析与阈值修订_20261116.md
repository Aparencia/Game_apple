## 2. 清水为什么抖

### 2.1 现象

```
CLEAR 0.8~3.2 s → UNCERT 1.4~1.6 s → CLEAR 0.8~1.2 s → …（周期 ≈2.2 s）
25 s 内 19 次阀换向（9 次回收吸合），继电器计数 36→45
```

### 2.2 机制

把 ΔEC 与阀位对齐：

| 阀动作后 0.5~3 s 窗口 | ΔEC 均值 |
|---|---|
| 切到 RECOVER | **+6.1 mV** |
| 切到 DRAIN | **−1.5 mV** |

即 **阀换向改变探头周围流场/水团，EC 跟着漂 +6~+16 mV**，不是水真的变脏。循环链路：

1. 切回收 → ΔEC 在约 1.5 s 内升到 +10~+16 mV；
2. 固定 `d1=8 mV`（`max(4σ,8)`）只相当于 EC0 的 **2.3%**，而漂移是 **5%**；
3. 保持 CLEAR 的退出边界 `1.25×d1≈10 mV` 被越过 → 候选 L1；
4. 400 ms 块投票通过 → 立即降 L1 / 排空；
5. 排空后 ΔEC 在 0.4 s 内回落到 ≈0，但升级回 L0 要连续 3 块（1.2 s）→ 多排 1.4 s 清水；
6. 回到 CLEAR，流场再次把 ΔEC 抬起来 → 重复。

两个放大器：

- **400 ms 换向屏蔽只覆盖电磁瞬态**；实测水力瞬态持续 **1.5~2 s**；
- **L0→L1 立即生效**，而 L0 升级要 1.2 s，形成一个弛豫振荡器。

### 2.3 肥皂水为什么是好的

- 稳定 `SOAP/L2/DRAIN`，无回收；
- 与清水的间隔：
  - ΔEC：清水最大 +16 → 肥皂最小 +36.9（间隔 21 mV）；
  - ΔNTU：清水最大 −0.3 → 肥皂最小 +8.6（间隔约 9 个百分点，清水噪声仅 ±0.3）。

## 3. v2.2.0 的修订

| # | 改动 | 依据 |
|---|---|---|
| 1 | `d1 = max(4σ, 8mV, **6%×EC0**)`、`d2 = max(8σ, 20mV, **9%×EC0**)` | 348 mV → d1≈20.9、d2≈31.3；清水峰值 16<d1，肥皂 40>d2 |
| 2 | **L0→L1 需连续 2 块（0.8 s）**；L0→L2 仍立即 | 清水 L1 候选只持续约 0.4~0.6 s，一块就过去 |
| 3 | NTU 阈值：`d1=4%`、`d2=8%`（原 8%/25%） | 清水 −1.6%、肥皂 +10.9%；NTU 噪声 ±0.3，比 EC 更能分开两者 |

新增配置项：

| 参数 | 默认 | 位置 |
|---|---|---|
| `ec_d1_pct` | 6.0 % | `decision_cfg_t` |
| `ec_d2_pct` | 9.0 % | `decision_cfg_t` |
| `downgrade_blocks` | 2 | `decision_cfg_t` |
| `ntu_d1_pct` | 4.0 % | `decision_cfg_t` |
| `ntu_d2_pct` | 8.0 % | `decision_cfg_t` |

> 百分比下限为 0/0 时可关闭，回到纯 σ+绝对阈值；改动后重新启动会打印新的
> `# thresholds: ec d1=max(4.0*sigma,8.0mV,6.0%EC0) ...` 行，便于现场核对。

## 5. 现场复验要点

1. 烧录后看启动行：应为 `SENSOR-NODE v2.2.0-THRESH`，并出现新的 `# thresholds: ... 6.0%EC0 ... 9.0%EC0`。
2. 清水稳定后观察 60 s：
   - `# STATE` 应保持 `CLEAR`，不再出现 2 s 周期的 `CLEAR↔UNCERT`；
   - `# VALVE count` 不再持续增长；
   - `# TIP` 里 `dEC` 应在 ±16 mV 内、`dNTU` 为负。
3. 肥皂水：应稳定 `SOAP/L2/DRAIN`；`dNTU` 应 >8%。
4. 空腔：应稳定 `DRY`，阀不动。
5. 若清水又出现偶发 L1，先把 `ec_d1_pct` 调到 7%（或 `downgrade_blocks=3`）再试，**不要**直接回到固定 8 mV。

## 6. 已知限制

1. 6%/9% 是从这一股清水（EC0=348 mV）标出来的；换水样/换探头后应重新按 `# TIP` 的
   ΔEC 峰值与肥皂 ΔEC 回填，不能当通用常数。
2. NTU 的绝对电平在本装置上是“水 > 空气”（空腔 AO≈2241 mV、清水 AO≈2639 mV），
   所以 NTU 只能用于“水中相对变化”，不能用于空气/水判别；v2.1 自检里
   “AO≤干态×98%”的确认在本装置上不成立，属另一个待修项。
3. 400 ms 换向屏蔽仍未覆盖 1.5~2 s 的水力瞬态；本次靠阈值与去抖压住，
   结构项（探头位置/流路，诊断报告 P0-0）仍是根治手段。
