1电路总览 OVERVIEW

1.1 三类连接（20 多根线先分成三类，接线不会乱）

① 电源

Type-C 5V 进板 → 板载 LDO 出 3.3V（U1-12）；5V 外设从 VIN（U2-19/20）取电，与板同开同关；12V 只给阀（本阶段不接）。

② 地

所有模块 GND 汇到“星形单点”，再进板 GND（U1-1/8/16、U2-4/6/11/14/18，共 8 个排针地脚）；阀/继电器大电流地单独走线。

③ 信号

2 路模拟（TDS→P014/AN12、浊度分压→P013/AN11）+ 1 路 1-Wire（DS18B20→P500）+ 板载 I2C0（OLED→P407/P408）+ 板载串口（CH340E→P109/P110）+ 2 路 GPIO（LED1→P111 板载、阀→P104 预留）。

1.4 电气特性与绝对最大（做任何连接前先记住这 5 条）

① 逻辑电平 3.3V除 P206/P407/P408/P409 外，所有 IO 都不是 5V 容忍；模拟输入绝对最大 3.6V，超过即损坏 ADC / 引脚。
② ADC 参考VREFH0 = 板载 3.3V（不用外接基准）；12 位 = 0~4095 对应 0~3.3V，1 LSB ≈ 0.806 mV。
③ ADC 源阻抗 ≤ 1 kΩ这是浊度必须用 1k+2k、不能用“10k+20k”的原因（见 §4.3）。
④ 5V 容忍脚只有 4 个P206（流量计预留）、P407/P408（已给 OLED）、P409（蜂鸣器预留）；其余 5V 信号一律分压或加电平转换。
⑤ 5V 外设只从 VIN 取电与板同开同关；不允许“板断电、外设带电”（会从 IO 倒灌）。
⑥ 板载 LDO 余量3.3V 侧负载约 60~90 mA，板载 LDO（丝印 662K，约 200 mA 级，⏳ 型号待核）；外部取电余量估计 <100 mA，满载实测确认。

2板卡与孔位事实 BOARD & PINOUT

2.1 板卡型号与板载资源 🟢（已按实际板卡原理图 V1.2.1 + 瑞萨数据手册核对）

  • 型号：RA4M2_MINI（R7FA4M2AD3CFL，ARM Cortex-M33，48 脚 LQFP）；
  • 板载：0.96" OLED（SSD1306 兼容，I2C0，0x3C，自带 4.7kΩ 上拉）、CH340E USB-串口（接 SCI9）、 用户 LED1、用户按键 K2、复位键、两排 20 孔排针（记作 U1、U2）、SWD 排针（P300/P108）；

  • 开发板是借的、赛后收回：只接排针/端子，禁止不可逆改造（见 §11 红线）。

3.2 接地：为什么必须星形单点

  • 板上 GND 有 8 个排针地脚（U1-1/8/16、U2-4/6/11/14/18）+ SWD 排针 GND + OLED 座地；本方案只用排针 8 处。
  • 所有模块 GND 先汇到“接线端子排/洞洞板地排”，再用 1 根线进板 GND —— 不要一根一根地“就近插板子” （会形成地环路，ADC 读数跳动、OLED 花屏）。
  • 阀/继电器的电流地单独走一根到端子排，绝不流经开发板地线（大电流会把地电位抬起）。
  • 通电后用万用表通断档确认：每个模块 GND 与板 GND 之间 < 1 Ω。

3.3 去耦与滤波

  • 每个模块电源入口就近并 0.1 µF 瓷片电容到 GND（TDS、DS18B20、浊度模块各 1 只）；
  • 继电器模块 VCC 就近并 100 µF 电解 + 0.1 µF 瓷片（吸合瞬间防拉跌）；
  • 浊度分压节点并 0.1 µF 对地（与 R2 并联，滤高频，见 §4.2）；
  • 探头线/信号线尽量短（≤30 cm 为佳），与 5V 电源线、12V 线分开走，不要捆在一起。

3.4 上电/断电顺序与三条禁令

上电先板（插 USB / 适配器）→ 等自检（LED 快闪 3 下、串口 boot 行）→ 再开 5V 外设。
断电先关 5V 外设 → 再断板。
三条禁令 ① 不要把外部 5V 灌进 VIN 排针同时插 USB（防倒灌）；
② 不要用电脑 USB 与外部 5V 适配器同时给板供电；
③ 板子只有 1 个 Type-C：插 5V 适配器就没有串口（独立演示工况），串口 + 独立供电二选一 （要同时保留可加带供电的 USB HUB，可选）。

4模拟输入电路（两路 ADC） ANALOG

4.1 TDS 通道（P014 / AN12，主判据）：可以直连

TDS 模块端子接到要点

GNDU1-16（或 GND 地排）必须共地

为什么可以直连 模块标称 AOUT 0~2.3V，实测高浓度皂液水最高 2.356V，均 < 3.6V 绝对最大，也 < ADC 满量程 3.3V。 若个别批次输出更高（>3.0V），必须改分压后再接。
TDS 注意 ① 不要给模块接 5V：5V 供电时输出幅度会抬高；若同时给 DS18B20 供 5V，DQ 上拉会变成 5V，超 MCU 耐压。
② AOUT 不是“越大越脏”：不同批次方向可能不同，只做相对判据，不预测方向。
③ 探头可拆洗：每次实验后取下冲洗、甩干；探头不要碰杯壁/杯底（固定深度）。
④ 可选抗干扰（默认不装）：AOUT 对地并 0.1 µF（只并电容、不串电阻，保持源阻抗）。

为什么不能用 10k + 20k 分压比同样是 2/3，但源阻抗 = 6.67 kΩ > 1 kΩ，12 位 ADC 采样会明显偏低且不稳 —— 这是最容易犯的错。
电阻怎么选（别照抄旧版“AO 最大 4.5V / 满量程 5.0V”） 板 VIN 供电（4.5~4.7V）→ AO 上限 ≤4.7V → 保持 R1=1k、R2=2k； 只有改成独立 5.0V 供电（AO 可到 5.0V）时，才把 R2 换 1.5k（节点 3.0V），此时固件 ntu_div_r2_ohm 必须同步改 1500。电阻优先 1% 金属膜；5% 最坏时节点仍 <3.3V 但余量小，务必实测。
⚠ 分压比写死在固件配置里 pipeline_cfg.ntu_div_r1_ohm / ntu_div_r2_ohm，默认 1000 / 2000 —— 换电阻必须同步改这两个值，否则 ao_mv 还原错误。 输出方向以实测为准（常见批次“清水电压高、越浑越低”，也有反相批次）；用 08 文档 T4 做一次清水/浑水对照即可确定，反相才把 ntu_clear_high 改 false。
到货必做两项实测（§8.2 第 11 / 12 项） ① 清水（或空气）下量 A-G 最高电压，得 AO 满量程 → 决定保持 1k+2k 还是换 R2； ② 清水/浑水各量一次 A（或节点）并看串口 ntu_node_mv → 定方向。
VIN 电压注意 本板 VIN 是 USB VBUS 经防反接二极管后的 4.5~4.7V（低于标称 5V）。模块要求 5V，4.5V 一般也能工作（LED 稍暗、AO 整体略低）； 若读数不稳/贴轨，先量 V（VCC）是否 ≥4.5V，必要时用独立 5V 适配器给模块供电（与板共地、同开同关，不能把外部 5V 灌进 VIN）。

4.3 两路 ADC 的共同要求

  • 参考电压：VREFH0 = 板载 3.3V（RASC 默认，不要外接基准）；
  • 采样：两路必须在同一个 Scan Group（AN11 + AN12），一次扫描同时转换，保证 TDS 与浊度“同一时刻”采样（RASC 配置见 00 §4.1）；
  • 源阻抗：任何进 ADC 的信号源阻抗 ≤ 1 kΩ（分压电阻/跟随器要按此选型）；
  • 保护：P013/P014 绝对最大 3.6V；上电前必须先量 AO 最大值（§8.2）；
  • 地：模拟地按 §3.2 星形单点，探头信号线与电源线分开走。

4.4 探头安装与噪声（影响数据质量，接线后立刻检查）

  • TDS 探头与 DS18B20 装在流动池同一水体、同一深度，探头感测面浸入 10~20 mm，不碰壁、不碰底（详见《硬件搭建方案》§7.3 流动池）；
  • 浊度模块的 4 线探头同样固定（感测面浸入 10~20 mm），避开气泡/泡沫聚集处；
  • 气泡/泡沫会造成 2% 级噪声：流动池下进上出、撇泡；
  • 电极污染/结垢会漂移：每次实验前重采基线（08 T5）。

5.3 串口 CH340E（P109 / P110，115200 8N1）：完全板载

  • Type-C 座 → 板载 CH340E → P109(TXD9) / P110(RXD9)，不需要外接 USB-TTL 模块；
  • 电脑端装 CH340 驱动，SSCOM 选对应 COM，115200 8N1，勾“发送新行”；
  • 关键前提：P109/P110 默认被 Debug0 的 JTAG 功能（TDO/TDI）占用，必须先在 RASC 把 Debug0 改成 SWD（P300/P108）， 再把 P109/P110 配成 SCI9（00 §4.2/§4.4），否则 UART 打不开（固件会 LED 10 Hz 报警、不静默死等）；
  • 联调用电脑 USB 即可；独立演示用 5V/2A 适配器时没有串口（二选一，§3.4）。

5.4 用户 LED1（P111）与按键 K2（P000）：完全板载

LED1（P111，高电平点亮）

启动时快闪 3 下（约 0.72 s）表示“程序在跑”；状态图案：WAIT 1 Hz 慢闪 / FLUSH 5 Hz 快闪 / CLEAR 常亮（回收）/ UNCERTAIN、SOAP 灭（判读以串口 state/action 列为准）。它是“假执行器”：本阶段用它演示阀的回收/排空，不接真阀。

K2（P000，板载 4.7k 上拉，按下为低）

8接线步骤与上电前检查 CHECK BEFORE POWER-ON

8.1 断电接线顺序（每次改线都按这个顺序；拔掉所有电源再动手）

  1. 断电：拔 USB / 适配器（接 12V 时先把船型开关关掉）。

9上电联调（对应 08 验收 T0~T10） BRING-UP

9.1 第一步：看读数是否“像真的”（不做标定，只看趋势）

  • TDS：探头放自来水 vs 皂液水，串口 tds_mv / tds_adc 应有变化（方向以实测为准）；高浓度到 >2400 mV 会标 TDS_SAT（饱和提醒），不是故障；
  • 浊度：清水 vs 浑水，ntu_node_mv 应有明显变化；若一直贴轨（≥4040 ADC）或为 0，先查分压/接线/供电（08 T4）；
  • DS18B20：室温水应显示接近实际水温；显示 25.0 且 CSV src=FIX → 传感器没通（08 T2）；T24.5 可手输兜底。

9.2 第二步：基线 + 假执行器（08 T5 / T7）

  • 探头浸在本底水（自来水）中，发 B（或长按 K2 ≥1.5 s）采基线；OLED 显示 BASELINE n/20，串口 # BASELINE start/OK；
  • 发 R 开始事件 → 观察 OLED 大字“冲洗”→“清水”、LED1 状态、串口 state/action；
  • L2 时 OLED 反显“污水”、LED1 灭（假执行器“排空”）；
  • 全程 P104 不动作（APP_USE_VALVE=0）——先用 LED 把状态机跑通。
串口命令

R 开始事件 / E 结束 / B 采基线 / P 打印状态 / H 帮助 / V1 V0 阀（钩子）

状态映射

L0 回收（CLEAR）/ L1 拿不准（UNCERTAIN→排空）/ L2 含皂液特征（SOAP→排空）；安全侧优先。

数据留痕

200 ms CSV（17 列）+ 事件行；现场指示看 OLED，答辩数据一律引用串口 CSV。

T0 ~ T5

T6 ~ T10

接线相关的前置项 08 §2（上板前检查）与本文 §8.2 是同一套检查（本文覆盖 08 §2 并补充 6 项），做一次即可。

11红线与已知限制（写报告 / 答辩必须如实说） RED LINES

11.1 电气红线（违反会烧 ADC/烧板，或答辩被扣分）

#红线说明
①3.3V 逻辑模拟输入绝对最大 3.6V；5V 输出必须分压/钳位后才可进 MCU；P206/P407/P408/P409 是仅有的 5V 容忍脚，其余都不耐 5V。
②取电纪律5V 外设一律从 VIN（U2-19/20）取电、与板同开同关；禁止外部 5V 灌 VIN；禁止电脑 USB 与 5V 适配器同时给板供电；阀的 12V 必须独立供电。
③不可逆改造板子是借的、赛后收回：只接排针/端子，禁止割线、焊死、拆焊 OLED / CH340E / LDO。
④上电前必量TDS AOUT ≤2.4V、分压节点 ≤3.2V、3V3 = 3.25~3.35V、VIN = 4.5~4.7V；断电时 3V3/5V 对 GND 电阻 >1 kΩ（无短路）。
⑤上电先“排空”固件第一步把 P104 置低；硬件 P104 与 GND 之间加 10 kΩ 下拉；接真阀时这个下拉不得省略（复位/配置完成前 P104 是高阻，靠它守住“不动作”）。
⑥湿电分离电气在防水盒/干燥区，线缆做滴水弯，漏水盘在电气下方；12V 线远离水。
⑦先验收再上水任何“新想法”先过 08 验收再上水；一次只改一处，改完重测（§8.2）。

11.2 已知限制与待实测项（如实记录，⏳ 在到货/装机时逐条清掉）

  • U1-20 丝印存疑（原理图标 3V3、板背疑 VIN）：⏳ 先别用，3.3V 一律走 U1-12
  • 板载 LDO 的实际电流余量 ⏳（按 3.3V 侧 60~90 mA 估算，待满载实测）
  • 浊度模块是 4 针 G/A/D/V + 4 线探头：D（DO）悬空、电位器不动、探头必须原配；AO 满量程（≤4.7V 用 1k+2k；独立 5V 时 5.0V 才改 R2=1.5k）与方向 ⏳ 到货先实测
  • 继电器模块有效电平（高/低触发）以实测为准，⏳ 30 秒验证法确认后再改固件
  • 12V 三通阀的断电方向、通径、连续通电温升 ⏳（见《硬件搭建方案》§6）
  • 本阶段不接真阀、无流量计：LED1 为假执行器，P104 钩子默认关闭
  • 无 NTU 标定：浊度只输出相对量；TDS 无标准液时不报绝对 ppm（红线见 08 §15）
  • 探头污染/气泡/结垢会漂移：可拆洗、间歇采样、每次实验前重采基线
  • 酒精免洗凝胶是 ΔEC + 浊度双盲区：写进“已知局限”，不得声称“识别所有污染物”
