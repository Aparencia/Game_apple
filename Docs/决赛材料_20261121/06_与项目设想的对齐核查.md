## 二、设想里已经过时、不能再照着讲的部分

> 设想写于 10/15，当时"判别实验未做、器件未下单"。到 11/21，这些前提全部变了。**以下内容在材料里一律不出现**，评委若引用旧说法，按"实现态"回答。

| 设想的计划 | 实现后的现实 | 材料中的口径 |
|---|---|---|
| 判别实验未做、14 条待验证 | 已做完整判别链路，有四段实测 | 全部用实测数据（§5） |
| 器件未下单，候选 DFR0300 / SEN0189 | 实际用模拟 TDS 模块（0~2.3 V 直连）+ TS-300B 浊度（1k/2k 分压） | §4.2 引脚表按实物写 |
| 温度补偿用片上 TSN，"省掉 DS18B20" | 实际用 DS18B20 测**水温** | 明确解释：TSN 是结温，不能替代水温（问答 D12） |
| 采样 50~100 ms/组、块内 3 次一致 | 50 ms 主循环 + **400 ms 块投票（8 点 6 票）** | 保留 400 ms 并说明取舍（抗气泡 vs 延迟） |
| 计划采用"截留腔 + 批式判别" | **未采用**（工期风险） | 只在"下一步"出现，不说已实现 |
| 可选：阻抗 C 分量、ORP、流量计、ADC 窗口比较、ADC 自诊断、DAC 4-20 mA | **均未实现** | §3.8 与问答 D12 明确列为"未做/下一步" |

## 四、需要你决定的一处

设想的**§12.1 两件"待决"**，到现在仍未定：

1. **是否把"截留腔 + 批式判别"作为主架构** —— 现在**没做**，材料里写成"下一步"。若明天评委问"为什么不把判定时间拉长"，标准答法是"腔体是结构改动，赛前只做可逆改动；批式逻辑已在纸面验证"。
2. **接触型回用（再洗手）是否进演示** —— 现在**只演示杂用水一条**（冲厕/拖地/绿化）。这是对的，答辩时不要主动扩展到"洗手回用"。
