## 1. 现场数据结论

从日志的 `dEC/(g-1)` 反推：

- `EC0 = 294.1 mV`，p10=293.5、p90=294.8（5 分钟内几乎不变）；
- 清水实际 EC ≈ **324 mV**，g≈1.10，`ΔEC≈+30 mV`；
- 当前阈值：d1=6%×294≈**17.6 mV**，d2=9%×294≈**26.5 mV**；
- 清水 ΔEC +30 > d2 26.5 → **判 SOAP/污水**；
- EC 在 300~325 波动 → 跨 d1/d2 → **清/污横跳**；
- 清水段 ΔNTU≈0，SOAP 行 ΔNTU 中位数 −1.6% → **不是浊度气泡主因，是 EC 基线偏低**。

四次测试共用同一次开机自检的 `EC0=294`，所以不重启/不 `W`，每次都是同一个错误参考。

## 2. 自检到底检什么

| 阶段 | 采什么 | 影响 |
|---|---|---|
| 干态 10 s | `EC_DRY/AO_DRY` | 只用于浸没判断、湿态基线校验；**不直接算 d1/d2** |
| 等水 | EC/AO 水体证据 | 决定能不能采湿态 |
| 湿态 2 s | `EC0/NTU0` | **d1/d2、ΔNTU 的参考**；清水/污水判定的核心 |
| 校验 | 量程/CV/干湿差值/AO | 通过才进 MEASURE |

空腔干态不是“没用”，它影响**能不能正确采到湿态基线**；但阈值数值由湿态 `EC0` 决定。

## 3. v2.4.3 改动

### 3.1 湿态基线：稳定触发，不固定延长

原逻辑：浸没后固定等 800 ms 就采 2 s，容易采到上升沿（294）。

新逻辑：

```
浸没 800 ms 后：
  连续稳定 300 ms（gate.stable）→ 立即采 2 s 基线
  不稳定 → 最多再等 2.2 s（总 3 s），仍不稳也采，reason=calib_low_conf
采完：
  |当前 EC - EC0| > 5 mV → 判 BASE_DRIFT，作废重采（最多 3 次）
```

正常清水约在浸没后 **1.5~2.5 s** 开始采，不会固定多排 3 s；只有水一直在动/气泡多时才等到 3 s。采后漂移校验只在坏基线时多花一次 2 s。

### 3.2 基线清洁度：脏水不能当本底

新增 `ao_clean_delta_mv = 250 mV`：

- 自检/手动基线都要求 `AO0 - AO_DRY ≥ 250 mV`；
- 本机：清水 AO≈2650、空腔≈2241（+409）；肥皂≈2310（+69）；
- 不满足 → `BASE_TURBID`，拒绝自动基线；手动 W 也会被拒，提示换清水。

这解决“首股水是肥皂/脏水”时把脏水当本底的问题：否则同质脏水 ΔEC≈0 会被判 L0 **误回收**。

### 3.3 运行中 `BASE_SUSPECT`

MEASURE 中：

- `g_ec > 1.08`（EC 比基线高 8%）
- 且 `ΔNTU < 4%`（浊度仍干净）
- 持续 5 s

→ 每 30 s 打一行：

```
# BASE_SUSPECT t=... g=1.10 ec0=294.0mV dEC=+30.0mV
```

只报警，不自动改基线（自动学习脏水会把脏水当新本底）。现场看到它应重新 `W`。

### 3.4 OLED 湿态进度（v2.4.2）

湿态采基线时大字显示 **校准**，第二行 `Auto calib n/40`，第三行 `Keep still`；不再显示“待机”。

## 4. 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `APP_AUTOCAL_WATER_MS` | 800 ms | 浸没后最早开始时间 |
| `APP_AUTOCAL_STABLE_MS` | 300 ms | 连续稳定多久才采 |
| `APP_AUTOCAL_WATER_MAX_MS` | 3000 ms | 不稳定时的最长等待 |
| 采后漂移 | 5 mV | 超过则 `BASE_DRIFT` 重采 |
| `ao_clean_delta_mv` | 250 mV | 基线清洁度门槛 |
| `g_ec` 怀疑阈值 | 1.08 | 持续 5 s 打 `BASE_SUSPECT` |

---

## 5. 验收

1. 启动行 `SENSOR-NODE v2.4.3-FAST`；
2. 空腔上电：`Auto dry …` → `Auto wait water`；
3. 注清水：`Auto water ok` → `Auto calib n/40`（大字“校准”）→ `# BASELINE OK`；
4. 基线 `ec0` 应接近当前清水实际值（本机约 324 mV），不是 294；
5. 若 `# BASELINE REJECT note=BASE_DRIFT`：说明水还在动，会自动重采；
6. 若 `note=BASE_TURBID`：水不够清亮，换清水或等泡沫消散后 `W`；
7. 运行中若长期 `g>1.08`，出现 `# BASE_SUSPECT`，按提示重新 `W`；
8. 清水连续 60 s 应稳定 `CLEAR`，不再 SOAP↔CLEAR 横跳。

---

## 6. 限制

1. 基线清洁度用 AO 绝对值差判断，换模块/换水需重新确认 `ao_clean_delta_mv`；
2. 透明但高 EC 的脏水（如盐水）仍可能过 AO 门槛，最终要靠“自检只用清水”的流程；
3. 稳定触发最多等 3 s，仍可能在水一直流动时采到低置信基线，采后漂移校验会兜底；
4. 没有 Flash 持久化，每次上电仍要自检。
