# 第二次稀释肥皂水被判清水（M1e，2026-11-20）

- 固件：`SENSOR-NODE v2.8.0-LEVEL-M1e`
- 构建：`text 86200 / data 480 / bss 11516`，0 error / 0 warning
- 基于：`v2.8.0-LEVEL-M1d`

---

## 1. 超声已经正常，但还没有参与判定

M1d 日志：

```
# hc-sr04: ready ... c/us=90
# LEVEL ... mm=108 valid=1 ... us=633 cpus=90
```

超声已经能稳定输出 mm（约 53~129mm），但 M1 只输出：

```
# LEVEL
```

`decision / gate / valve` 仍然是 v2.7.6 的 EC/NTU 逻辑，**液位没有参与 CLEAR/SOAP 判定**。

所以这次第二次肥皂水判 CLEAR，不是超声判错，是超声根本没接入判定。

---

## 2. 第二次肥皂水为什么 CLEAR

标定：

```
DRAIN  EC0=301.4
RECOVER EC0=315.7
```

第一次肥皂水（t≈820~837s）：

```
EC≈339~341
dEC≈+21
dNTU≈-2.6
状态：UNCERT/L1/DRAIN
```

第二次同一份稀释（t≈881~929s）：

```
EC≈331 → 329
dEC≈+14 → +5（3 秒内）
g≈1.045 → 1.015（EC0 被抬高）
dNTU≈+2~4
状态：CLEAR/L0/RECOV
```

关键：**dEC 从 +14 掉到 +5，不是水变干净，是 trim 把 EC0 拉上去了。**

当前阈值：

```
d1 = 5% × 315.7 ≈ 15.8
trim 条件：5 ≤ dEC < d1
```

第二次 dEC=+14 < 15.8，正好落进 trim 区间：

```
每 50ms 把 EC0 往 EC 拉 0.2mV
→ dEC 14→5
→ 判 L0/CLEAR
```

第一次 dEC=+21 > d1，trim 不动作，所以保持 L1。

**所以第二次被判清水，是弱肥皂偏移被 trim 学掉了。**

---

## 3. M1e 修复

### ① EC d1：5% → 4%

```
d1 = 4% × 315.7 ≈ 12.6
```

第二次 dEC=+14 > 12.6 → L1/UNCERT/DRAIN，不再 CLEAR。

### ② trim 上限：d1 → 0.7×d1

```
只允许 5 ≤ dEC < 0.7×d1 ≈ 8.8
```

第二次 +14 不进入 trim，不会被学成 0。

第一次 +21 也不进入 trim。

---

## 4. 预期

| 水样 | dEC | dNTU | 结果 |
|---|---|---|---|
| 清水 | -7~+5 | -5~+4 | CLEAR/L0 |
| 第一次肥皂稀释 | +21 | -2.6 | **UNCERT/L1/DRAIN** |
| 第二次同稀释 | +14 | +2~4 | **UNCERT/L1/DRAIN** |
| 典型肥皂（NTU 也升） | +40 | +10 以上 | SOAP/L2 |

注意：

- 这两次肥皂水的 NTU 都没有明显上升（-2.6、+2~4），所以不会标 SOAP；
- 但至少不会 CLEAR、不会回收；
- 如果必须标 SOAP，需要 NTU 也升，或把 EC d2 降到 4~5%（有清水误判风险）。

---

## 5. 超声数据什么时候真正参与判定

M2 才会：

- 液位 STABLE 才允许 MEASURE/标定；
- 液位变化时冻结分类和 trim；
- 液位无效时回退 v2.7.6 gate。

但液位不能识别“肥皂”，只能识别液位/阀位平台。

---

## 6. 现场图像与 NTU

你发的肥皂水看起明显浑浊，但传感器：

```
肥皂1 dNTU≈-2.6
肥皂2 dNTU≈+2~4
```

说明 TS300B 没有把这份“浑浊”变成明显正 dNTU。可能原因：

- 泡沫/气泡在液面，探头在液面下；
- 探头表面附着气泡/皂膜；
- 这份稀释的悬浮颗粒散射不够强；
- NTU 探头位置/方向。

这需要单独检查 NTU 探头安装与清洗，不是软件阈值能完全解决。
