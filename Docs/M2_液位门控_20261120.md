# M2g：AO 低时用液位+EC 降级继续标定（修复 Auto fail）（2026-11-20）

- 固件：`SENSOR-NODE v2.8.0-LEVEL-M2g`
- 构建：`text 87160 / data 480 / bss 11532`，0 error / 0 warning
- 基于：`v2.8.0-LEVEL-M2f`

> **现场 Auto fail 的直接原因**
>
> ```
> # CAL REJECT water_dirty:
>   ec=303.3 (ec_dry=60.0)
>   ao=2373.0 (ao_dry=2337.0)
>   mm=144
> ```
>
> AO 只比干态高 36mV，未过 `AO_DRY+80=2417`，所以 `water_dirty`。
> 超声 `mm=144 valid=1` 正常，不是超声导致。
>
> 这可能是塑料片/气泡/探头位置让 AO 偏低，也可能是水确实脏。
>
> M2g：液位 `mm≥20` 且 EC 已高于干态 80mV 时，AO 低也允许继续标定，
> 但打印 `CAL WARN`，并在 baseline validate 中接受低 AO 基线。







---

## 1. 现场问题

同一份肥皂水：

- 前半段：`UNCERT/L1/DRAIN`；
- 后半段：`CLEAR/L0/RECOV`；
- 液位从 100 → 65 → 32 → 60 → 114 → 100 mm 明显变化；
- 超声 `valid=1, mm` 正常，但 **M1 只记录，不参与判定**。

后半段 CLEAR 的两个因素：

1. 液位变化导致 EC 平台变化，决策仍用旧状态；
2. EC `d1=4%`，但 `ec_hyst_ratio=25%` 把 L0 保持上限抬到 `1.25×d1≈15.9mV`；
   `dEC=+14~+16` 落在保持区内，继续 CLEAR。

## 2. M2 实现

### 2.0 标定水体确认（M2g）

正常路径仍然要求 EC/AO 双证据：

```
EC ≥ EC_DRY + 80mV
AO ≥ AO_DRY + 80mV
```

降级路径（M2g）：

```
液位 valid=1 且 mm≥20
EC ≥ EC_DRY + 80mV
AO 低（可能塑料片/气泡/探头位置）
→ CAL WARN，继续标定
→ baseline validate 也接受低 AO（CAL WARN）
```

危险提示：

- 如果水确实脏/肥皂，降级会把脏水当本底；
- `CAL WARN` 必须配合人工确认“这是清水”。


### 2.1 液位状态

`app_level_task()`：

```
|rate| > 5 mm/s     → level_hold=true，稳定计时清零
1 < |rate| ≤ 5      → 过渡带，保持 hold
|rate| ≤ 1 mm/s 1s  → level_hold=false
level invalid/<10mm → 释放 hold，回退 v2.7.6
```

### 2.2 判定门控

**M2f：不强制 WAIT，槽切换改为阀位优先。**

```
level_hold=true：
  只禁止 trim
  槽切换继续按阀位（DRAIN/RECOVER/FULL）
  decision 继续分类
```

原因：

- 冻结槽切换会让 RECOVER 继续用 DRAIN 基线，dEC 从 0 跳到 +14~18；
- 仅按 EC 最近槽也会因液位/EC 噪声选错；
- 所以槽由阀位决定，EC 只做 FULL 判定和数值校验。

### 2.3 trim 与基线选择

- `level_hold=true` 时禁止 `app_baseline_trim_task()`；
- 槽选择始终执行，阀位优先；
- 阀位槽无效时用最近有效槽兜底；
- 液位无效时仍回退 v2.7.6。

### 2.4 EC 迟滞

`ec_hyst_ratio`：25% → 10%。

```
L0 保持上限 = 1.10 × d1
d1 = 4% × 315 ≈ 12.6
保持上限 ≈ 13.9
```

`dEC=+14~+16` 不再留在 CLEAR，进入 L1/UNCERT/DRAIN。

## 3. 预期

| 阶段 | 液位 | 状态 |
|---|---|---|
| 清水稳定 | mm 稳定 | CLEAR/L0 |
| 进水/液位上升 | >5mm/s | **继续分类；基线/trim 冻结，不插入 WAIT** |
| 肥皂水稳定 | mm 稳定 | dEC+14 → UNCERT/L1/DRAIN |
| 失水 | 快速下降 | 继续分类，gate 进入 DRY |
| 超声无效 | invalid | 回退 v2.7.6 gate |

注意：

- 液位变化时不再用旧 CLEAR 回收；
- 液位稳定后，弱肥皂水仍不会标 SOAP（NTU 不升），但不会 CLEAR；
- 典型肥皂（NTU 也升）仍走 SOAP/L2。

---

## 4. 验证

1. 启动行 `v2.8.0-LEVEL-M2`；
2. 清水稳定：`CLEAR`；
3. 倒水/液位变化：应出现 `WAIT/L1/DRAIN`，reason `LEVEL_MOVE`；
4. 液位稳定 1s 后才恢复分类；
5. 肥皂水稳定段：`UNCERT/L1/DRAIN`，不再 CLEAR；
6. 失水：`DRY`；
7. 长按跳过/校准仍可用。
