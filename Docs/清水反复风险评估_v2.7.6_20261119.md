# d1 降到 5% 会不会重新横跳？（v2.7.6-B3）

- 日期：2026-11-19
- 固件：`SENSOR-NODE v2.7.6-B3`
- 构建：`text 84684 / data 480 / bss 11440`，0 error / 0 warning
- 基于：`v2.7.5-B3`

---

## 1. 清水数据：5% 有余量

从 v2.7.3 清水和这次“除最后一次外都是清水”的日志统计：

| 数据 | 稳定清水 max |dEC| | p95 | 说明 |
|---|---|---|---|
| v2.7.3 清水 | 4.4 mV | 2.8 mV | 槽 343.5/406.5 |
| 这次清水段 | 16.1 mV | 11.3 mV | 槽 373.8/553.0 |

5% 门限：

```
d1 = 5% × 553 = 27.7 mV
```

清水最大 16.1 mV，离门限还有 **11.6 mV**；p95 只有 11.3 mV。

所以 **纯净水本身不会因为 d1 从 6% 降到 5% 而重新跨阈值横跳**。

---

## 2. 但只降 d1 不够：trim 会把肥皂“学掉”

这次最后一次肥皂冲洗水：

```
dEC 从 +30 mV 慢慢降到 +22 mV（约 15 s）
dNTU 只有 +0.6~1.0%
```

dEC 为什么会自己降？

因为 v2.7.5 的慢跟踪：

```
|dEC| > d1 → 以 4 mV/s 把 active EC0 拉向当前 EC
```

它把“肥皂水的 EC 偏移”慢慢当成了液位漂移，EC0 被拉高，dEC 就降下来了。  
降到 d1 以下后，又会 CLEAR。

**这才是可能“回到反复”的真正风险，不是 d1=5% 本身。**

---

## 3. v2.7.6 修复：trim 只跟踪 d1 以内

```c
if ((d_ec < 5.0f) || (d_ec >= g_dec.out.d1_ec_mv)) {
    return;   // 不跟踪
}
```

也就是：

| 偏移 | 行为 |
|---|---|
| `5 mV ≤ |dEC| < d1` | 允许慢跟踪（小液位漂移） |
| `|dEC| ≥ d1` | 不跟踪，保持 L1/DRAIN |
| `|dEC| < 5 mV` | 已经干净，不需要跟踪 |

这样：

- 清水小漂移：仍然能跟；
- 肥皂 +30 mV：**不会被 trim 学掉**，保持 L1/DRAIN；
- 不会出现“先 UNCERT，几秒后又 CLEAR”。

---

## 4. 最终判定

| 水样 | dEC | dNTU | 结果 |
|---|---|---|---|
| 清水 | <16 mV（<3%） | <7% | CLEAR/L0 |
| 这次肥皂冲洗水 | +30 mV（5.4%） | +0.6~1.0% | **UNCERT/L1/DRAIN，持续** |
| 典型肥皂水 | +40 mV 以上 | +10% 以上 | SOAP/L2 |
| 失水 | 快速下降 | 冲高 | DRY/LOCKOUT |

- d1=5% 不会让清水反复；
- trim 限制后，肥皂也不会被慢慢学成清水；
- 这次肥皂冲洗水会显示 `UNCERT/DRAIN`，不是 `SOAP`，因为 NTU 没有信号。
