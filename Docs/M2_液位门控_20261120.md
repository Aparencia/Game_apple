# M2d：液位只区分“没水/水脏”，不绕过清洁门槛（2026-11-20）

- 固件：`SENSOR-NODE v2.8.0-LEVEL-M2d`
- 构建：`text 86808 / data 480 / bss 11532`，0 error / 0 warning
- 基于：`v2.8.0-LEVEL-M2b`

> **M2c 不彻底，已废弃。**
>
> M2c 用 `液位 mm≥20` 直接覆盖 `allow_wet`，会把“有水但水脏/肥皂”的情况强行当清水标定，
> 重新引入“把肥皂当本底”的风险。
>
> M2d 改为：
> - 液位 `valid=1 mm≥20` 只用于区分 `water_dirty` 与 `water_unconfirmed`；
> - **不覆盖 EC/AO 清洁门槛**；
> - 水脏时仍然 `DONE(water_dirty)`，两槽不采，NO_BASE 是保护结果。
>
> 现场这份日志：
>
> ```
> AO ≈ 1530×1.5 = 2295mV
> AO_DRY ≈ 2337mV
> ```
>
> AO 低于干态，说明当时腔里的水不是干净水（或 AO 通道/干态指纹有问题），
> 标定拒绝是正确行为，不是 NO_BASE bug。




---

## 1. 现场问题

同一份肥皂水：

- 前半段：`UNCERT/L1/DRAIN`；
- 后半段：`CLEAR/L0/RECOV`；
- 液位从 100 → 65 → 32 → 60 → 114 → 100 mm 明显变化；
- 超声 `valid=1, mm` 正常，但 **M1 只记录，不参与判定**。

后半段 CLEAR 的两个因素：

1. 液位变化导致 EC 平台变化，决策仍用旧状态；
2. EC `d1=4%`，但 `ec_hyst_ratio=25%` 把 L0 保持上限抬到 `1.25×d1≈15.9mV`；
   `dEC=+14~+16` 落在保持区内，继续 CLEAR。

## 2. M2 实现

### 2.0 标定水体确认（M2d）

`APP_AC_SETTLE` 仍然只认 EC/AO 清洁双证据：

```
EC ≥ EC_DRY + 80mV
AO ≥ AO_DRY + 80mV
```

液位只用于区分原因，不覆盖门槛：

```
液位 valid=1 mm≥20，但 EC/AO 不通过
→ DONE(water_dirty)，两槽不采
液位 invalid
→ DONE(water_unconfirmed)
```

日志：

```
# CAL REJECT water_dirty: ec=... (ec_dry=...) ao=... (ao_dry=...) mm=...
```

NO_BASE 是保护结果，不是 bug。

### 2.1 液位状态

`app_level_task()`：

```
|rate| > 5 mm/s     → level_hold=true，稳定计时清零
1 < |rate| ≤ 5      → 过渡带，保持 hold
|rate| ≤ 1 mm/s 1s  → level_hold=false
level invalid/<10mm → 释放 hold，回退 v2.7.6
```

### 2.2 判定门控

**M2a 修订：不再强制 WAIT。**

原因：`WAIT` 会让识别失效区间变长，现场不接受。

M2a 的行为：

```
level_hold=true：
  只冻结 baseline 选槽和 trim
  decision 继续用当前基线做 EC/NTU 分类
  不插入 WAIT，不冻结状态
```

液位变化时可能出现 `UNCERT/DRAIN`，但不会整段 WAIT；  
液位稳定 1s 后恢复选槽/trim。

### 2.3 trim 与基线选择

- `level_hold=true` 时禁止 `app_baseline_trim_task()`；
- 禁止 `app_baseline_task()` 选槽，避免液位过渡时切错槽；
- 稳定 1s 后恢复。

### 2.4 EC 迟滞

`ec_hyst_ratio`：25% → 10%。

```
L0 保持上限 = 1.10 × d1
d1 = 4% × 315 ≈ 12.6
保持上限 ≈ 13.9
```

`dEC=+14~+16` 不再留在 CLEAR，进入 L1/UNCERT/DRAIN。

## 3. 预期

| 阶段 | 液位 | 状态 |
|---|---|---|
| 清水稳定 | mm 稳定 | CLEAR/L0 |
| 进水/液位上升 | >5mm/s | **继续分类；基线/trim 冻结，不插入 WAIT** |
| 肥皂水稳定 | mm 稳定 | dEC+14 → UNCERT/L1/DRAIN |
| 失水 | 快速下降 | 继续分类，gate 进入 DRY |
| 超声无效 | invalid | 回退 v2.7.6 gate |

注意：

- 液位变化时不再用旧 CLEAR 回收；
- 液位稳定后，弱肥皂水仍不会标 SOAP（NTU 不升），但不会 CLEAR；
- 典型肥皂（NTU 也升）仍走 SOAP/L2。

## 4. 验证

1. 启动行 `v2.8.0-LEVEL-M2`；
2. 清水稳定：`CLEAR`；
3. 倒水/液位变化：应出现 `WAIT/L1/DRAIN`，reason `LEVEL_MOVE`；
4. 液位稳定 1s 后才恢复分类；
5. 肥皂水稳定段：`UNCERT/L1/DRAIN`，不再 CLEAR；
6. 失水：`DRY`；
7. 长按跳过/校准仍可用。
