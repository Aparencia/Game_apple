【0】这份文件解决什么问题、怎么读
------------------------------------------------------------------------
本文件回答三个问题：
  ① 板子上到底哪个孔是哪个脚、哪些脚已占用、哪些脚能碰（§2）；
  ② 每根线从模块的哪个端子接到板子的哪个孔、串什么电阻电容（§3~§7）；
  ③ 接完怎么确认没接错、上电后应该看到什么（§8~§9）。
读法（已装过 tds_mini 或本工程的同学可跳读）：
  - 第一次接线：按 §0 → §2 → §3 → §4 → §5 → §7 → §8 顺序做；
  - 只查一根线：直接看 §7 完整接线表或文末【附录 A·接线速查卡】；
  - 排障：看 §10；答辩口径/红线：看 §11。
三条硬前提（违反会烧 ADC 或烧板，§11 会逐条展开）：
  P1 板子 IO 是 3.3V 逻辑，模拟输入绝对最大 3.6V——5V 传感器输出必须先分压；
  P2 板子是借的、赛后收回——只接排针/端子，禁止割线、焊死、拆焊板载器件；
  P3 断电接线、先量后接、一次只改一处——每次改线后重新按 §8 量一遍。
0.1 v1.1 更正（2026-10-31，按实物 / 商品页核对；v1.0 是按 TS-300B 3 针写的）
    实际采购的浊度模块是"4 针模块 + 4 线分立探头"套装，不是 3 针一体化：
    - 丝印 G/A/D/V：G=GND（电源负极）、A=AO（模拟输出）、D=DO（数字比较器输出，
      5V 电平）、V=VCC（规格书要求 5V，禁止 3.3V）；
    - D（DO）本方案不用：悬空即可，**严禁**接 P013 / P014 / P104 或任何 3.3V 引脚；
    - 灵敏度电位器只调 DO 的比较阈值，不影响 AO，不用调（若实测 AO 随它变，
      说明是增益型批次，调到中间后固定，并在实验记录里写明）；
    - VCC 只能 5V，与 v1.0 的"从 VIN 取电"一致；AO 标称 0~5V，但板上 VIN 只有
      4.5~4.7V → 实际满量程 ≈4.7V，1k+2k 后节点 ≤3.13V（<3.3V），分压电阻不变；
    - 配套探头是 4 线（1 电源负极 / 2 传感器− / 3 传感器out / 4 传感器+）：
      必须用原配探头、按模块座丝印对插；不能配 TS-300B 那种 3 线一体化探头；
    - 不变的部分：VCC→VIN、GND→地、AO→[1k]→节点→[2k]/[0.1µF]→GND→P013；
      接线表第 8~10 根的模块端子名以丝印 G/A/V 为准（D 不接）；
    - 到货必须实测两项：AO 满量程（4.7V 还是 5.0V）与方向（清水高还是浑水高），
      做法见 §4.2 / §8.2；测完再定 R2 与 ntu_clear_high（只有反相才改 false）。
    （正文其余处出现 "TS-300B" 是沿用的工程/代码命名，代码符号 sensor_ts300b /
      TS300B_* 不改；03 文档代码注释里的 ≤3.0V 是典型工作值，安全上限按 ≤3.2V 计。）
与其它文档的关系一句话：本文给"电"的唯一口径；《硬件搭建方案》给"水"和
"阀选型"；00 §3.1 是本文的压缩速查版；08 T0~T10 是本文接完后的验收动作。


【1】电路总览
------------------------------------------------------------------------
1.1 三类连接（把 20 多根线分成三类，接线不会乱）
    ① 电源：Type-C 5V 进板 → 板载 LDO 出 3.3V（U1-12）；5V 外设从 VIN（U2-19/20）
       取电，与板同开同关；12V 只给阀（本阶段不接）。
    ② 地：所有模块 GND 汇到"星形单点"，再进板 GND（U1-1/8/16、U2-4/6/11/14/18，
       共 8 个排针地脚）；阀/继电器的大电流地单独走线，不经过开发板地。
    ③ 信号：2 路模拟（TDS→P014/AN12、浊度分压→P013/AN11）+ 1 路 1-Wire
       （DS18B20→P500）+ 板载 I2C0（OLED→P407/P408）+ 板载串口（CH340E→P109/P110）
       + 2 路 GPIO（LED1→P111 板载、阀→P104 预留）。

1.4 电气特性与绝对最大（做任何连接前先记住这 5 条）
    ① 逻辑电平：3.3V。除 P206/P407/P408/P409 外，所有 IO 都**不是** 5V 容忍；
       模拟输入绝对最大 3.6V（数据手册），超过即损坏 ADC/引脚。
    ② ADC 参考：VREFH0 = 板载 3.3V（不用外接基准）；12 位 = 0~4095 对应 0~3.3V，
       1 LSB ≈ 0.806 mV。
    ③ ADC 模拟源阻抗要求 ≤ 1 kΩ（12 位精度前提）——这是浊度必须用 1k+2k、
       不能用"10k+20k"的原因（§4.3）。
    ④ 5V 容忍脚只有 P206（流量计预留）、P407/P408（已给 OLED）、P409（蜂鸣器预留）；
       其余 5V 信号一律分压或加电平转换，不能直连。
    ⑤ 5V 外设（浊度、继电器线圈）只从 VIN（U2-19/20）取电，与板同开同关；
       不允许"板断电、外设带电"（会从 IO 倒灌）。


【2】板卡与孔位事实
------------------------------------------------------------------------
2.1 板卡型号与板载资源（🟢 已按实际板卡原理图 V1.2.1 + 瑞萨数据手册核对）
    - 型号：RA4M2_MINI（R7FA4M2AD3CFL，ARM Cortex-M33，48 脚 LQFP）；
    - 板载：0.96" OLED（SSD1306 兼容，I2C0，0x3C，自带 4.7kΩ 上拉）、
            CH340E USB-串口（接 SCI9）、用户 LED1、用户按键 K2、复位键、
            两排 20 孔排针（记作 U1、U2）、SWD 排针（P300/P108）；
    - 没有板载调试器：烧录走 Type-C + CH340E + SCI Boot（Renesas Flash Programmer），
      或用外部 J-Link/EZ-Cube3 走 SWD（P300/P108）；
    - 开发板是借的、赛后收回：只接排针/端子，禁止不可逆改造（见 §11 红线）。

2.2 孔位计数规则（★ 数错孔是新手第一大坑）
    U1、U2 两排都是从板子**下端往 Type-C 方向**数：
        第 1 孔 = U1-1 / U2-1，第 9 孔 = U1-12 / U2-12，第 20 孔 = U1-20 / U2-20。
    记忆锚点："第 9 孔 = 3V3"（U1 侧）；"U2 第 19/20 孔 = VIN"。
    接线前把排针孔位用标签纸/记号笔标出来，接线时逐孔念"U1-6 = P014"再插。

【3】电源与接地
------------------------------------------------------------------------
3.1 供电拓扑（照这个接，不要自由发挥）
    【5V 回路：板 + 传感器 + 继电器线圈】
      220V ── 5V/2A 适配器 ── USB-C 线 ── RA4M2_MINI（或联调时用电脑 USB 供电）
                                          ├─ 板载 LDO ── U1-12（3V3）── TDS VCC
                                          │                          ├─ DS18B20 VDD
                                          │                          └─ 分压上端/上拉（4.7k 等）
                                          ├─ U2-19（VIN≈4.5~4.7V）── 浊度模块 VCC（4 针 V，约 20~40 mA）
                                          └─ U2-19（VIN）────────── 继电器模块 VCC（约 45~55 mA，预留）
    【12V 回路：只给阀（本阶段不接，先了解）】
      220V ── 12V/3A 适配器（内正外负）── 2A 保险丝 ── 船型开关 ── 继电器 COM
                                                              继电器 NO ── 阀线圈（+）
                                                              阀线圈（−）── 12V（−）
                          1N4007 并在阀线圈两端（阴极→线圈+，阳极→线圈−）
    【地：星形单点】
      12V（−）──┐
      5V（−） ──┼── 接线端子排 GND ── 板 GND（U1-1/8/16、U2-4/6/11/14/18）── 各模块 GND
      继电器/阀─┘        （阀的大电流地单独一根到端子排，不经过开发板地线）

3.2 电流预算（估算值，实测为准）
 ┌──────────────────────────┬───────────────┬───────────────┬──────────────┐
 │ 负载                      │ 电压/电流（估）│ 取电点         │ 备注          │
 ├──────────────────────────┼───────────────┼───────────────┼──────────────┤
 │ RA4M2_MINI（MCU+OLED+CH340E）│ 5V，≈60~90 mA │ Type-C USB    │ 板载 LDO 余量 │
 │ TDS 模块                  │ 3.3V，≈3~6 mA  │ U1-12         │ 模拟输出      │
 │ DS18B20                   │ 3.3V，≈1 mA    │ U1-12         │ 测温 2 s 一次 │
 │ 浊度模块（4 针）           │ 5V，≈20~40 mA  │ U2-19/20 VIN  │ AO≤4.7V       │
 │ 继电器模块（预留）          │ 5V，≈45~55 mA  │ U2-19/20 VIN  │ 吸合瞬间电流大│
 │ 12V 阀（不接）             │ 12V，≈0.3~0.5 A│ 独立 12V      │ 禁止从板取电  │
 └──────────────────────────┴───────────────┴───────────────┴──────────────┘
    结论：3.3V 侧负载约 60~90 mA（MCU+OLED+传感器；板载 LDO 丝印 662K、约 200 mA 级，
    🟡 型号待核，3.3V 外部取电余量估计 <100 mA，⏳ 满载实测确认）；
    5V 侧（含板）约 150~200 mA。联调用电脑 USB 供电完全够；演示用 5V/2A 适配器
    有余量。12V 阀必须独立供电，绝不从板 5V/3V3 取。

3.3 接地（为什么必须星形单点）
    - 板上 GND 有 8 个排针地脚（U1-1/8/16、U2-4/6/11/14/18）+ SWD 排针 GND + OLED 座地；
      本方案只用排针 8 处。
    - 所有模块 GND 先汇到"接线端子排/洞洞板地排"，再用 1 根线进板 GND——不要
      一根一根地"就近插板子"（会形成地环路，ADC 读数跳动、OLED 花屏）。
    - 阀/继电器的电流地单独走一根到端子排，绝不流经开发板地线（大电流会把地电位抬起）。
    - 通电后用万用表通断档确认：每个模块 GND 与板 GND 之间 < 1 Ω。

3.4 去耦与滤波
    - 每个模块电源入口就近并 0.1 µF 瓷片电容到 GND（TDS、DS18B20、浊度模块各 1 只）；
    - 继电器模块 VCC 就近并 100 µF 电解 + 0.1 µF 瓷片（吸合瞬间防拉跌）；
    - 浊度分压节点并 0.1 µF 对地（与 R2 并联，滤高频，见 §4.2）；
    - 探头线/信号线尽量短（≤30 cm 为佳），与 5V 电源线、12V 线分开走，不要捆在一起。

3.5 上电/断电顺序与三条禁令
    上电：先板（插 USB/适配器）→ 等自检（LED 快闪 3 下、串口 boot 行）→ 再开 5V 外设。
    断电：先关 5V 外设 → 再断板。
    三条禁令：
      ① 不要把外部 5V 灌进 VIN 排针同时插 USB（防倒灌）；
      ② 不要用电脑 USB 与外部 5V 适配器同时给板供电；
      ③ 板子只有 1 个 Type-C：插 5V 适配器就没有串口（独立演示工况），
         串口 + 独立供电二选一（要同时保留可加带供电的 USB HUB，可选）。


【4】模拟输入电路（两路 ADC）
------------------------------------------------------------------------
4.1 TDS 通道（P014 / AN12，主判据）
    接线：
        TDS 模块 VCC  ── U1-12（3V3，第 9 孔）        ← 必须 3.3V，不要接 5V
        TDS 模块 GND  ── U1-16（或 GND 地排）         ← 必须共地
        TDS 模块 AOUT ── U1-6（P014 / AN12）          ← 直连安全（0~2.3V）
        TDS 探头      ── 模块上 2P XH-2.54 座          ← 插紧；黑色连接器不可入水
    为什么可以直连：模块标称 AOUT 0~2.3 V，实测高浓度皂液水最高 2.356 V，均 < 3.6V
    绝对最大，也 < ADC 满量程 3.3V。若个别批次输出更高（>3.0V），必须改分压后再接。
    注意：
      - 不要给 TDS 模块接 5V：5V 供电时输出幅度会抬高、且若同时给 DS18B20 供 5V，
        DQ 上拉会变成 5V，超 MCU 耐压；
      - AOUT 不是"越大越脏"：不同批次方向可能不同，只做相对判据，不预测方向；
      - 探头可拆洗：每次实验后取下冲洗、甩干；探头不要碰杯壁/杯底（固定深度）。
    可选抗干扰（默认不装）：AOUT 对地并 0.1 µF（只并电容、不串电阻，保持源阻抗）；
    若现场噪声大且线长 > 30 cm，再考虑加 100 Ω 串联 + 0.1 µF（源阻抗仍 < 1 kΩ）。

4.2 浊度模块通道（P013 / AN11，分压必做，不能省；模块为 4 针 G/A/D/V）
    接线（模块丝印 G/A/D/V；只用 G、A、V 三个端子，D 悬空）：
        浊度模块 V（VCC）── U2-19/20（VIN ≈4.5~4.7V）   ← 规格书要求 5V，禁止 3.3V
        浊度模块 G（GND）── GND 地排 / U2-18
        浊度模块 A（AO） ──┬─ R1 = 1 kΩ ──┬─► U1-5（P013 / AN11）
                           │              │
                           │              ├─ 0.1 µF ── GND   （与 R2 并联，滤高频）
                           └─ R2 = 2 kΩ ──┴─ GND
        浊度模块 D（DO） ── 悬空，不接     ← 5V 比较器输出，接 MCU 会超压；电位器只调它
    电路图：
        浊度模块 A ──[R1 1k]──┬──────────► P013 / AN11
                              │
                              ├──[R2 2k]── GND
                              │
                              └──[0.1µF]── GND
    计算（写进报告/答辩要会算）：
        分压比 = R2/(R1+R2) = 2/3；
        AO 上限 = 模块 VCC ≈4.5~4.7V（板上 VIN 供电）→ 节点 ≈3.00~3.13V
        （< 3.3V，安全；也 < ADC 绝对最大 3.6V，且低于固件 4040 的贴轨门限）；
        源阻抗 = R1∥R2 = (1k×2k)/(1k+2k) ≈ 667 Ω ≤ 1 kΩ（满足 RA4M2 ADC 要求）。
    为什么不能用 10k+20k：分压比同样是 2/3，但源阻抗 = 6.67 kΩ > 1 kΩ，12 位 ADC
    采样会明显偏低且不稳（这是最容易犯的错）。
    电阻怎么选（v1.1 更正：别照抄旧版"AO 最大 4.5V"）：
        - 模块用板 VIN（4.5~4.7V）供电 → AO 上限 ≤4.7V → 保持 R1=1k、R2=2k；
        - 只有改成独立 5.0V 供电（AO 可到 5.0V）时，才把 R2 换成 1.5k（节点 3.0V、
          源阻抗 600 Ω）——此时固件 ntu_div_r2_ohm 必须同步改 1500，否则 ao_mv 还原错；
        - 电阻优先 1% 金属膜；5% 最坏时节点仍 <3.3V，但余量变小，务必实测。
    4 针模块的三件"不用/不接"（v1.0 差异项）：
        ① D（DO）悬空：5V 电平的比较器数字输出，接 P013/P014/P104 会超压；想用
           "数字浊度报警"必须先分压/电平转换（本阶段不做）；
        ② 灵敏度电位器不动：只影响 DO 阈值、不影响 AO；若实测 AO 随它变（增益型
           批次），左右各试一档后固定到中间位置，并写进记录；
        ③ 探头用原配 4 线：模块 4P 座丝印 1 电源负极 / 2 传感器− / 3 传感器out /
           4 传感器+，探头插头防呆对插即可；探头线不占 MCU 引脚、不需要另接电源。
    到货必做的两项实测（做完再写结论，§8.2 第 11/12 项）：
        ① 量 AO 满量程：清水（或空气）下万用表量 A-G 最高电压；
           ≤4.7V 用 1k+2k；接近 5.0V 按上面第 2 条处理；
        ② 定方向：清水、浑水各量一次 A（或节点）电压 + 看串口 ntu_node_mv，
           确认"清水高还是浑水高"；反相时把 ntu_clear_high 改 false。
    ⚠ 分压比写死在固件配置里（pipeline_cfg.ntu_div_r1_ohm / ntu_div_r2_ohm，
      默认 1000/2000）——换电阻必须同步改这两个值，否则 ao_mv 还原错误。
    - VIN 电压注意：本板 VIN 是 USB VBUS 经防反接二极管后的 4.5~4.7V（低于标称 5V）。
      模块规格要求 5V，4.5V 一般也能工作（LED 稍暗、AO 整体略低）；若读数不稳/贴轨，
      先量 V（VCC）是否 ≥4.5V，必要时用独立 5V 适配器给模块供电（与板共地、与板
      同开同关，上电顺序见 §3.5；外部 5V 不许灌进 VIN 排针）。

4.3 两路 ADC 的共同要求
    - 参考电压：VREFH0 = 板载 3.3V（RASC 默认，不要外接基准）；
    - 采样：两路必须在同一个 Scan Group（AN11+AN12），一次扫描同时转换，
      保证 TDS 与浊度"同一时刻"采样（RASC 配置见 00 §4.1）；
    - 源阻抗：任何进 ADC 的信号源阻抗 ≤ 1 kΩ（分压电阻/跟随器要按此选型）；
    - 保护：P013/P014 绝对最大 3.6V；上电前必须先量 AO 最大值（§8.2）；
    - 地：模拟地按 §3.3 星形单点，探头信号线与电源线分开走。

4.4 探头安装与噪声（影响数据质量，接线后立刻检查）
    - TDS 探头与 DS18B20 装在流动池同一水体、同一深度，探头感测面浸入 10~20 mm，
      不碰壁、不碰底（详见《硬件搭建方案》§7.3 流动池）；
    - 浊度模块的 4 线探头同样固定（感测面浸入 10~20 mm），避开气泡/泡沫聚集处；
    - 气泡/泡沫会造成 2% 级噪声：流动池下进上出、撇泡；
    - 电极污染/结垢会漂移：每次实验前重采基线（08 T5）。


【5】数字接口电路
------------------------------------------------------------------------
5.1 DS18B20 水温（P500，1-Wire）
    接线（3 线供电方式）：
        DS18B20 VDD ── U1-12（3V3）
        DS18B20 GND ── U1-1（或 GND 地排）
        DS18B20 DQ  ── U1-17（P500）       ← 同时用 4.7 kΩ 上拉到 3.3V
    注意：
      - 4.7 kΩ 上拉是必须的（开漏总线）；若模块座/转接板已自带，不用重复加，
        否则上拉过强（两个 4.7k 并联 ≈2.35k，一般也能用，但不必要）；
      - 不要给 DS18B20 接 5V：P500 不是 5V 容忍，DQ 会被 5V 上拉打坏；
      - 杜邦线尽量短（≤50 cm）；长线/多探头要降速或改寄生供电（本方案不需要）；
      - 固件已有保障：全 0/全 FF 判无效、连续 3 次无效自动停用、串口 T24.5 手输兜底。

5.2 板载 OLED（I2C0：P407/P408，0x3C）
    - 完全板载：模块已焊在板上，SDA=P407、SCL=P408，自带 4.7kΩ 上拉，
      **不需要任何外部接线**；
    - 位置：RA4M2_MINI 板载 0.96" SSD1306 兼容 128x64；
    - 固件地址：0x3C（7-bit），I2C0，Fast Mode 400 kHz（RASC 配置见 00 §4.3）；
    - 禁止：不要拆焊/遮挡 OLED；不要把 P407/P408 改作 GPIO 或别的外设；
    - 故障注入（08 T10）：把固件里的 OLED_I2C_ADDR 临时改为 0x3D 重烧，
      串口应出现一次 WARN，判别/CSV/LED/阀不受影响（OLED 不是安全路径）。

5.3 串口 CH340E（P109/P110，115200 8N1）
    - 完全板载：Type-C 座 → 板载 CH340E → P109(TXD9)/P110(RXD9)，
      **不需要外接 USB-TTL 模块**；
    - 电脑端装 CH340 驱动，SSCOM 选对应 COM，115200 8N1，勾"发送新行"；
    - 关键前提：P109/P110 默认被 Debug0 的 JTAG 功能（TDO/TDI）占用，
      必须先在 RASC 把 Debug0 改成 SWD（P300/P108），再把 P109/P110 配成 SCI9
      （00 §4.2/§4.4），否则 UART 打不开（固件会 LED 10 Hz 报警、不静默死等）；
    - 联调用电脑 USB 即可；独立演示用 5V/2A 适配器时没有串口（二选一，§3.5）。

5.4 用户 LED1（P111，板载）
    - 完全板载，高电平点亮，无需接线；固件启动时快闪 3 下（约 0.72 s）表示"程序在跑"；
    - 状态图案：WAIT 1 Hz 慢闪 / FLUSH 5 Hz 快闪 / CLEAR 常亮（回收）/
      UNCERTAIN、SOAP 灭（判读以串口 state/action 列为准）；
    - 它是"假执行器"：本阶段用它演示阀的回收/排空，不接真阀。

5.5 用户按键 K2（P000，板载）
    - 完全板载，板上 4.7k 上拉，按下为低；无需接线；
    - v1.3.0 起：短按释放时切换 OLED 页（P1 水质/P2 执行器/P3 详情），串口打印
      "# DISPLAY page=n/3 (K2)"；按住 ≥1.5 s 重采基线（与串口 B 等效）；
    - MARK 改由串口命令 M 发送（# MARK ... src=UART）；K2 短按不再打 MARK。

5.6 烧录/调试接口
    - 烧录（推荐）：Type-C + CH340E + SCI Boot + Renesas Flash Programmer（RFP）；
      进入 SCI Boot：按板卡说明把 BOOT 拨到 ON/按复位（具体以板卡丝印为准）；
    - 调试（可选）：外部 J-Link/EZ-Cube3 接 SWD 排针（5 针，针序与常见 20 针不同：
      pin1=P300/SWCLK、pin2=P108/SWDIO、pin3=RES、pin4=GND、pin5=3.3V）；
      P300/P108 在 RASC 里已配成 DEBUG 功能；
    - 提示：RASC 里改 Debug0 为 SWD 后，P300/P108 会出现在 pin_data.c 的
      IOPORT_PERIPHERAL_DEBUG 行（00 §4.4 验收：最终 pin_data.c 正好 8 条）。


【6】执行器接口（v1.1 历史版本：预留不接；v1.2.0 已真实接入，以 15 文档为准）
------------------------------------------------------------------------
6.1 本阶段状态（v1.1 历史）：APP_USE_VALVE = 0（默认；v1.2.0 起默认 1）
    - P104 不驱动继电器，只由 LED1 表示"回收/排空"（假执行器，先跑通状态机）；
    - 但固件仍在最早时刻把 P104 配置为输出低（排空电平），保证以后接上继电器时，
      上电/复位瞬间也是排空（fail-safe）；
    - 对应固件常量：APP_VALVE_PIN=BSP_IO_PORT_01_PIN_04（P104/U2-8）、
      APP_VALVE_RECOVER_LEVEL=HIGH、APP_VALVE_DRAIN_LEVEL=LOW。

6.2 继电器模块接法（3.3V 触发，光耦输入）
       继电器模块 VCC ── U2-19/20（VIN）      ← 从板取 5V，与板同开同关
       继电器模块 GND ── GND 地排 / U2-18     ← 必须共地
       继电器模块 IN  ── U2-8（P104）          ← 3.3V 电平触发
       P104 ↔ GND 之间加 10 kΩ 下拉          ← 复位/配置完成前 P104 高阻，强制"阀不动作"
    - 模块必须是"3.3V 可触发"款（购买前确认，别买纯 5V 触发）；
    - 光耦输入级共地后不提供电气隔离，只作电平/驱动；
    - 若模块为低电平触发：把 10 kΩ 下拉改成 10 kΩ 上拉到 3.3V，并改固件
      APP_VALVE_RECOVER_LEVEL/DRAIN_LEVEL（有效电平以实测为准）；
    - 继电器模块 VCC 就近并 100 µF + 0.1 µF（§3.4）；
    - 到货 30 秒验证法（必做）：
      ① 万用表量模块 VCC-GND ≥4.5V；
      ② 触发端接 3.3V（或 GPIO），听"咔哒"；
      ③ 通断档量 COM-NO：吸合导通、释放断开；
      ④ 吸合时量线圈两端电压 ≈VCC（<4.2V → 换短粗线/独立 5V）；
      ⑤ 连续触发 10 次全部动作 → 合格。

6.3 12V 三通阀回路（本阶段不接，接阀时按此做）
    - 阀选型：12V 二位三通直动式、一进两出、**断电=排空口通**、通径 ≥4 mm、
      G1/4、EPDM 密封（详见《硬件搭建方案》§6）；
    - 回路：12V 适配器（内正外负）→ 2A 保险丝 → 船型开关 → 继电器 COM；
      继电器 NO → 阀线圈（+）；阀线圈（−）→ 12V（−）；
    - 续流二极管：1N4007 并在阀线圈两端，**阴极→线圈（+）、阳极→线圈（−）**，
      反接会短路（轻则烧保险丝，重则烧电源）；
    - 线圈两端电压：12V 额定；阀只在回收段通电（单次 ≤120 s 为后续需求，本阶段未实现）；
    - 安全：断电/复位/程序跑飞时阀必须回到"排空"位；主排水路常通；
      阀的地单独走线到端子排（§3.3）；
    - 若不用三通阀：用"常通直排 + 回收支路常闭阀"方案 B 兜底（《硬件搭建方案》§6.3）。

6.4 可选：流量计/蜂鸣器（本阶段不做，先留位置）
    - 流量计（YF-S201 类，5V 方波）：VCC→U2-19、GND→U2-18、信号→U2-16（P206，
      5V 容忍脚，关内部上拉）；用于算回收水量/回收率（固件尚未支持）；
    - 蜂鸣器（3.3V 有源模块）：VCC→U1-12、GND→GND、IN→U2-3（P409，5V 容忍脚）；
      裸蜂鸣器不要直驱（电流可能超 GPIO 能力）。

【9】上电联调（对应 08 验收 T0~T10）
------------------------------------------------------------------------
9.1 第一步：看读数是否"像真的"（不做标定，只看趋势）
    - TDS：探头放自来水 vs 皂液水，串口 tds_mv / tds_adc 应有变化（方向以实测为准）；
      高浓度到 >2400 mV 会标 TDS_SAT（饱和提醒），不是故障；
    - 浊度：清水 vs 浑水，ntu_node_mv 应有明显变化；若一直贴轨（≥4040 ADC）
      或为 0，先查分压/接线/供电（08 T4）；
    - DS18B20：室温水应显示接近实际水温；显示 25.0 且 CSV src=FIX → 传感器没通
      （08 T2）；T24.5 可手输兜底。
9.2 第二步：基线 + 假执行器（08 T5/T7）
    - 探头浸在本底水（自来水）中，发 B（或长按 K2 ≥1.5 s）采基线；
      OLED 显示 "BASELINE n/20"，串口 "# BASELINE start/OK"；
    - 发 R 开始事件 → 观察 OLED 大字"冲洗"→"清水"、LED1 状态、串口 state/action；
      L2 时 OLED 反显"污水"、LED1 灭（假执行器"排空"）；
    - 全程 P104 不动作（APP_USE_VALVE=0）——先用 LED 把状态机跑通。
9.3 第三步：对照 08 逐项验收
    T0 上电自检 → T1 串口链路 → T2 DS18B20 → T3 TDS → T4 浊度 → T5 基线 →
    T6 判据小实验 → T7 状态机/假执行器 → T8 故障与 fail-safe → T9 稳定性 →
    T10 OLED 状态页（含 0x3D 故障注入）。
    接线相关的前置项：08 §2（上板前检查）与本文 §8.2 是同一套检查（本文覆盖 08 §2
    并补充 6 项），做一次即可。

【11】红线与已知限制（写报告/答辩必须如实说）
------------------------------------------------------------------------
11.1 电气红线（违反会烧 ADC/烧板，或答辩被扣分）
    ① 3.3V 逻辑：模拟输入绝对最大 3.6V；5V 输出必须分压/钳位后才可进 MCU；
       P206/P407/P408/P409 是仅有的 5V 容忍脚，其余都不耐 5V。
    ② 5V 外设一律从 VIN（U2-19/20）取电、与板同开同关；禁止外部 5V 灌 VIN、
       禁止电脑 USB 与 5V 适配器同时给板供电；阀的 12V 必须独立供电。
    ③ 板子是借的、赛后收回：只接排针/端子，禁止割线、焊死、拆焊 OLED/CH340E/LDO。
    ④ 上电前必量：TDS AOUT ≤2.4V、分压节点 ≤3.2V、3V3=3.25~3.35V、VIN=4.5~4.7V；
       断电时 3V3/5V 对 GND 电阻 >1 kΩ（无短路）。
    ⑤ 上电先"排空"：固件第一步把 P104 置低；硬件 P104 与 GND 之间加 10 kΩ 下拉；
       接真阀时这个下拉不得省略（复位/配置完成前 P104 是高阻，靠它守住"不动作"）。
    ⑥ 湿电分离：电气在防水盒/干燥区，线缆做滴水弯，漏水盘在电气下方；12V 线远离水。
    ⑦ 任何"新想法"先过 08 验收再上水；一次只改一处，改完重测（§8.2）。
11.2 已知限制与待实测项（如实记录，⏳ 在到货/装机时逐条清掉）
    - U1-20 丝印存疑（原理图标 3V3、板背疑 VIN）：⏳ 先别用，3.3V 一律走 U1-12；
    - 板载 LDO 的实际电流余量 ⏳（按 3.3V 侧 60~90 mA 估算，待满载实测）；
    - 浊度模块是 4 针 G/A/D/V + 4 线探头：D（DO）悬空、电位器不动、探头必须原配；
      AO 满量程（≤4.7V 用 1k+2k；独立 5V 时 5.0V 才改 R2=1.5k）与方向 ⏳ 到货先实测；
    - 继电器模块的有效电平（高/低触发）以实测为准，⏳ 30 秒验证法确认后再改固件；
    - 12V 三通阀的断电方向、通径、连续通电温升 ⏳（见《硬件搭建方案》§6）；
    - 本阶段**不接真阀、无流量计**：LED1 为假执行器，P104 钩子默认关闭；
    - 无 NTU 标定：浊度只输出相对量；TDS 无标准液时不报绝对 ppm（红线见 08 §15）；
    - 探头污染/气泡/结垢会漂移：可拆洗、间歇采样、每次实验前重采基线；
    - 酒精免洗凝胶是 ΔEC+浊度双盲区：写进"已知局限"，不得声称"识别所有污染物"。

   11 12V/3A 适配器、2A 保险丝+座、船型开关、端子排  │ 12V 回路

 明确不买（省钱且避免踩坑）：
   - 5V→3.3V 降压模块（板载 LDO 够用，5V 外设直接接 VIN）；
   - 电平转换模块（3.3V 与 5V 之间本项目只有浊度 1 路，1k+2k 分压即可）；
   - TS-300B 3 针一体化探头 / 另买第二套探头（与 4 针模块的 4 线探头不通用）；
   - PCB 打板/工业浊度/第二块 TDS/12V 水泵（本阶段不需要）。
