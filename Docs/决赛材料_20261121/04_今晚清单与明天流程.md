## 三、14:00–17:00 验收现场：怎么打这一仗

### 3.1 工位布置（评委走到你桌前，30 秒内要能看懂）

```
[ 绿桶 回收 ]   [ 灰桶 排空 ]     ← 桌下或桌侧，A4 大字
        ↑ 三通阀
[ 装置/腔体 ]  [ 接水盘 + 毛巾 ]
[ 电路板（远离水路，接口朝下）]  [ 笔记本：串口日志 + PPT ]
```

- 屏幕常驻一页：串口 `# TIP` 滚动（评委很吃这套，能看见"为什么切"）
- OLED 停在 P1（水质页）；需要时切 P2（执行器页）
- 桌上只放：装置、两个桶、笔记本、一张数据卡。**其他杂物全部收进箱子。**

### 3.2 评委来了，按这 4 步走（每步一句话）

1. **一句话定位**（10 s）："这是一台给洗手水做在线判别、再决定去回收桶还是排空桶的装置。"
2. **看一次完整动作**（60–90 s）：注清水 → 屏上 `Clear` → 阀切回收 → 加皂液 → `Soap` → 切排空。
3. **指向证据**（30 s）："串口这一行是电导增量，这一行是浊度增量；两路同时越限才判肥皂。"
4. **主动交底**（30 s）："腔体大所以慢，肥皂进入后约 1.6 秒内可能漏一点，基线还没掉电保存——这些都在我们的边界页。"

> 评委通常只给 3–5 分钟。**不要从头讲原理**，先给动作，再给证据，最后给边界。

### 3.3 三套预案（写卡片上，放口袋）

| 预案 | 触发条件 | 做法 |
|---|---|---|
| **A 实机** | 自检通过、阀向正确、不漏水 | 按 3.2 走 |
| **B 视频 + 静态** | 自检连败 2 次 / 阀向反 / 漏水 / 串口无输出 | 播 2 min 视频；实物只手动演示 `V1`/`V0` 与 OLED |
| **C 只讲数据** | 设备完全不可用 / 场地不给水 | 用 PPT 曲线 + 日志截图讲，明说"设备在现场出了 X 问题，数据是昨晚实测" |

**切换纪律**：A→B 最多尝试 **2 分钟**；不现场改代码、不现场烧录、不现场拆管。

### 3.4 五条现场禁忌

1. 不要真洗手（溅到继电器/板子），用挤水瓶。
2. 不要让水在桌上流向插排/电源。
3. 不要在评委面前纠结报错超过 10 秒，直接切预案。
4. 不要说"再等 30 秒就好"——大腔体确实慢，但要提前说，不要现场等。
5. 不要说"这个我们回去改"——说"已记录，是下一步"。
