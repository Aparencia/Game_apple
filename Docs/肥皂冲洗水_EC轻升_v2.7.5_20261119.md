# 肥皂冲洗水“只升 EC、不升 NTU”的处理（v2.7.5-B3）

- 日期：2026-11-19
- 固件：`SENSOR-NODE v2.7.5-B3`
- 构建：`text 84684 / data 480 / bss 11440`，0 error / 0 warning
- 基于：`v2.7.3-B3`

---

## 1. 更正：基线确实是清水

现场确认：除了最后一次，其余都是清水；基线采集也是清水。

因此 v2.7.4 把 AO 清洁门槛从 250 抬到 300 是**错误方向**：

```
清水 AO-AO_DRY ≈ 244 mV（2581-2337）
```

300 会把这次清水基线直接拒掉。v2.7.5 恢复：

```c
.ao_clean_delta_mv = 250.0f
```

---

## 2. 最后一次肥皂冲洗水的真实数据

最后一次注水（19:15:47~19:16:07）：

| 项 | 数值 |
|---|---|
| 基线 RECOVER | 553.0 mV |
| 肥皂冲洗水 EC | 580.5~594.7 mV |
| dEC | **+25.5~+31.5 mV（约 +5.4%）** |
| dNTU | **+0.6~+1.0%** |
| 状态 | CLEAR/L0 |

旧 d1：

```
d1 = 6% × 553 = 33.2 mV
+30 < 33.2 → L0 → CLEAR
```

所以它被判成清水，不是基线错，是 **EC 上升只有 5.4%，刚好在 6% 门限内，而且浊度没有信号**。

---

## 3. 为什么“肉眼浊度明显”但 dNTU 不升

- 肥皂冲洗水可能是**泡沫/气泡**，不是悬浮颗粒；
- TS300B 测的是透射/散射光，泡沫在液面或气泡附着探头时，读数可能不升反降；
- 这次 dNTU 只有 +0.6~1.0%，传感器确实没有看到“浊度”。

软件不能把“肉眼看到的泡沫”变成 NTU 信号；只能依靠 EC 的轻升。

---

## 4. 修复：d1 6% → 5%

```c
.ec_d1_pct = 5.0f
```

对最后一次肥皂水：

```
d1 = 5% × 553 = 27.7 mV
+30 > 27.7 → L1/UNCERT/DRAIN
```

- 不会再判 CLEAR、不会回收；
- 但也不会标 SOAP，因为 dNTU 没升，双通道 L2 不成立；
- 真正的肥皂水（EC 和 NTU 同时升）仍然走 L2。

---

## 5. 预期行为

| 水样 | EC | dNTU | 结果 |
|---|---|---|---|
| 清水 | 接近当前槽 | <7% | CLEAR/L0 |
| 这次肥皂冲洗水 | +5.4% | +0.6~1.0% | **UNCERT/L1/DRAIN** |
| 典型肥皂水 | +10% 以上 | +10% 以上 | SOAP/L2 |
| 失水 | 快速下降 | 冲高 | DRY/LOCKOUT |

---

## 6. 如果一定要把“EC 轻升”标成 SOAP

可以把 EC d2 降到 5%（约 27.7 mV），但会带来：

- 清水液位/温度造成的 +5% 也会被标 SOAP；
- 与之前 FULL 333 的 EC-only 假 SOAP 同类问题。

当前选择是：**EC 轻升 → L1/排空（安全，但不标 SOAP）**；  
**只有 NTU 也升，才标 SOAP/L2。**
