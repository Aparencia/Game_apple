# HC-SR04 液位接入 M1（2026-11-19）

- 固件：`SENSOR-NODE v2.8.0-LEVEL-M1`
- 构建：`text 85608 / data 480 / bss 11492`，0 error / 0 warning
- 分支：`sensors-level-flow`
- 基线：`v2.7.6-B3`

---

## 1. 实现方式

标准四针 HC-SR04：

| 信号 | 引脚 | 说明 |
|---|---|---|
| TRIG | **P402 / U1-2** | 3.3V GPIO 输出，外部电平转换到 5V |
| ECHO | **P409 / U2-3** | IRQ6，5V 容忍；串 1k 直接进 |
| VCC | 5V / U2-19/20 | 约 15mA |
| GND | GND | 共地 |

- 不使用 GPT；
- Echo 上升/下降沿 IRQ6；
- **DWT CYCCNT** 测脉宽（180MHz，约 5.5ns 分辨率）；
- 非阻塞：每 100ms 触发一轮，主循环 50ms 不被卡住。

## 5. 上电预期

```
# [BOOT] SENSOR-NODE v2.8.0-LEVEL-M1
# hc-sr04: ready (TRIG=P402/U1-2, ECHO=P409/U2-3 IRQ6)
...
# LEVEL t=1000ms mm=... valid=1
```

- 无回波/超时：`valid=0`；
- 液位值 20~2000mm 限幅；
- 3 次中值。

### 现场第一次上电现象（已修复）

日志在 `# LEVEL` 处只打出 `# LE` 就重启：

```
[20:41:40] # LE
[20:41:50] # [BOOT] ...   ← 复位
```

原因是 **IRQ6 状态位没有清**：`IELSR[9].IR` 一直有效，边沿 IRQ 反复重入，
主循环被饿死/看门狗复位。

修复：

```c
R_ICU->IELSR_b[9].IR = 0U;   /* ISR 末尾清 IRQ 状态 */
```

烧录 M1a 后不再重启，但 `# LEVEL` 全为 `valid=0`，说明 Echo 没有形成有效回波/边沿。

### M1b 诊断字段

```
# LEVEL t=... mm=... valid=... trig=... edge=... rise=... fall=... to=... us=...
```

判断：

| 现象 | 含义 |
|---|---|
| `trig` 不增长 | 主循环没跑到 / 任务被卡 |
| `trig` 增长、`edge=0` | Echo 没到 P409：Trig 没触发/接线/电平/传感器 |
| `edge>0`、`rise/fall` 不增长 | IRQ 进入但边沿识别异常 |
| `rise/fall` 增长、`us=0` | DWT 没计数 |
| `us` 有值但 `valid=0` | 脉宽超范围（<100µs 或 >25ms） |
| `valid=1` | 正常 |

### M1b 现场数据（关键发现）

```
trig=3711 edge=5574 rise=2787 fall=2783 to=962 us=38736
```

- `trig` 10/s、`edge` 20/s：触发和 Echo IRQ 都正常；
- `rise/fall` 基本相等：双边沿都进；
- `us=28000~70000` 不是脉宽，是 **DWT 原始周期数**。

根因：ISR 把 `DWT->CYCCNT` 差值直接当 `us`，忘记除以
`SystemCoreClock/1e6`（180）。

修复 M1c：

```c
uint32_t cycles = g_pulse_cycles;
uint32_t us = cycles / g_cycles_per_us;
```

按 180MHz 换算：

```
28000~70000 cycles → 155~390 µs
→ 2.6~6.7 cm
```

这说明探头前方确实有近距离回波/遮挡物；修复后应得到 `valid=1`。

## 6. 接线注意

- **Echo 5V** 直接到 P409（5V 容忍），串 1k；不要再分压到 3.3V 以下导致误判；
- **Trig** 不能直接 3.3V 硬撑：HC-SR04 VIH≈3.5V，需 74LVC1T45 或 NPN/2N7002 电平转换；
- 5V 从 U2-19/20 取，共地；
- 探头装最高水位以上，薄 PE/PTFE 声学窗，别厚灌封；
- 泡沫会导致 HC 误判，这是下一步 M2 要处理的。
