# 液位 + 微型流量计扩展计划（2026-11-19）

- 基线：`v2.7.6-B3`
- 分支：`sensors-level-flow`
- 目标版本：`v2.8.0-SENSORS`
- 原则：**先加传感器做状态/时序，不立即改水质阈值；保留 v2.7.6 作为回退**

---

## 1. 目标

新增：

1. **HC-SR04 液位**（防水改装，空气超声）
2. **微型流量计**（主水路，脉冲输出）

用途：

| 传感器 | 用途 |
|---|---|
| 液位 | 判断空腔/进水/满水/排水；稳定液位才允许标定/分类 |
| 流量 | 测传感器→阀的传输时间/死区体积；用累积流量替代固定 blank_ms |
| 融合 | 液位变化 vs 流量积分互相校验；发现泡沫/气堵/堵塞 |

**不承诺**：
- HC-SR04 一定能穿透泡沫；
- 流量计能测水质；
- 一步解决清水/肥皂分类。

---

## 2. 硬件

### 2.1 HC-SR04

```
VCC   5V
GND   共地
TRIG  3.3V GPIO（建议经 74LVC1T45 或三极管电平转换）
ECHO  5V 脉冲 → 1k/2k 分压 → 3.3V → GPT 输入捕获
```

- 探头装在最高水位以上，只测空气路径；
- 防水：薄 PE/PTFE 声学窗 + 背面密封，**不要厚灌封探头正面**；
- 加干燥剂/透气阀防冷凝；
- 5V 供电电流约 15 mA。

### 2.2 微型流量计

```
5V / GND
脉冲输出（开集/霍尔）→ 10k 上拉到 3.3V → IRQ 或 GPT 计数
```

- 必须串在**主水路**，不能旁路；
- 上游加过滤（皂垢/颗粒会卡涡轮）；
- 量程覆盖实际流量（例如 0.1~1 L/min）；
- 记录 K 因子（pulses/L）。

### 2.3 引脚/资源审计（第一步，未定死）

当前已用：

| 功能 | 引脚/资源 |
|---|---|
| TDS | P014/AN12 |
| 浊度 | P013/AN11 |
| DS18B20 | P500 |
| UART9 | P109/P110 |
| OLED IIC0 | P407/P408 |
| 阀继电器 | P104 |
| LED | P111 |
| K2 | P000 |

待选：

- HC TRIG：普通 GPIO；
- HC ECHO：必须是 **GPT 输入捕获** 引脚；
- 流量计：外部 IRQ 或 GPT 计数引脚。

> 需要对照 RA4M2_MINI 排针/原理图确认可用引脚，避免与板载功能冲突。

## 3. FSP 配置

新增：

1. **GPT 通道 A**：1 MHz 自由运行，用于 HC-SR04 Echo 输入捕获（上升/下降沿）；
2. **IRQ 通道**：流量计脉冲（或第二 GPT 计数）；
3. 引脚配置：Trig 输出、Echo 输入、Flow 输入；
4. 中断优先级：Echo/Flow 高于 50 ms 主循环，低于阀/安全；
5. 5V/3.3V 电平：Echo 分压、Trig 电平转换。

如果找不到 GPT 输入捕获引脚：

- 备选 1：用 **JSN-SR04T**（UART 版，避开捕获）；
- 备选 2：用 ICU/外部中断 + 硬件定时器；
- 备选 3：改用压力式液位（模拟 ADC）。

## 4. 软件模块

### 4.1 `hc_sr04.c/h`

接口：

```c
void hc_sr04_init(void);
void hc_sr04_task(uint32_t now_ms);      /* 非阻塞，10~30 ms 触发一次 */
bool hc_sr04_get_mm(uint16_t *p_mm, bool *p_valid);
uint32_t hc_sr04_age_ms(void);
```

实现：

- Trig 10 µs 脉冲；
- GPT 捕获 Echo 上升/下降，算脉宽；
- 距离 `mm = pulse_us × 0.343 / 2`（按 DS18B20 温度修正声速）；
- 中值/限幅：20~2000 mm，超时/无回波置 invalid；
- 不阻塞主循环。

### 4.2 `flow_meter.c/h`

接口：

```c
void flow_init(void);
void flow_task(uint32_t now_ms);
float flow_lpm(void);
float flow_total_ml(void);
bool flow_valid(void);
bool flow_no_flow(uint32_t ms);
```

实现：

- IRQ 计数脉冲；
- 每 1 s 算 L/min；
- 累积 mL（K 因子）；
- 最小流量以下置 0/无效；
- 断流超时。

### 4.3 融合/状态

```c
typedef enum { LV_EMPTY, LV_FILL, LV_STABLE, LV_DRAIN } level_state_t;
```

规则：

```
level < 10 mm          → EMPTY
level 上升 > 5 mm/s    → FILL，不分类
|rate| < 1 mm/s 稳定   → STABLE，允许 MEASURE
level 下降 > 5 mm/s    → DRAIN，不分类
```

与现有 gate 的关系：

- 液位 STABLE 才允许 `MEASURE`；
- 标定只在 STABLE 且与实际运行液位一致时做；
- 液位变化时禁止 `app_baseline_trim_task()`；
- 流量为 0 但液位在涨 → 泡沫/假回波；
- 流量 >0 但液位不动 → 气堵/堵塞。

## 5. 时序校准

### 5.1 死区体积/传输时间

```
V_dead ≈ ∫ Q dt
t_transport ≈ V_dead / Q
```

用清水→肥皂水阶跃，记录：

- 流量 Q(t)
- 传感器 EC/NTU
- 阀命令/实际位置

### 5.2 用累积流量替代固定 blank_ms

```c
阀切换后：
  累计流量 < 2×V_dead → 冻结判别
  累计流量 ≥ 2×V_dead → 允许分类
```

保留 `blank_ms` 作为流量无效时的兜底。

## 6. 数据/协议

不直接改现有 17 列 CSV，先加事件行：

```
# LEVEL t=... mm=... state=... valid=...
# FLOW  t=... lpm=... total_ml=... valid=...
# SENSOR level=OK/INVALID flow=OK/NOFLOW
```

验证稳定后，再升级 CSV 到 19/20 列：

```
...,level_mm,flow_ml_min
```

并升协议版本，避免旧解析器错位。

## 7. 标定流程

1. **液位零点**：空腔，记录 HC 距离/偏移；
2. **液位量程**：用直尺/定容，记录 50/100/150 mm 对应值；
3. **流量 K 因子**：量杯 + 秒表，`K = pulses / mL`；
4. **死区体积**：关闭阀，积分流量到传感器响应；或注水计量；
5. **阀延迟**：命令→流量计检测到流动；
6. 写入常量/命令（先编译常量，后续加 `L`/`F` 命令）。

## 8. 测试/验收

### 台架

- 液位 0/50/100/150 mm：误差 ≤5 mm；
- 流量 0.1/0.3/0.5 L/min：误差 ≤5%；
- 阀切换：流量计能检测开/关，延迟可重复；
- 泡沫层：记录 HC 是否跳变、流量是否正常；
- 5V/3.3V 电平、EMI（阀/继电器动作）不误触发。

### 现场

- 清水：液位 STABLE → CLEAR；
- 肥皂冲洗水：不因液位/流量误判；
- 失水：快速 DRAIN/DRY；
- 与 v2.7.6 日志对比，确认无回归。

### 验收

- 液位/流量事件行稳定；
- 标定只使用 STABLE 液位；
- 阀切换后按累积流量开窗；
- 清水不再因液位平台横跳；
- 原有 EC/NTU 判定阈值不变（第一阶段）。

## 9. 风险

| 风险 | 缓解 |
|---|---|
| HC-SR04 泡沫误判 | 流量交叉校验；必要时换压力式 |
| 5V Echo 损坏 MCU | 分压+钳位，先测电压 |
| GPT 捕获引脚冲突 | 先做引脚审计；备选 JSN-SR04T |
| 流量计堵塞/低流量不转 | 过滤、选小量程、最小流量判断 |
| 流量计增加阻力 | 选通径足够、旁通维护 |
| 协议变更 | 先事件行，后 CSV 升版 |
| 标定/运行液位不一致 | 液位稳定门控 + 标定记录液位 |
