## 1. 立意：这个想法到底新在哪

### 1.1 想法的原始形态（最初的直觉）

> "有时从上完厕所出来会洗手，但是往往会多用水。"

最初的方案只是**"节水"**：检测到有人洗手就控水、限流、缩短出水时间。**这条路的致命问题是——它太容易被做出来，也太容易被看穿。**

- 红外感应 + 限时出水 = **市售感应龙头二十年前就有了**，评委一句话就能问倒："你和九牧的感应龙头有什么差别？"
- 而"省水"的叙事在水利类赛事里已被反复做过（第八届《基于 STM32 单片机的马桶智能优化设计》二等奖即此类）；
- 更关键：**限流本质上是在限制使用者的体验**——多用水有时恰恰是必要的（冲掉皂液需要足够水量）。

### 1.2 升级后的立意（当前采用）

> **问题的本质不是"用水多"，而是"没必要回收的水被混在一起排掉了"。**

洗手用水的**水质随时间剧烈变化**：刚出水时是**准清水**（管道滞留水，略有温升），中段进入**皂液水**（表面活性剂 + 皮脂 + 悬浮物），末段又接近清水（冲洗残留）。**现行做法是不加区分的全量排入下水道。**

于是立意从"**少用水**"改成了"**别把还能用的水当废水倒掉**"：

| 维度 | 原立意（限流节水） | 现立意（选择性回收） |
|---|---|---|
| 动作 | 限制出水（减少供给） | **判别 + 分流（改变去向）** |
| 电子含量 | 红外 + 定时器（几乎为零） | **在线判别算法 + 阀控闭环 + 标定数据** |
| 答辩天花板 | "和市售产品有什么不同？" | "**你凭什么判定这杯水能回用？**"（← 这个问题你能拿出实验数据回答） |
| 与"多用水"矛盾 | 直接冲突 | **不冲突**——皂液水该冲就冲，只回收不该浪费的那部分 |

**一句话**：从"**管住水龙头**"变成"**给水做一次在线化验，再决定它去哪**"。

## 2. 一句话定义（对外口径，答辩时直接用）

> **本作品是一台"洗手水在线判别与选择性回收装置"：以 RA4M2 为核心，用电导率的相对基线增量 ΔEC（为主）配合浊度、水温与时序趋势在线判别洗手水的瞬时水质，驱动三通阀把判定为"可回用"的水引入回收水箱（供冲厕/拖地/绿化），把判定为"含皂液"的水排入下水道；判据参数由本队实测标定给出，全过程数据留痕。**

- **传感链**：电导率 + 浊度（+ 水温 + 流量）
- **判别层**：RA4M2 —— 滑窗滤波 → 温度补偿（片上 TSN）→ **相对基线增量 ΔEC + 双阈值迟滞 + 时序状态机**
- **执行链**：三通电磁阀（或两阀组合）分流 → OLED 现场显示 + 串口/无线记录
- **量化指标**：**ΔEC 与测量波动的分离余量（倍）**、判别正确率、分流响应时间、回收水量与回收率、装置功耗（见第 6 节实验设计）

## 3. 可行性：先说结论，再说凭什么

**结论：可行，且是本队（3 名水务工程大一新生 / 5 周 / ≤800 元）**目前找到的**专业契合度与技术亮点最平衡**的方向。但它有**一个必须先验证的赌注**：**电导率增量（ΔEC）能不能显著大于测量波动**。

可行性由**四条独立理由**支撑——注意它们的证据强度不同：

| # | 理由 | 证据强度 | 依据 |
|---|---|---|---|
| 1 | **场景真实且有专业依据**：洗手/洗浴水回用于冲厕是再生水利用的常规做法，非杜撰 | 🟢 **事实** | 城市污水再生利用系列国标设有杂用水（冲厕/绿化/道路清扫）水质要求，见第 6.4 节指标表 |
| 2 | **该场景已被赛事验证可达奖**：水利创新设计大赛有洗手废水回收类二等奖先例 | 🟢 **事实** | 第九届《改性凹凸棒石三级滤层耦合重力驱动的洗手废水再生系统》河西学院 **二等**（**公开可核实的只有作品名称、名次与学校**） |
| 3 | **但先例走的是材料学路线，留下了电子空位**：公开的凹凸棒石过滤装置专利为**纯机械结构，无电子、无在线监测、无自动控制** | 🟢 **事实**（专利文本已核） | 实用新型 CN213468060U |
| 4 | **"在线判别 + 分流"在 RA4M2 能力范围内**：12 位 ADC 采集、阈值判别（可硬件窗口比较）、PWM/GPIO 驱动阀、I²C/SPI 显示、SCI 记录，均为本平台成熟外设，无需摄像头/NPU/云 | 🟢 **事实（芯片级已核实）** | 本机官方 SVD：`ADC120`(12-bit)、`TSN`(片上温度→ADC12)、`DAC12`、`CTSU`、`ADCMPCR`(窗口比较)、`ADCER`(自诊断)；**平台能力边界（内联）**：RA4M2 = 100 MHz Cortex-M33 + FPU / TrustZone，512 KB Flash、128 KB SRAM，有 ADC/DAC/I²C/SPI/SCI/CAN/USB/低功耗，**无摄像头接口、无以太网、无 NPU** → "采集 + 判别 + 显示 + 告警 + 低功耗"是甜蜜区，**视觉识别与 AI 推理是死路** |

### 3.1 反面：它为什么**可能不行**（必须先看这里）

| 风险 | 具体表现 | 后果 | 对策 |
|---|---|---|---|
| 🔴 **判别失败（头号风险）** | **皂液引起的电导率增量只有数十 μS/cm 量级**（已核实），可能被测量波动淹没；且自来水本底地域差异大，绝对阈值不可移植 | 整个立意塌掉——"你凭什么判"答不上来 | **第 6 节实验先行，零采购验证**；**改用相对基线增量 ΔEC + 时序趋势 + 上电自校准**；准备第 7 节降级方案 |

## 4. 边界与红线（新会话最需要知道的"不要重新纠结"）

### 4.1 已经排除、不要再捡回来的路线

| 已排除 | 为什么 |
|---|---|
| ❌ **滤料/吸附材料研发**（凹凸棒石、活性炭配方、改性） | 那是材料学主场（先例已用二等奖占位），我们在 5 周内**做不过、也不需要做** |
| ❌ **全量过滤净化 → 出水达饮用水标准** | 工作量与验证成本远超预算，且需要水质检测试剂/仪器 |
| ❌ **化学试剂法测水质**（COD、余氯、硬度滴定） | **本队已判定为死路**：需持续耗材、重复性差、5 周内做不出可靠数据，答辩会被问穿 |
| ❌ **膜处理 / 反渗透 / 紫外消毒** | 成本与安全（紫外伤眼）都不可控 |
| ❌ **云平台 / App / 数字孪生** | 5 周做不完，且与"现场可演示"无关 |
| ❌ **摄像头视觉判浊 / AI 推理** | RA4M2 **无摄像头接口、无 NPU**（能力边界见第 3 节理由 4） |
| ❌ **靠限流/红外感应节水** | 市售产品已有，无创新性（见 1.1） |

### 4.2 保留但不作为主线的（只在时间有余时加）
| 可选项 | 加它的价值 | 加它的成本 |
|---|---|---|
| 用 **RA4M2 片上温度传感器（TSN）**做电导率的温度补偿 | 工程正确性 + "用足芯片外设"的证据 | **零成本**（✅ 已核实芯片内置，省掉 DS18B20；且补偿本身是必需项） |
| **ADC 硬件窗口比较（ADCMPCR）**做阈值判别 | 越过阈值直接产生比较中断，不必软件轮询；**"用足芯片外设"的硬素材** | 低（寄存器配置） |
| **ADC 自诊断（ADCER）**做采集通道自检 | 直接对应答辩加分项"传感器失效怎么办" | 低 |
| **12 位 DAC 输出 4~20 mA** 标准工业信号 | 一句话证明懂工业接口 | 极低（零成本） |
| **低功耗模式**（间歇采样 + 传感器断电） | 官方认可的加分项（电赛 2017 P 题把工作电流写成硬指标） | 中（需实测电流） |
| **流量计**（霍尔脉冲）用于回收水量计量 | 让"回收了多少水"可量化 | 中（多一个器件、多一条标定线） |
| **CTSU 电容触摸**做液位/按键 | 探头不接触介质；但**做液位需自证**（瓷盆/接地/皂液膜耦合稳定性） | 中高（**不建议作为主线**，可做按键） |
| **ESP8266/ESP32 上报数据** | 数据留痕更好看 | 中（会挤占时间，非必需） |

## 5. 与先例的差异化：我们凭什么拿分

### 5.1 先例速览（2025 第九届全国大学生水利创新设计大赛，二等奖，河西学院）

### 6.2 判别逻辑（⚠️ 已按核验结论改造：**相对基线增量 + 时序趋势**，不再是绝对阈值）

> **为什么改**：独立核验发现两条硬约束（见 6.4 第 10–12 条）：
> ① **皂液的电导率增量很小**（按权威实测配比，真正的强电解质只有 SDS 140 mg/L + NaCl 10 mg/L，属**数十 μS/cm 量级**，不是数量级差异）；
> ② **自来水本底电导率地域差异大**，且**国标不设电导率限值** → **绝对阈值换地点即失效**。
> **所以判据改成"相对量 + 趋势"，并且这个改造本身就是答辩亮点**（"我们发现绝对阈值不可移植，改用基线相对判据 + 上电自校准"）。

```
上电/待机
  ▼ ① 自校准：读取管路静水本底的 EC₀（与温度 T₀）
     —— 解决"阈值不可移植"：换地点、换季节都自动重新定基准
     ⚠️ 第 3 版补：刚开龙头的最初 1~2 s 水（管道锈水/滞留水）
        强制排空、【不参与基线、不回收】——否则把"本底"测成了"脏水"
  ▼ 触发（按键/红外/流量突变）
  ▼ ② 采集：每 50~100 ms 一组（⚠️ 不再是 200 ms），中值(3) + 轻量 EMA
      计算相对增量 ΔEC = EC − EC₀；同步读浊度 T、水温 θ
  ├─ ΔEC < Δ₁ 且 浊度 < T₁ 且处于清水/收尾阶段 → 判为【L0 可回用】→ 阀切回收
  ├─ ΔEC > Δ₂（或浊度突增 / 变化率 dΔEC/dt 超限）→ 判为【L2 应放弃】→ 阀切排空
  └─ Δ₁ ≤ ΔEC ≤ Δ₂                     → 判为【L1 不确定】→ 默认排空（安全侧）
  ▼ ③ 消抖：改成"同一时间块内 3 次一致"（≤200 ms），⚠️ 不再用"连续 M 个采样"
       ⭐ 且【变化率抢先触发】：dΔEC/dt 超限立即动作，不等绝对值确认
  ▼ ④ 冲洗收尾段：ΔEC 回落并持续 X 秒 → 回到"可回用"分支
  ▼ ⑤ 超时冲洗：水流停止 N 秒仍有余水（截留腔方案）→ 强制排放，防积存
```

#### 6.2.1 ⭐ 时间预算（第 3 版新增：本方案的隐藏门槛）

> **为什么必须补这一节**：单次洗手只有 **10~30 s**，龙头流量约 **4~8 L/min** → **1 s 的判定延迟 ≈ 白分流 70~130 mL 水**。
> 因此**"判得多准"必须和"多快做决定"一起设计**——原第 6.2 节的"滑窗 N=5 + 连续 M 次一致"，照字面实现**光消抖就会超过 1 s**。

| 环节 | 预算 | 实现手段 |
|---|---|---|
| ADC 采样与滤波 | **≤100 ms** | 50~100 ms/组；中值(3) + EMA，**不用 N=5 长窗** |
| 特征计算 | ≤50 ms | 增量式计算，不重算全窗口 |
| **触发判定** | **≤300 ms** | **变化率抢先触发**（皂液到来是阶跃，先判"变了"再判"变成什么"） |
| 消抖确认 | ≤200 ms | **同一时间块内 3 次一致**（不是连续 5 个采样） |
| 阀动作 | **≤100 ms** | 低惯量直动阀 + 12 V 足够瞬时驱动电流 |
| **合计** | **≤1.5 s（力争 ≤0.8 s）** | 折算误分水量 **≤100 mL**（占单次水量 1~3 L 的 3%~10%） |

**三个"不靠堆时间"的准确性来源**：
1. ⭐ **变化率优先**：判"突变"比判"绝对值"早得多；
2. ⭐ **利用"关水揉搓"这个天然分段点**：涂皂时大多会关水 → **水流中断本身就是最强的阶段标记**；
3. ⭐ **轴向缓冲（水力延迟线）**：探头放阀**上游**并留一段管路（0.5~1 m、内径 8 mm ≈ **25~50 mL**）→ **物理上白送判定时间**（长度/容积待实测）。

**🟡 可选架构：截留腔 + 批式判别（把"边流边判"改成"一批一判"）**

| 项 | 内容 |
|---|---|
| 做法 | **100~200 mL 小腔体**截留一批水 → **静止时测量**（无流动噪声、无气泡）→ 一批一判 → 闸门放行（按判定决定去向） |
| 好处 | **判定时间从 0.1 s 拉到 1~3 s**；单批内可多次平均；与真实工程"**调节池 + 批式处理**"同构，答辩可写"**批式判别**" |
| ⚠️ 尺寸两难 | **太大 → 一批水混了清水和皂液，反而判错；太小 → 判定频次过高、阀寿命吃紧** → 目标每批 **100~200 mL（约 1~3 s/批）**，⚠️ 具体值必须实测标定 |
| 🔴 传感器选型红线 | **不要用普通压力传感器**：h=30 mm 水柱 ≈ **0.29 kPa**，而常见量程 **100 kPa 级**（0.3% F.S.，分辨率完全不够）→ 改用**浮子/光电液位开关**（最省）或**腔体称重**（兼做回收水量计量）；坚持用压力则必须选 **±1~2 kPa 微压差**并实测验证 |
| 🔴 必补三件 | ① **溢流旁通**（腔体上部溢流口直通下水道，不经阀 → 阀卡死也不积水）；② **超时冲洗**（否则最后一批 50~100 mL 残水无人触发、积存发臭）；③ 每批**排空不存水**（电极长期泡静水会加速结垢，厂商仅保"间歇采样"） |

#### 6.2.2 ⭐ 污染源不止"皂液"（第 3 版新增）

> **关键认知**：**传感器不认识"洗手液"，只认识"电离 / 遮光 / 氧化还原"三件事。** 所以污染源要**按物理化学类型分**，不能按商品名分。

| 类别 | 典型来源 | ΔEC | 浊度 | ORP | 主要判据 |
|---|---|---|---|---|---|
| **A 电解型**（离子） | **皂基皂**、**84 消毒液**（次氯酸钠）、汗液/尿液、**管道锈水** | 🔴 强 | 弱 | 中（84 极强） | **ΔEC** |
| **B 非电解型**（醇/油脂） | **酒精免洗凝胶**、甘油、皮脂、**合成洗手液** | 🟡 **弱/无** ⚠️ | 中 | 中（耗余氯） | **阻抗 C 分量**（可选） |
| **C 颗粒型** | 尘土、泥沙、铁锈、毛发纤维 | 🟢 无 | 🔴 强 | — | **浊度** |
| **D 化学型**（还原/氧化） | 皂液（耗余氯）、84、亚铁离子 | 中 | 弱 | 🔴 强 | **ORP**（可选） |

> **由此修正一句旧表述**："**我们测的是皂液**"其实不准确——皂基皂属 A、合成洗手液属 B+D。准确的表述是：
> **"我们测的是这一段水相对本底的理化性质偏离"**。**本方案只测"偏离"，不测"是什么"**（→ 9.1 红线 6）。

**⚠️ 四个必须点名的判据盲区**：

| # | 盲区 | 后果 | 对策 |
|---|---|---|---|
| 1 | 🔴 **酒精免洗凝胶**（非电解质 + 透明） | ΔEC 与浊度**同时无响应 → 会被判成"清水"回收**（最危险） | **主动写进"已知局限"**；有余力用**阻抗 C 分量/ORP**；**场景隔离**（免洗凝胶本不需水冲洗） |
| 2 | 🔴 **管道锈水**（刚开龙头的最初 1~2 s） | **把"本底"测成"脏水" → 整条基线与判据全歪** | **最初 1~2 s 强制排空，不参与基线**（纯软件，P0） |
| 3 | 🟠 **纯油脂** | 判成清水 → 回收了含油水（拖地场景明显） | 光学 + 场景隔离 |
| 4 | 🟠 **毛发/纤维** | 对任何判据都无信号，但**物理上已经要堵了** | **只能物理防护**（滤网 + 可拆洗），不指望传感器 |

> **方法论（本版最重要的产出之一）**：**判据不是"识别污染物"，是"发现偏离"。** 因此必须承认：**未知污染源 + 无响应 = 可能被误回收** → 工程上唯一解法是**拿不准一律默认放弃**（6.2.3 的 L1）。
> **速查结论**：没有任何单一判据覆盖四类；而 **"时序/阶段"是唯一对四类都有效的维度**（6.2 设计要点 5 的地位因此上调）。

#### 6.2.3 ⭐ "污染程度"怎么定义（相对量，不是绝对值）

> 因为 🔴 **自来水本底 150–800 μS/cm 不可移植**、🔴 **皂液增量可能仅数十 μS/cm**、🔴 **我们没有水质标准检测能力**（无试剂/NTU 标定/微生物），所以**不能定义成"达到某标准"**，只能定义成 **4 个自建量**：

| 量 | 定义 | 作用 |
|---|---|---|
| ① **基线偏离度** | `D = ΔEC / σ`（σ = 本底重复测量的波动/极差） | **信噪比**——即本文件"≥3 倍"那条判定线的本体 |
| ② **变化率** | `Ṡ = dΔEC/dt`（也可用浊度、温度） | 区分"突然进入皂液段"与"缓慢漂移（污染/温漂）" |
| ③ **持续时间** | 偏离超阈**连续保持**的时间 | 防单点噪声（"块内 3 次一致"的连续版） |
| ④ **阶段位置** | 事件开始后的相对时间轴（第 N 秒 / 已用水量） | **阶段本身就是判据** |

**合成状态量（建议命名"回收适宜度 R"）**：
```
R = w₁·(ΔEC/σ) + w₂·(ΔNTU/σ_T) + w₃·阶段位置 + w₄·趋势方向
     σ 与权重 w 由实验 1/2 实测标定；基线由"上电自校准"更新
```
> ⚠️ **命名纪律**：对外只能说"**本队自建的回收适宜度指标**"，**不许**包装成国标水质指标（→ 9.1 红线 4 与红线 6）。

#### 6.2.4 可选判据（按性价比排序，全部排在"能稳定演示"之后）

| 优先级 | 判据 | 做法与价值 | 判断 |
|---|---|---|---|
| **P2** | ⭐ **阻抗双通道（R + C）** | **同一对电极**加一个电阻 + 一个 GPIO，用**充电/放电计时**得 RC 时间常数 → 同时拿到**电阻分量（≈电导）**与**电容分量（≈介电，反映有机物/表面活性剂）**→ **把"总脏度"拆成"离子型脏"和"有机物型脏"，且不增加传感器** | 🟡 强烈建议（补 B 类盲区） |

#### 6.2.5 ⭐ 三级判定 + "哪些该回收、哪些该放弃"

**关键认知**：**"污染程度"的真正源头是"这段水跟谁接触过"，不是传感器读数。** 传感器的活是**识别阶段**，不是重新发明水质学。

| 水源（同一洗手动作内） | 接触过什么 | 判定 | 去向 | 主要判据 |
|---|---|---|---|---|
| **前段滞留水 / 准清水** | **只接触过管道** | ✅ **优先回收** | 预冲洗 / 冲厕 / 拖地 | ΔEC 低 + 处于事件前段 |
| **冲洗收尾水（末段）** | 皮肤 + **少量皂液残留** | ✅ **可回收（次级）** | 冲厕 / 拖地 | **ΔEC 回落 + 趋势向下**（"先升后降"的降段） |
| **皂液揉搓段** | 洗手液 + 皮脂 | ❌ **放弃** | 下水道 | ΔEC 高位 + 浊度上升 + 变化率突增 |
| **泥沙 / 明显浑浊** | 固体悬浮物 | ❌ 放弃 | 下水道 | **浊度为主** |
| **水温异常 / 长时间静置水** | 停滞（生物膜风险） | ⚠️ 放弃 | 下水道 | 时间轴 + 温度 |
| **传感器故障 / 读数矛盾 / 超量程** | 未知 | ❌ **放弃（安全侧）** | 下水道 | 🟢 **ADC 自诊断（ADCER）** + 合理性校验 |

**"该放弃"的三类通用情形**（报告可直接用）：① **偏离不可逆**（洗完不回落）→ 说明是持续污染源而非过路水；② **变化太剧烈**（Ṡ 超限）→ 可能不是皂液而是异物/异常入流，**不赌**；③ **特征互相矛盾**（EC 正常但浊度很高）→ **判据失效即降级，降级即排空**。

#### 6.2.6 ⭐ "看得出的脏"与"拿不准的水"分工（第 3 版新增）

> **判别层负责"拿不准的水"，物理层负责"看得出的脏"，时序层负责"阶段"。**

| 水的类型 | 谁来处理 | 例子 |
|---|---|---|
| **看得出的脏**（尘土、泥沙、毛发） | **物理层**：滤网/沉砂 + **直接放弃回收** | 拖把池、洗菜池、洗手最初 1~2 s 的锈水 |
| **看不出但有变化**（皂液、酒精、合成洗手液） | ⭐ **判别层（本作品主场）** | 洗手的中段/收尾段 |
| **不需要判别**（本来就干净） | **直接回收**（零成本） | 淋浴预热水、空调冷凝水（见 6.2.7） |
| **拿不准** | **默认放弃** | 任何判据失效/矛盾 |

> **由此回答一个常见追问（"尘土水要不要回收"）**：**技术上尘土水最好判**（浊度响应强、滤芯拦得住），**但在本项目里不值得回收**——① 回收用途（冲厕/拖地/绿化）**不在乎浊度、在乎皂液/油**，投入产出比最低；② 为它必须**把浊度升为主判据 = 换标定逻辑 = 重做实验**；③ 它的解法是**物理过滤 + 定期清洗**，是**维护负担不是电子价值**，且直接恶化"不影响体验"。
> **⭐ 认知层面的一条（答辩很好用）**：**尘土造成的浑浊，人眼比我们的传感器判得准**——水浊到需要过滤时使用者肉眼就看得出，这时再"智能判别"是多余的。**本作品的价值在"人眼看不出的差别"上**（皂液/酒精这类透明污染），**这正是本课题的立身之本**。

#### 6.2.7 回用点分级 + 跨次回用的安全条件（第 3 版新增）

> **红线更正**：不是"任何接触人体的回用都不做"，而是**"不做饮用级"（不宣称、不追求达到饮用水标准）**。**回用点决定水质等级，水质等级决定要不要处理、处理到什么程度。**

| 回用点 | 水质等级要求 | 判定 |
|---|---|---|
| 饮用 / 做饭 | 生活饮用水（GB 5749） | ❌ **不做**（5 周内无法验证，且**不许编造"达标"结论**） |
| **洗手 / 洗脸（接触皮肤）** | 不低于生活饮用水 | ⚠️ **可做，但代价最高**（见下） |
| **冲厕 / 拖地 / 绿化（杂用水）** | 城市杂用水（GB/T 18920 体系，**不以电导率为控制项** 🔴已核实） | ✅ **最稳（推荐主线）** |
| 景观补水 / 初步冲洗 | 视用途 | ✅ 可选（降级使用） |

**"洗手水过滤后再洗手"（原设想）必须改写为三件事，风险各不相同**：

| 动作 | 风险 | 判断 |
|---|---|---|
| ① 只做非饮用级 | 🟢 低 | ✅ 界定正确 |
| ② **过滤** | 🟠 中 | ⚠️ **常规滤芯（滤网/PP 棉/活性炭/石英砂）只降浊度，不是消毒单元、不灭活病原体**——**"清"不等于"无菌"** |
| ③ **跨次存储** | 🔴 **最高** | 🔴 **真问题在这**：储水 = 停留时间 = 细菌繁殖 + 生物膜。**"过滤"解决不了它，"缩短停留时间"才能**；同一杯水"**当场用掉**"与"**存 24 h 再用**"卫生性质完全不同 |

**若坚持接触型回用，唯一安全的做法**：
1. ⭐ **不跨次存储**：同一动作内前段准清水**实时**导入预冲洗支路，**末段强制切回新鲜自来水**（无停留时间 = 无繁殖窗口；"新鲜水收尾"本身就是安全性论证）；
2. 若保留跨次水箱：**小容量短停留 + 停留时间上限 + 日清 + 避光 + 无死水段 + 定期清洗**，且**只能作预冲洗**；
3. ❌ **不加消毒单元**（紫外已在 4.1 排除：成本与伤眼），**不做微生物实验**（做不了、做不准），**绝不写"达到××水质标准"**。

**设计要点（都是答辩加分项）**：

1. **双阈值迟滞（滞回）**：Δ₁ < Δ₂，进入与退出用不同阈值，防止阈值附近反复切换（可给实测的切换次数）；
2. **块内一致才动作**（⚠️ 第 3 版修正）：原"**连续判定 M 次一致**"改为"**同一时间块（≤200 ms）内 3 次一致**"——**避免单个噪声点造成误分，同时不把延迟堆到 1 s 以上**（见 6.2.1）；可给"误动作次数"与"判定延迟"两组数据；
3. **默认排空（安全侧）**：不确定时排空——工程思维，评委爱听；
4. **温度补偿**：用**片上温度传感器（TSN）**把 EC 折算到参考温度（电导率随温度变化显著，且这是"用足芯片外设"的证据）；
5. **趋势特征**：真实洗手有明确阶段结构（先清水 → 皂液 → 冲洗收尾），**"先升后降"的形状本身就是强特征**，比单点阈值可信得多；
6. **硬件窗口比较**：可用 `ADCMPCR` 直接对 ADC 结果设上下限并产生比较中断（减少软件轮询、提高响应确定性）；
7. **全过程留痕**：串口/OLED 记录每次判定的 EC、ΔEC、浊度、结论 → **报告的数据来源**。
8. **区分"污染源类型"而非"品牌"**（第 3 版新增）：判据设计以 **A 电解型 / B 非电解型 / C 颗粒型 / D 化学型** 四类效应为依据（6.2.2），**并主动声明本方案的判据盲区**（如酒精免洗凝胶）。

### 6.3 实验设计：本周零采购就能做的六组实验（★全项目第一优先）

> **原则**：**不买任何东西**，用"两根导线 + 万用表 + 杯子 + 皂液"先验证判据。
> **纪律**：**实验没结论，不下单**（下单截止 11/01）。
> **记录载体**：**本文自带记录格式（不依赖任何外部表格文件）**——打印或手抄下面这一行作表头，每个样品填满 10 格即可：
> `样品编号 | 配比 | 水温θ | 读数1..10 | 均值 | 极差σ | ΔEC | 四问判定`
> **填完的这张表就是报告的原始数据页**（要给的是一组数，不是一个数）。

#### 实验 1（最关键）：电导率区分度——"两根铜线 + ADC"即可

**目的**：回答**两个**问题 —— ① 电导率到底能不能分开清水与皂液水？② **分离余量有多大**（是"数十 μS/cm 的小增量"还是"显著差异"）？

> ⚠️ **按核验结论，本次实验的核心指标不是"能不能看出差别"，而是"差别的幅度是否显著大于测量波动"**。
> 如果增量只有几十 μS/cm，而你的测量波动也是几十 μS/cm → **判据不成立**，必须走第 7 节降级 A。

| 项 | 做法 |
|---|---|
| **样品（按权威实测配比设计）** | ①**自来水空白**（本底 EC₀，同时用于自校准）②洗手液 **0.5 mL/L** ③**1.0 mL/L**（≈文献配比 1.5 mL 皂液/1 L 水）④**2.0 mL/L**（高浓度揉搓段）⑤**真实模拟样**（皂液水 + 手搓 30 s，含皮脂）⑥冲洗后的低浓度皂液水 |
| **关键测法（零成本）** | 两根铜线作电极（**间距、插入深度、电极面积全部固定**）+ 串联固定电阻分压 → **RA4M2 ADC（12 位）**采集 → 串口打印 |
| **前置标定（别省）** | 先用**几个已知电阻**替代电极，验证"ADC 读数 ↔ 电阻"的换算关系（同时确认分压后电压 ≤3.0 V）→ 这一步让后面的数据**可换算成 μS/cm**，而不是一堆无意义的 ADC 数字 |
| **对照测法** | 有万用表就用电阻档读同一电极的电阻值，交叉验证 ADC 链路 |
| **读数要求** | 每个样品 **≥10 次**；每次记录 EC 与水温；**必须先记录自来水本底 EC₀** |
| **判定标准（四问）** | ① **本底自校准是否有效**：同一杯水重复测 10 次，波动是否远小于"皂液引起的增量"？② **分离余量**：ΔEC(1.0 mL/L) ÷ 测量波动 ≈ **≥3 倍**？（≥3 才算判据成立；<3 则不可靠）③ **顺序单调性**：随洗手液浓度升高，ΔEC 是否**单调上升**？（单调上升 = 判据有物理依据，答辩能讲原理）④ **（第 3 版新增）污染源敏感性**：同一浓度下，**皂基皂 / 合成洗手液 / 酒精免洗凝胶** 三者的 ΔEC 各是多少？→ **直接量化 6.2.2 的判据盲区**（酒精预计几乎无响应，这条数据就是"已知局限"的证据） |
| **产出** | **一张"浓度 vs ΔEC"表 + 一张标定曲线图** → 直接进报告（这就是"理论分析与计算"和"测试结果"的采分点） |

> ⚠️ **必须做的事**：① 同一杯水**重复测 10 次**并记录波动——**只报一个数不算实验**；② **先测本底 EC₀**，因为判据要建立在 ΔEC 之上。

#### 实验 2：浊度辅助判据（可选，加分）

用光敏电阻/LED 对射或反射看透光变化（准清水 vs 皂液水浑浊度差异）。**目的**：证明"电导率 + 浊度双判据更可靠"。
> ⚠️ **不可做的映射**：市售浊度模块（如 SEN0189）**只给相对值、无 NTU 标定**，因此**不能把读数写成"NTU"、也不能对标国标 NTU 限值**——报告里只能写"相对浊度值"。这条红线由核验给出，务必遵守。

#### 实验 3：分流动作的"假执行器"验证（零成本，验证闭环逻辑）

用 **LED 代替电磁阀**（红=排空，绿=回收），跑通"ΔEC 越限 → 状态切换 → 消抖 → 动作"的完整逻辑链，并用串口打印状态迁移过程。**目的**：证明闭环逻辑成立、可演示，且**不依赖器件到货**。

> **⚠️ 第 3 版新增两项必做**（否则"在线判别"会被质疑成"定时器"）：
> ① **对照组**：同时实现"**纯定时器方案**"（如前 3 s 回收、中段排空、末段回收），**与判别方案并排跑同一组样品** → 用数据回答"**在线判别比定时器好在哪**"；
> ② **延迟与误分水量**：测"**从读数越限到 LED 切换**"的时间（20 次均值），并折算**误分水量（mL）**——这是 6.2.1 时间预算的验收数据。

#### 实验 4（新增，强烈建议）：原理解释性实验——"皂液到底贡献了多少电导率"

| 项 | 做法 |
|---|---|
| **目的** | 用**自来水 + 纯 NaCl 溶液**配几个已知浓度，测其电导率，**反推"皂液实际电离当量"**——把"为什么增量小"讲成物理机理 |
| **价值** | 这是**答辩的护城河**：评委问"皂液怎么会让电导率变化"时，你能拿数据说"皂液主要成分是非电解质（甘油）+ 少量阴离子表面活性剂，电离贡献有限，所以我们用 ΔEC + 趋势而不是绝对阈值" |
| **成本** | 一包食盐 + 一个量杯（几乎为零） |

| 实验 | 依赖 | 时间 | 通过标准 |
|---|---|---|---|
| 1 判别区分度（含本底自校准） | 零采购 | 半天 | **ΔEC/波动 ≥3 倍且随浓度单调**（否则降级） |
| 2 浊度辅助 | 可选器件 | 半天 | 有对比数据（**只写相对值**） |
| 3 假执行器闭环（含**定时器对照组**） | 零采购 | 半天 | 状态机可演示、无抖动误动作；**判定延迟与误分水量有实测值** |
| 4 皂液电离当量反推 | 食盐 + 量杯 | 2 小时 | 给出"ΔEC 与浓度的关系式"（报告加分） |
| **5（第 3 版新增）污染源分类响应** | 零采购（皂基皂 + 合成洗手液 + 酒精免洗凝胶各一点） | 2 小时 | **给出三类污染源在 ΔEC/浊度上的响应表** → 明确写出盲区（预期：**酒精免洗凝胶几乎无响应**） |
| **6（第 3 版新增）时序与延迟实测** | 零采购（现有链路 + 秒表/串口时间戳） | 半天 | ① 得到"**阶段曲线**"（清水→皂液→收尾的 ΔEC 随时间形状）② 实测**判定延迟**（20 次均值+极差）③ 实测**误分水量**（mL） |

> - **时序趋势判据**：真实洗手有明确阶段（先清水 → 皂液 → 冲洗收尾），**趋势形状本身就是强特征**；

> **这个被迫的修正，反而让方案更专业**：答辩时讲"我们发现绝对阈值不可移植，所以改用了基线相对判据 + 时序状态机"，这正是评委会认可的工程认知。

## 7. 降级方案：如果电导率分不开怎么办（提前写好，避免临场慌）

**触发条件（已按核验结论细化）**：
⓪ **（第 3 版新增）判据盲区被证实影响结论**：如实验 5 显示常用洗手液（合成/免洗）在 ΔEC 上**普遍无响应**，说明单靠电导率的"识别力"不足 → 直接进入 **降级 A**（加维度），**不必等实验 1 的余量结论**；
① 实验 1 显示 **ΔEC 与测量波动的比值 <3**（信号被噪声淹没）；
② 或 ΔEC **不随洗手液浓度单调变化**（说明不是电导率在响应，而是噪声/漂移）；
③ 或清水段与皂液段的读数区间严重重叠。

| 降级级别 | 方案 | 代价 | 何时用 |
|---|---|---|---|
| **降级 A** | **加大判别维度**：ΔEC + 浊度 + 温度趋势 + **流量/时间时序**（"洗手开始后的第 N 秒"本身是强特征） | 多一个传感器、多一条标定线 | 首选——判别维度变多，答辩反而更好讲 |
| **降级 A+** | **纯时序判别（最稳）**：承认水质判别不可靠，改判"阶段"——前 3 秒（清水）回收、中段排空、末段冲洗回收；用状态机 + 消抖实现 | 创新性下降，可能被问"这不就是定时器吗" | 实验 1 部分失败时 |
| **降级 B** | **换传感方案**：改用**非接触/光学**判据（透光度/颜色/气泡）作为主判据，电导率降为辅助 | 需重新验证，时间成本 | 电导率方案彻底失败时 |
| **降级 C** | **转向同主线其他方向**（可复用本条"电导率/浊度突变判别"链路的候选：**农村供水末梢水质哨兵**、**农村水窖水位 + 泵空转保护**、**户内夜间漏水告警**、**初雨截流智能分流**） | 需重新定题，时间成本高 | 最后手段（**最好在第 2 周内触发，不要拖到第 4 周**） |

> **重要**：降级 A / A+ 里的"**用时间序列判别**"其实是**很强的工程亮点**——真实洗手过程有明确的阶段结构，把它写成"**多特征状态机判别**"，比单一阈值更像系统设计。**所以降级不是失败，是把赌注换成稳赢的牌。**
