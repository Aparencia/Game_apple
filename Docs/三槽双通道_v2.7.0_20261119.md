# 三槽最近基线 + EC/NTU 双通道（v2.7.0-B3）

- 日期：2026-11-19
- 固件：`SENSOR-NODE v2.7.0-B3`
- 构建：`text 83196 / data 480 / bss 11440`，0 error / 0 warning
  （`_tmp/build_v270_b3_full.log`）
- 基线：`scheme-b`（v2.6.0-B2）

---

## 1. 数据依据

同一批清水三次注水（2026-11-19 12:30~12:34），出现三个稳定 EC 平台：

| 状态 | EC 平台 | dNTU |
|---|---|---|
| FULL / 流动满水 | 327~342 mV（≈333） | +1~+7.6% |
| RECOVER 静态 | 302~309 mV（≈305） | +2~+4% |
| DRAIN 静态 | 255~261 mV（≈258） | +2~+4% |

旧单基线 281 导致：

- 第 1/3 次 FULL 333 → dEC +52 > d2 → 全 SOAP；
- 中间段 DRAIN 258 / RECOVER 305 相对同一 281 → dEC ±22 → CLEAR↔UNCERT 横跳。

结论：**需要三条基线；并且 EC 单独偏高不能判 SOAP。**

---

## 2. 三槽

| 槽 | 标定条件 | 默认值（本机实测） |
|---|---|---|
| `DRAIN` | 阀 DRAIN，静态液位 | EC0=258 |
| `RECOVER` | 阀 RECOVER，静态液位 | EC0=305 |
| `FULL` | 进水流动、腔体满 | EC0=333 |

运行时：

```
每 tick 取当前 EC，找最近的有效槽
若当前槽距离 ≤ 最近距离 + 8 mV → 保持
否则切槽，并开 1.5 s 屏蔽窗
```

串口：

```
# BASE slot=DRAIN/RECOVER/FULL ec0=… ec=…
# BASELINE SLOT DRAIN/RECOVER/FULL ec0=…
```

---

## 3. 三段标定

上电首轮强制：

```
空腔自检 3 s
  ↓
槽 0：DRAIN，稳定后采 2 s
  ↓
槽 1：RECOVER，稳定后采 2 s
  ↓
槽 2：FULL（保持进水流动），EC ≥ max(DRAIN,RECOVER)+10 mV 后采 2 s
  ↓
按当前 EC 选最近槽 → 正常测量
```

- 每段仍要过 `baseline_ok`、5 mV 漂移、AO 清洁门槛；
- FULL 段若 EC 不够高，保持 `SETTLE`，OLED 显示 `Cal F fill`，不会误采静态 DRAIN；
- 长按 K2 ≥3 s 可跳过，写三条默认基线：

```
# CAL SKIP: default slots DRAIN=258 RECOVER=305 FULL=333 ntu0=2659mV
```

---

## 4. 双通道判据

`decision_classify()` 改为：

```
L2：dNTU > 9%
    或（dEC > d2 且 dNTU > 0.9×9% = 8.1%）

L1：dEC < -d2 或 dNTU < -9%

L0：dEC < d1 且 dNTU < 7%

其余：L1
```

关键：

- **EC 单独高、NTU 干净 → L1/UNCERT/DRAIN，不判 SOAP**；
- 这正好覆盖 FULL 333 这种“液位抬 EC”的情况；
- 真肥皂：EC +40 且 dNTU +10.9% → L2；
- 清水稳定段 dNTU 最高 7.6%，低于 9%。

阈值：

| 参数 | v2.6 | v2.7-B3 |
|---|---|---|
| EC d1 | 6%×EC0 | 6%×EC0（按当前槽） |
| EC d2 | 9%×EC0 | 9%×EC0（按当前槽） |
| NTU d1 | 4% | **7%** |
| NTU d2 | 8% | **9%** |
| L2 | EC 或 NTU 单路 | **NTU 单独 / EC+NTU 双路** |

---

## 5. 用这份清水日志回放

按三槽最近基线 + 上述阈值离线回放：

- 第 1/3 次 FULL 333：匹配 FULL 槽，dEC≈0，dNTU≤7.6 → 绝大多数 L0；
- 中间 DRAIN 258 / RECOVER 305：各自匹配，dEC≈0 → L0；
- 只有进水/失水边界出现少量 L1/L2，属于液位过渡；
- 不再出现“整段 SOAP”或“1 s 周期 CLEAR↔UNCERT”。

## 6. 验证要点

1. 启动行 `SENSOR-NODE v2.7.0-B3`；
2. 上电三段标定，串口应有：
   ```
   # BASELINE SLOT DRAIN ec0≈258
   # BASELINE SLOT RECOVER ec0≈305
   # BASELINE SLOT FULL ec0≈333
   # AUTOCAL state=DONE reason=base_ok_three_slot
   ```
3. 正常清水注入：
   - 满水流动：`# BASE slot=FULL`，应稳定 `CLEAR`；
   - 阀切 DRAIN/RECOVER：`# BASE slot=…`，仍 `CLEAR`；
4. 打肥皂：EC 和 NTU 同时上升 → `SOAP/L2`；
5. 只有 EC 高、NTU 干净：应 `UNCERT/L1`，不是 SOAP；
6. 长按 3 s：`CAL SKIP`，三条默认基线生效。

---

## 7. 已知限制

1. FULL 槽需要现场保持进水流动；若无法保持，FULL 段会停在 `Cal F fill`，可长按跳过；
2. 三条槽仍只在 RAM，掉电丢失；
3. 三槽都是清水基线；若水样电导率与现场差异大，需重标；
4. 阈值按本次同一批清水 + 之前肥皂日志设定，仍需更多肥皂/脏水数据复核；
5. 阀位/液位若还有未覆盖的第四种平台，需要再增加槽或改机械定液位。
