## 1. 现场依据

V1 手动阀日志证明：同一腔体在 DRAIN / RECOVER 是两个稳定平台：

| 阀位 | EC 平台 | ΔNTU |
|---|---|---|
| DRAIN | 约 218 mV | −7% |
| RECOVER | 约 258 mV | 0% |
| 差 | 约 40 mV | 约 7% |

单一 `EC0` 无法同时覆盖两个平台，所以采用 B 方案：**按阀位保存两条基线**。

---

## 2. 双基线（pipeline slots）

`sensor_pipeline` 新增：

- `PIPELINE_SLOT_DRAIN = 0`
- `PIPELINE_SLOT_RECOVER = 1`
- 每条槽保存 `EC0 / NTU0 / σEC / σNTU / valid`
- `pipeline_baseline_select_slot()`：切换 active，重置 EMA/速率，下一 tick 用新基线算 Δ
- `pipeline_baseline_store_slot()`：把刚采完的基线存入当前槽
- `pipeline_baseline_set_default()`：跳过标定时写默认值
- `pipeline_baseline_clear_slots()`：Z / 重新标定时清空

运行时：

```
阀切到 DRAIN   → active = DRAIN 槽
阀切到 RECOVER → active = RECOVER 槽
```

切换后 `blank_ms = 1500 ms`，先冻结判别等液位稳定，再分类。

---

## 3. 首轮强制清水标定

上电后自检流程：

```
空腔自检 3 s（缩短，原 10 s）
  ↓
等水 / 确认浸没
  ↓
槽 0：强制 DRAIN，稳定后采 2 s → 保存 DRAIN 基线
  ↓
槽 1：强制 RECOVER，稳定后采 2 s → 保存 RECOVER 基线
  ↓
按当前阀位选择 active → 正常测量
```

- 标定完成前阀保持排空/标定阀位，不进入正常回收；
- 槽 0/1 都要求 `gate.baseline_ok` + 5 mV 漂移校验 + AO 清洁门槛（v2.4.3 逻辑）；
- OLED 显示：
  - `Cal dry n/60`（空腔 3 s）
  - `Cal wait water`
  - `Cal D wait` / `Cal D n/40`（DRAIN 槽）
  - `Cal R wait` / `Cal R n/40`（RECOVER 槽）
  - 大字“校准”

串口：

```
# BASELINE SLOT DRAIN ec0=…mV
# BASELINE SLOT RECOVER ec0=…mV
# AUTOCAL state=DONE reason=base_ok_two_slot
```

---

## 4. 长按跳过：使用默认数据

标定期间（或标定失败 DONE）**长按 K2 ≥3 s**：

```
# KEY: long press >=3s -> skip calibration, use defaults
# CAL SKIP: using default EC0=348mV ntu0=2659mV
```

默认值：

| 参数 | 默认 |
|---|---|
| `APP_DEFAULT_EC0_MV` | 348 mV |
| `APP_DEFAULT_NTU0_AO_MV` | 2659 mV |

两条槽都写同一组默认值，按当前阀位选 active，然后进入正常测量。

> 默认值只是临时兜底；不同水路/阀位仍建议做完整两段标定。

## 6. 验证

1. 启动行 `SENSOR-NODE v2.6.0-B2`；
2. 空腔上电：`Cal dry n/60`（约 3 s）→ `Cal wait water`；
3. 注清水：
   - 先 `Cal D wait` → `Cal D n/40` → `# BASELINE SLOT DRAIN`；
   - 再 `Cal R wait` → `Cal R n/40` → `# BASELINE SLOT RECOVER`；
4. 完成后放清水，应稳定 `CLEAR`；
5. 手动 `V1`/`V0`：EC 应分别接近两条槽的值，不再用单一 348 去比 218/258；
6. 标定中长按 3 s：应出现 `CAL SKIP`，并使用默认 348/2659 进入测量；
7. 若槽缺失时阀切换，串口会出现 `NO_SLOT` 并排空（安全侧）。

---

## 7. 已知限制

1. 默认数据两条槽都是 348/2659，不包含真实阀位差；跳过标定后仍可能横跳；
2. 基线仍只在 RAM，掉电丢失（Flash 需 FSP `r_flash_lp`，尚未接入）；
3. 两段标定要求 DRAIN/RECOVER 两个液位都能淹到电极；若 DRAIN 液位太低，需先改水路/电极位置；
4. 阈值仍是 v2.2 的 6%/9%、4%/8%，**尚未按新数据重新设计算法**；
5. 标定过程会强制切换阀位，现场需确认水路允许（不会溢流/抽空）。
