# M2e：液位只冻结 trim，不冻结槽切换（修复跳跃）（2026-11-20）

- 固件：`SENSOR-NODE v2.8.0-LEVEL-M2e`
- 构建：`text 86848 / data 480 / bss 11532`，0 error / 0 warning
- 基于：`v2.8.0-LEVEL-M2d`

> **M2d 现场又出现 CLEAR↔UNCERT 跳跃。**
>
> 原因：`app_baseline_task()` 在 `g_level_hold=true` 时被跳过，
> 液位轻微波动（117↔113↔144mm）就长期冻结槽切换。
>
> 于是：
> - 阀在 RECOVER 时，active 仍是 DRAIN 槽 302；
> - dEC 变成 +14~+18；
> - 决策在 CLEAR/UNCERT 之间跳。
>
> 这是“冻结槽切换”造成的，不是 EC 阈值本身。
>
> M2e：液位变化只冻结 **trim**；槽切换继续按当前 EC/阀位做，
> 保证 RECOVER 用 RECOVER 槽、DRAIN 用 DRAIN 槽。





---

## 1. 现场问题

同一份肥皂水：

- 前半段：`UNCERT/L1/DRAIN`；
- 后半段：`CLEAR/L0/RECOV`；
- 液位从 100 → 65 → 32 → 60 → 114 → 100 mm 明显变化；
- 超声 `valid=1, mm` 正常，但 **M1 只记录，不参与判定**。

后半段 CLEAR 的两个因素：

1. 液位变化导致 EC 平台变化，决策仍用旧状态；
2. EC `d1=4%`，但 `ec_hyst_ratio=25%` 把 L0 保持上限抬到 `1.25×d1≈15.9mV`；
   `dEC=+14~+16` 落在保持区内，继续 CLEAR。

---

## 2. M2 实现

### 2.0 标定水体确认（M2d）

`APP_AC_SETTLE` 仍然只认 EC/AO 清洁双证据：

```
EC ≥ EC_DRY + 80mV
AO ≥ AO_DRY + 80mV
```

液位只用于区分原因，不覆盖门槛：

```
液位 valid=1 mm≥20，但 EC/AO 不通过
→ DONE(water_dirty)，两槽不采
液位 invalid
→ DONE(water_unconfirmed)
```

日志：

```
# CAL REJECT water_dirty: ec=... (ec_dry=...) ao=... (ao_dry=...) mm=...
```

NO_BASE 是保护结果，不是 bug。

### 2.1 液位状态

`app_level_task()`：

```
|rate| > 5 mm/s     → level_hold=true，稳定计时清零
1 < |rate| ≤ 5      → 过渡带，保持 hold
|rate| ≤ 1 mm/s 1s  → level_hold=false
level invalid/<10mm → 释放 hold，回退 v2.7.6
```

### 2.2 判定门控

**M2e：不强制 WAIT，也不冻结槽切换。**

```
level_hold=true：
  只禁止 trim
  槽切换继续按当前 EC/阀位做
  decision 继续分类
```

原因：

- 冻结槽切换会让 RECOVER 继续用 DRAIN 基线，dEC 从 0 跳到 +14~18；
- 决策就会在 CLEAR/UNCERT 之间反复。

### 2.3 trim 与基线选择

- `level_hold=true` 时禁止 `app_baseline_trim_task()`；
- **不再禁止 `app_baseline_task()` 选槽**；
- 保证 RECOVER 用 RECOVER 槽、DRAIN 用 DRAIN 槽；
- 液位无效时仍回退 v2.7.6。

### 2.4 EC 迟滞

`ec_hyst_ratio`：25% → 10%。

```
L0 保持上限 = 1.10 × d1
d1 = 4% × 315 ≈ 12.6
保持上限 ≈ 13.9
```

`dEC=+14~+16` 不再留在 CLEAR，进入 L1/UNCERT/DRAIN。

## 3. 预期

| 阶段 | 液位 | 状态 |
|---|---|---|
| 清水稳定 | mm 稳定 | CLEAR/L0 |
| 进水/液位上升 | >5mm/s | **继续分类；基线/trim 冻结，不插入 WAIT** |
| 肥皂水稳定 | mm 稳定 | dEC+14 → UNCERT/L1/DRAIN |
| 失水 | 快速下降 | 继续分类，gate 进入 DRY |
| 超声无效 | invalid | 回退 v2.7.6 gate |

注意：

- 液位变化时不再用旧 CLEAR 回收；
- 液位稳定后，弱肥皂水仍不会标 SOAP（NTU 不升），但不会 CLEAR；
- 典型肥皂（NTU 也升）仍走 SOAP/L2。

## 4. 验证

1. 启动行 `v2.8.0-LEVEL-M2`；
2. 清水稳定：`CLEAR`；
3. 倒水/液位变化：应出现 `WAIT/L1/DRAIN`，reason `LEVEL_MOVE`；
4. 液位稳定 1s 后才恢复分类；
5. 肥皂水稳定段：`UNCERT/L1/DRAIN`，不再 CLEAR；
6. 失水：`DRY`；
7. 长按跳过/校准仍可用。
