0. 先看结论（TL;DR）
--------------------------------------------------------------------------------
0.1 一句话
    v1.3.0 把 OLED 从"单页、大字只有清水/污水"升级为三页现场指示：
      P1 水质页：清水/污水（反显）/待机/冲洗/故障 + dEC/g/N（原 v1.1 布局）；
      P2 执行器页：大字"回收/排空/手动（反显）/故障/待机" + 继电器 RLY:ON/OFF +
                   吸合次数 CNT + 本次通电时长 ON；
      P3 详情页：事件状态与时长、STATE/LEVEL、VALVE/RLY、MODE/CNT、dEC/g、dNTU/水温、
                   EC0/σ、d1/d2 阈值（8 行 6x8 小字）。
    K2 短按循环切页（P1→P2→P3→P1，默认 P1，不自动轮播）；K2 长按 ≥1.5 s 仍是重采基线；
    MARK 改由串口 M 发送。显示仍不是安全路径：屏坏/掉线不影响判别、CSV、LED 与阀。

1. 需求理解与设计决策
--------------------------------------------------------------------------------
1.1 用户反馈
    原 v1.1 的 OLED 大字只有 清水/污水/待机/冲洗/故障 五种，其中 L1（拿不准）与 L2
    （含皂液）都显示"污水"两个大字，只靠第二行小字 "L1 UNCERTAIN"/"L2 SOAP" 区分；
    阀的实际状态（回收/排空/手动）、动作次数、事件进度、阈值等现场都看不到。
    用户反馈："oled 显示状态只有污水和清水，我觉得不够"。

1.2 需求确认（与用户对齐后）
    ① 方向：两者都要——大字增加执行器状态（回收/排空/手动），同时增加多页明细；
    ② 切换方式：用板载用户按键（K2）切页；
    ③ 重点信息：阀实际状态 + 继电器 ON/OFF；ΔEC/g/ΔNTU%/水温；事件状态与时长。
    本阶段按此实现；未选的字段（如阈值）放 P3 最后一行，作为调试附赠，不喧宾夺主。

1.3 为什么是"按键切页"而不是"自动轮播"
    - 演示时讲解节奏由人控制：讲到水质按 P1，讲到阀按 P2，问到数据按 P3；
    - 自动轮播会在"评委正在看污水大字"时切走，而且多一层定时器/状态；
    - 板载只有 K2 一个用户按键：短按切页最符合直觉（长按仍保留原重采基线功能）；
    - 显示仍不是安全路径，切页失败/屏坏不影响任何控制逻辑。

1.4 页面优先级与默认
    - 默认停在 P1（水质结论是设备的第一语义）；
    - 切页只改显示，不改判别/阀/CSV；
    - 任何页面的内容都来自同一帧数据（pipeline_out_t/decision_out_t/valve_out_t），
      不从串口/PC 读取，脱机也能用。

1.5 兼容性
    - display_task 新增第 4 个参数 const valve_out_t *p_valve（可为 NULL）；
    - 传 NULL（旧集成/异常）时 P2/P3 显示 "NO VALVE"/"VALVE:NO DATA"，不会崩；
    - CSV 17 列协议、串口命令集、LED、阀逻辑全部不变；只改显示与 K2 短按语义。


2. 三页规格（128x64，全部 8 像素对齐）
--------------------------------------------------------------------------------
2.1 P1 水质页（保留 v1.1 布局，右上角加页码 1/3）

    ┌──────────────────────────────────────────────────────────────┐
    │ y=0  : EC0=1490 s1.5 T25.3                                  │ 6x8，≤21 字符
    │ y=8  :        [清 水] / [污 水](反显) / [待 机] ...          │ 32x32 x2（x=32/64）
    │ y=40 : CLEAR  RECOVER                                       │ 8x16，≤16 字符
    │ y=56 : dEC+12mV g1.008 N+5                                  │ 6x8，≤21 字符
    │ 右上角：1/3（x=98,y=8，6x8；与大字带不重叠：大字占 x=32..95）│
    └──────────────────────────────────────────────────────────────┘

    状态映射（与 v1.1 相同）：
      CLEAR → 清水（正显）；UNCERTAIN/SOAP → 污水（反显）；WAIT → 待机；
      FLUSH → 冲洗；传感器故障 → 故障；无基线 → 故障/采集中进度（BASELINE n/20）；
      第二行：WAIT "WAIT   EV:OFF" / FLUSH "FLUSH  DRAIN" / CLEAR "CLEAR  RECOVER" /
              L1 "L1 UNCERTAIN" / L2 "L2 SOAP  DRAIN" / 故障 "L1 SENSOR_FAULT" 等；
      第三行：dEC（整数 mV，带符号）/ g（x1000）/ N（ΔNTU%，整数，±99 限幅）。

2.2 P2 执行器页（v1.3.0 新增：大字显示阀的实际状态）

    ┌──────────────────────────────────────────────────────────────┐
    │ y=0  : P2/3 EXEC  MODE:AUTO                                 │ 6x8，≤21 字符
    │ y=8  :        [回 收](反显) / [排 空] / [手 动](反显)        │ 32x32 x2
    │ y=40 : RECOVER  RLY:ON   / DRAIN    RLY:OFF                 │ 8x16，≤16 字符
    │ y=56 : AUTO CNT:12 ON:5s / V1 CNT:12 ON:5s                  │ 6x8，≤21 字符
    │ 右上角：2/3                                                  │
    └──────────────────────────────────────────────────────────────┘

    内容优先级（从高到低）：
      ① p_valve 参数为 NULL（旧集成） → 大字"故障"，第二行 "VALVE NO DATA"；
      ② p_valve->pin_fault（P104 写/回读失败）→ 大字"故障"，第二行 "PIN_FAULT"，
         第三行 "check P104 count=N"；
      ③ 传感器故障（与 P1 同一判据）→ 大字"故障"，第二行 "SENSOR_FAULT"，第三行 note=...
      ④ 无基线：采集中 → 大字"待机" + "BASELINING" + "hold probe in water"；
         无基线 → 大字"故障" + "NO_BASELINE" + "send B in water"；
      ⑤ 正常：大字 = 阀的实际位置（valve_out_t.position）：
           RECOVER → 回收（反显）；DRAIN → 排空（正显）；
           手动模式（request_reason = MANUAL_*）→ 大字"手动"（反显，不论方向），
           方向看第二行 RECOVER/DRAIN；第三行模式短标签 V1/V0。
      第二行：阀位置 + 继电器实际状态（RLY:ON/OFF）；RECOVER 与 DRAIN 两种串宽 15/16 字符；
      第三行：模式标签（AUTO/V1/V0）+ 吸合次数 + 本次通电时长（整秒，count≤9999、秒≤999 限幅，
              保证最坏仍 ≤21 字符）。

2.3 P3 详情页（v1.3.0 新增：8 行 6x8，小字，近看/调试用）

    ┌──────────────────────────────────────────────────────────────┐
    │ y=0  : P3/3 INFO EV:ON 4.2s        （事件状态 + 已持续时长）  │
    │ y=8  : STATE:CLEAR LEVEL:L0        （判别状态/等级）          │
    │ y=16 : VALVE:RECOVER RLY:ON        （阀逻辑位置/继电器实际）  │
    │ y=24 : MODE:AUTO CNT:12            （自动/V1/V0 + 吸合次数）  │
    │ y=32 : dEC:+12mV g:1.008           （ΔEC / g）                │
    │ y=40 : dNTU:+5.0% T:25.3C          （ΔNTU% / 水温）           │
    │ y=48 : EC0:1490mV s:1.5            （基线 / 噪声 σ）          │
    │ y=56 : d1:8/8% d2:20/25%           （d1/d2：EC mV / 浊度 %）  │
    └──────────────────────────────────────────────────────────────┘

    规则：
      - 事件时长：display.c 自己跟踪 decision_out_t.event_active 的上升沿计时（不依赖决策层
        内部变量），显示 "EV:ON x.xs"（≤99.9 s 限幅）；无事件显示 "EV:OFF"；
      - 故障/无基线时最后一行改为 "note=..." / "send B in water"，其余行照常；
      - 所有行宽 ≤21 字符（6x8），计数/时长/事件秒数都限幅，防止超宽截断。

2.4 刷新策略
    - 页面内容变化立即重画对应区域；P1 页头/数值行、P3 数值行最快 200 ms 一次；
    - 1 s 整屏心跳（掉帧/残影自恢复，也是"屏还活着"的证据）；
    - 切页由 display_page_next() 置 g_force_full，下一次 display_task 整屏重画；
    - 只刷脏页（oled_flush 内部实现）：一页约 3 ms@400 kHz，整屏约 25 ms；
    - 连续 3 帧 I2C 失败才返回 false（app 只打印一次 WARN，之后继续用串口）。


3. 字库升级（32x32 汉字 9 → 15）
--------------------------------------------------------------------------------
3.1 为什么必须扩字库
    P2 页要用 32x32 大字显示 回收/排空/手动；原字库只有 9 个字形
    （清 水 污 待 机 冲 洗 故 障），没有这些字，只能退回英文大字，现场不如中文直观。

3.2 新增 6 个字与枚举顺序
    在原 0~8 之后追加（顺序必须与 oledfont.h 的 oled_hz32_bitmaps[15][128] 完全一致）：
      9=回  10=收  11=排  12=空  13=手  14=动
    枚举（src\oled.h）：
typedef enum e_oled_hz32_id
{
    OLED_HZ32_QING = 0,   /* 清 */
    OLED_HZ32_SHUI,       /* 水 */
    OLED_HZ32_WU,         /* 污 */
    OLED_HZ32_DAI,        /* 待 */
    OLED_HZ32_JI,         /* 机 */
    OLED_HZ32_CHONG,      /* 冲 */
    OLED_HZ32_XI,         /* 洗 */
    OLED_HZ32_GU,         /* 故 */
    OLED_HZ32_ZHANG,      /* 障 */
    OLED_HZ32_HUI,        /* 回（v1.3.0 执行器页） */
    OLED_HZ32_SHOU,       /* 收 */
    OLED_HZ32_PAI,        /* 排 */
    OLED_HZ32_KONG,       /* 空 */
    OLED_HZ32_HAND,       /* 手 */
    OLED_HZ32_DONG,       /* 动 */
    OLED_HZ32_COUNT
} oled_hz32_id_t;

    字模格式（与原有 9 字相同，oled.c 的 oled_hz32 按此解析）：
      bitmaps[id][p*32 + c]，bit0..bit7 = 第 p*8+0..7 行、第 c 列像素；1=点亮；
      一个字 4 页 × 32 列 = 128 字节。

    ① 按 3.3 生成 128 字节（8 行 16 列 C 数组，或 4×32 数组按页展开）；
    ② oled.h 枚举在 OLED_HZ32_COUNT 前加 id（注释写汉字）；
    ③ oledfont.h 数组维度改 [N][128]，在末尾追加字模块并更新索引注释；
    ④ display.c 用新 id；重新编译（字库是 static 数组，只占 Flash，不占 RAM）。
    注意：改枚举顺序会让所有已有显示错字，必须"只追加、不改旧顺序"。

/*
 * display.h —— 板载 0.96" OLED 状态页（v1.3.0：三页，K2 短按切页）
 * ---------------------------------------------------------------------------
 * 定位（与 oled.h 一致）：
 *   - 这是"现场指示器"，不是安全执行路径：屏幕坏了/不刷新，判别、串口 CSV、
 *     LED/阀都不受影响；app_main 只在连续失败时打印一次 WARN；
 *   - 只画"本工程定义的量"：不画 NTU 读数、不画绝对 ppm、不说"识别出污染物"；
 *   - 不用动态内存、不用变长数组、不用浮点 printf；最多 1 KB 静态显存。
 *
 * v1.3.0 三页（默认停在 P1；K2 短按循环切换 P1→P2→P3→P1，长按仍重采基线）：
 *
 *   P1 水质页（沿用 v1.1 布局 + 右上角页码 1/3）
 *     y=0   (6x8) : "EC0=1490 s1.5 T25.3"
 *     y=8   (32x32): 大字两个：清水 / 污水 / 待机 / 冲洗 / 故障（反显=污水）
 *     y=40  (8x16): "CLEAR  RECOVER" 等状态串
 *     y=56  (6x8) : "dEC+12mV g1.008 N+5" 数值串
 *
 *   P2 执行器页（v1.3.0 新增，大字显示阀的实际状态）
 *     y=0   (6x8) : "P2/3 EXEC  MODE:AUTO/MANUAL/FAULT"
 *     y=8   (32x32): 大字两个：回收（反显）/ 排空 / 手动（反显）/ 故障 / 待机
 *     y=40  (8x16): "RECOVER  RLY:ON" / "DRAIN    RLY:OFF"（继电器实际状态）
 *     y=56  (6x8) : "AUTO CNT:12 ON:5.2s"（模式/吸合次数/本次通电时长）
 *                   手动时 "V1 CNT:12 ON:5.2s" / "V0 ..."
 *
 *   P3 详情页（v1.3.0 新增，8 行 6x8，每行最多 21 字符）
 *     "P3/3 INFO EV:ON 4.2s"       事件状态 + 已持续时间
 *     "STATE:CLEAR LEVEL:L0"       判别状态/等级
 *     "VALVE:RECOVER RLY:ON"       阀逻辑位置/继电器实际状态
 *     "MODE:AUTO CNT:12"           自动/手动 + 吸合次数
 *     "dEC:+12mV g:1.008"          ΔEC / g
 *     "dNTU:+5.0% T:25.3C"         ΔNTU% / 水温
 *     "EC0:1490mV s:1.5"           基线 / 噪声 σ
 *     "d1:8/8% d2:20/25%"          当前生效的 d1/d2（EC mV / 浊度 %）
 *
 * 刷新模型（实现见 display.c）：
 *   - 页面内容变化立即重画对应区域；数值（P1 页头/P1 数值行/P3 数值行）最快 200 ms；
 *   - 1 s 心跳整屏重画（掉帧/残影自恢复，也是"屏还活着"的证据）；
 *   - 只刷脏页（oled_flush 内部实现），一页约 3 ms@400 kHz；
 *   - 切页（display_page_next）后下一 tick 整屏重画一次。
 */

#define DISPLAY_H

/* 三页轮换（K2 短按切换；默认 P1） */
#define DISPLAY_PAGE_COUNT       3U
#define DISPLAY_PAGE_WATER       0U   /* P1 水质页 */
#define DISPLAY_PAGE_EXEC        1U   /* P2 执行器页 */
#define DISPLAY_PAGE_INFO        2U   /* P3 详情页 */

/* 基线采集进度分母（与 app_main.c 的 pipeline_cfg_t.baseline_n 默认值 20 一致）。
 * 如果以后改基线点数，这个常量要同步改；否则进度页会显示 "BASELINE n/20" 不匹配。 */
#define DISPLAY_BASELINE_TOTAL   20U

/* 数值行刷新周期（ms）：状态变化立即刷新，数值最多 5 Hz。 */
#define DISPLAY_NUM_PERIOD_MS    200U

/* 整屏心跳周期（ms）：即使内容没变也重画一次（屏掉帧/残影自恢复）。 */
#define DISPLAY_HEARTBEAT_MS     1000U

/* 开机页保持时间（ms）：上电先让用户看到 "OLED OK"，再切到状态页。 */
#define DISPLAY_BOOT_HOLD_MS     800U

/*
 * 函数名：display_init
 * 作用：初始化 OLED（I2C0 + SSD1306）并画一屏开机页，证明整条显示链路可用。
 * 参数：无。
 * 返回：true=屏幕可用（后续 display_task 可调用）；false=不可用（app 只打印一次 WARN）。
 * 时序/边界：约 130~150 ms（oled_init 内部含上电延时与清屏）；必须在 UART 初始化之后调用。
 * 注意：返回 false 不是致命错误——本工程的安全路径不依赖显示。
 */
bool display_init(void);

/*
 * 函数名：display_task
 * 作用：把当前"流水线输出 + 判别输出 + 执行器输出"翻译成当前页并刷新
 *       （内容有变化/到节流周期才刷）。
 * 参数：now_ms —— app 的 1 ms 时基（用于节流与心跳；无符号回绕安全）；
 *       p_out  —— 流水线输出（EC0、σ、温度、ΔEC、g、ΔNTU%、note 等）；
 *       p_dec  —— 判别器输出（state/level/action，决定大字与状态串）；
 *       p_valve—— 执行器输出（阀逻辑位置/继电器实际状态/计数/通电时长；可为 NULL）。
 * 返回：true=正常（含"本 tick 无需刷新"）；false=连续 3 帧 I2C 刷新失败或屏幕已判丢失
 *       （app 只打印一次 WARN，之后继续用串口，不影响安全侧）。
 * 时序/边界：在 app_tick() 里每 50 ms 调一次；单次最坏约 25 ms（整屏心跳）。
 * 注意：p_out / p_dec 为 NULL 时直接返回 true（防御，不画屏也不报错）；
 *       p_valve 为 NULL 时 P2/P3 显示 "NO VALVE"（旧固件兼容）。
 */
bool display_task(uint32_t now_ms, const pipeline_out_t *p_out, const decision_out_t *p_dec,
                  const valve_out_t *p_valve);

/*
 * 函数名：display_page_next
 * 作用：K2 短按调用：切到下一页（P1→P2→P3→P1），下一 tick 整屏重画。
 * 参数：无。
 * 返回：切换后的页号（1~3，供串口日志）；屏幕不可用时返回 0（不改变内部页号）。
 * 时序/边界：O(1)，可在主循环上下文调用；不产生 I2C 传输。
 * 注意：显示不是安全路径，切页失败/屏坏不影响判别与阀。
 */
uint8_t display_page_next(void);

/*
 * 函数名：display_page_get
 * 作用：读取当前页号（1~3；屏幕不可用时仍返回 1~3，仅用于日志/调试）。
 * 参数：无。
 * 返回：当前页号 1..3。
 * 时序/边界：O(1)。
 * 注意：仅用于日志/调试。
 */
uint8_t display_page_get(void);

/*
 * 函数名：display_ok
 * 作用：查询显示是否可用（oled_init 成功且未连续失败到"丢失"阈值）。
 * 参数：无。
 * 返回：true=可用；false=初始化失败或已判丢失。
 * 时序/边界：O(1)，可在 app 里用于一次性的 WARN 判断。
 * 注意：显示不可用不代表系统故障，只是"少了一路现场指示"。
 */
bool display_ok(void);

#ifdef __cplusplus
}

#endif /* DISPLAY_H */

 * 刷新数据来源：
 *   pipeline_out_t：EC0/σ/水温/ΔEC/g/ΔNTU%/note；

/* ============================ 小工具 ============================ */

/*
 * 函数名：disp_round_i
 * 作用：浮点四舍五入到 int32（对称舍入，负值也按绝对值进舍）。
 * 参数：v —— 待舍入值（本工程量级远小于 int32 范围，不做溢出保护）。
 * 返回：舍入后的整数。
 * 时序/边界：纯计算，无副作用。
 * 注意：不用 lroundf/roundf（会拉进 libm，本工程禁 libm）。
 */
static int32_t disp_round_i(float v)
{
    if (v >= 0.0f)
    {
        return (int32_t)(v + 0.5f);
    }
    return (int32_t)(v - 0.5f);
}

/*
 * 函数名：disp_copy
 * 作用：安全字符串拷贝（带长度上限，保证 '\0' 结尾）。
 * 参数：p_dst/cap —— 目标与容量；p_src —— 源（NULL 视为空串）。
 * 返回：无。
 * 时序/边界：O(n)；截断而不是溢出。
 * 注意：本工程字符串都是静态字面量或固定缓冲，不会出现超长动态串。
 */
static void disp_copy(char *p_dst, uint32_t cap, const char *p_src)
{
    uint32_t i = 0U;

    if ((NULL == p_dst) || (0U == cap))
    {
        return;
    }

    while ((NULL != p_src) && ('\0' != *p_src) && ((i + 1U) < cap))
    {
        p_dst[i] = *p_src;
        i++;
        p_src++;
    }
    p_dst[i] = '\0';
}

/*
 * 函数名：disp_fmt_temp
 * 作用：把水温格式化成一位小数（如 "25.3"、"-3.0"），不带单位。
 * 参数：p_buf/cap —— 输出缓冲；temp_c —— 水温（℃）。
 * 返回：无。
 * 时序/边界：缓冲 ≥ 7 字节（"-99.9" + '\0'）。
 * 注意：负温度需要保留符号；本工程水温正常在 5~40 ℃，但 DS18B20 故障/冬天也不能
 *       让符号位丢失（否则 -0.5 ℃ 会显示成 0.5 ℃，温补方向就反了）。
 */
static void disp_fmt_temp(char *p_buf, uint32_t cap, float temp_c)
{
    int32_t  t10;
    uint32_t a;
    uint32_t whole;
    uint32_t i = 0U;

    if ((NULL == p_buf) || (0U == cap))
    {
        return;
    }

    t10 = disp_round_i(temp_c * 10.0f);
    if (t10 > 9999)
    {
        t10 = 9999;       /* 显示上限 999.9 ℃（实际水温不可能到，纯防格式化溢出） */
    }
    if (t10 < -9999)
    {
        t10 = -9999;
    }
    a     = (uint32_t)((t10 < 0) ? (-t10) : t10);
    whole = a / 10U;      /* 整数部分（0~999） */
    if (cap < 5U)
    {
        p_buf[0] = '\0';
        return;
    }

    /* 手工拼 "[-]<whole>.<一位小数>"：不用 snprintf，避免 -Wformat-truncation */
    if (t10 < 0)
    {
        p_buf[i] = '-';
        i++;
    }
    if (whole >= 100U)
    {
        p_buf[i] = (char)('0' + (whole / 100U));
        i++;
        whole %= 100U;
        p_buf[i] = (char)('0' + (whole / 10U));
        i++;
        p_buf[i] = (char)('0' + (whole % 10U));
        i++;
    }
    else if (whole >= 10U)
    {
        p_buf[i] = (char)('0' + (whole / 10U));
        i++;
        p_buf[i] = (char)('0' + (whole % 10U));
        i++;
    }
    else
    {
        p_buf[i] = (char)('0' + whole);
        i++;
    }
    p_buf[i] = '.';
    i++;
    p_buf[i] = (char)('0' + (a % 10U));
    i++;
    p_buf[i] = '\0';
}

/*
 * 函数名：disp_fmt_signed_dec
 * 作用：把"×10 缩放"的浮点格式化成带符号一位小数（如 "+5.0"、"-0.5"、"0.0"）。
 * 参数：p_buf/cap —— 输出；value —— 原值（内部×10 取整）。
 * 返回：无。
 * 时序/边界：缓冲 ≥ 8 字节；值域受传感器量程限制，不会溢出。
 * 注意：仅用于显示 dNTU%/变化率这类小量；正值带 '+'，零显示 "0.0"。
 */
static void disp_fmt_signed_dec(char *p_buf, uint32_t cap, float value)
{
    int32_t  x10;
    char     sign;
    uint32_t a;
    uint32_t whole;
    uint32_t frac;

    if ((NULL == p_buf) || (cap < 8U))
    {
        return;
    }

    x10 = disp_round_i(value * 10.0f);
    if (x10 > 99999)
    {
        x10 = 99999;
    }
    if (x10 < -99999)
    {
        x10 = -99999;
    }
    if (x10 < 0)
    {
        sign = '-';
        a    = (uint32_t)(-x10);
    }
    else if (x10 > 0)
    {
        sign = '+';
        a    = (uint32_t)x10;
    }
    else
    {
        sign = ' ';
        a    = 0U;
    }
    whole = a / 10U;
    frac  = a % 10U;
    (void)snprintf(p_buf, (size_t)cap, "%c%lu.%lu", sign,
                   (unsigned long)whole, (unsigned long)frac);
}

/*
 * 函数名：disp_fmt_header
 * 作用：格式化 P1 页头 "EC0=<4位mV> s<σ.一位> T<温度.一位>"；无基线时用 ---- / --- 占位。
 * 参数：p_buf/cap —— 输出；p_out —— 流水线输出。
 * 返回：无。
 * 时序/边界：缓冲 ≥ 22 字节。
 * 注意：EC0 用整数 mV（四舍五入），与 CSV 的 ec0 字段同源；σ 只显示一位小数，
 *       够现场判断"噪声大不大"，精确值看串口 CSV。
 */
static void disp_fmt_header(char *p_buf, uint32_t cap, const pipeline_out_t *p_out)
{
    char    tbuf[8];
    int32_t sig10;

    if ((NULL == p_buf) || (0U == cap) || (NULL == p_out))
    {
        return;
    }

    disp_fmt_temp(tbuf, (uint32_t)sizeof(tbuf), p_out->water_temp_c);

    if (p_out->baseline_valid)
    {
        sig10 = disp_round_i(p_out->ec_sigma_mv * 10.0f);
        if (sig10 < 0)
        {
            sig10 = 0;
        }
        if (sig10 > 999)
        {
            sig10 = 999;   /* 显示上限 99.9 mV，够用；真这么大说明探头/流动池有问题 */
        }
        (void)snprintf(p_buf, (size_t)cap, "EC0=%4u s%u.%u T%s",
                       (unsigned)disp_round_i(p_out->ec0_mv25),
                       (unsigned)((uint32_t)sig10 / 10U),
                       (unsigned)((uint32_t)sig10 % 10U),
                       tbuf);
    }
    else
    {
        (void)snprintf(p_buf, (size_t)cap, "EC0=---- s--- T%s", tbuf);
    }
}

/*
 * 函数名：disp_fmt_numbers
 * 作用：格式化 P1 数值串 "dEC%+dmV g%d.%03d N%+d"（例："dEC+12mV g1.008 N+5"）。
 * 参数：p_buf/cap —— 输出；p_out —— 流水线输出。
 * 返回：无。
 * 时序/边界：缓冲 ≥ 22 字节；N 限幅到 ±99（6x8 一行最多 21 字符）。
 * 注意：g 用"千分位整数"打印（g_milli=1008 → "g1.008"），避免浮点 printf；
 *       ΔEC 用四舍五入整数 mV（与 08 文档记录表的量级一致）。
 */
static void disp_fmt_numbers(char *p_buf, uint32_t cap, const pipeline_out_t *p_out)
{
    int32_t d_ec;
    int32_t g_milli;
    int32_t n;

    if ((NULL == p_buf) || (0U == cap) || (NULL == p_out))
    {
        return;
    }

    d_ec    = disp_round_i(p_out->d_ec_mv);
    g_milli = disp_round_i(p_out->g_ec * 1000.0f);
    n       = disp_round_i(p_out->d_ntu_pct);

    /* 限幅保证整行 ≤21 字符（6x8）：
     * "dEC%+dmV g%d.%03d N%+d" 最坏 "dEC+999mV g9.999 N+99" = 21 字符。 */
    if (d_ec > 999)
    {
        d_ec = 999;
    }
    if (d_ec < -999)
    {
        d_ec = -999;
    }
    if (g_milli < 0)
    {
        g_milli = 0;           /* g 理论上 >0；异常值兜底，防止出现 "g-1.000" */
    }
    if (g_milli > 9999)
    {
        g_milli = 9999;        /* g 显示上限 9.999（防止一行超长） */
    }
    if (n > 99)
    {
        n = 99;
    }
    if (n < -99)
    {
        n = -99;
    }

    (void)snprintf(p_buf, (size_t)cap, "dEC%+dmV g%d.%03d N%+d",
                   (int)d_ec, (int)(g_milli / 1000), (int)(g_milli % 1000), (int)n);
}

/*
 * 函数名：disp_fmt_note
 * 作用：把流水线 note（ADC_TIMEOUT / TDS_RAIL / ...）拼成 "note=xxx" 供故障页显示。
 * 参数：p_buf/cap —— 输出；p_note —— note 字符串（可能为 NULL）。
 * 返回：无。
 * 时序/边界：手动逐字符拼，不用 "%.13s"（避免 -Wformat-truncation 告警）。
 * 注意：note 已由 pipeline 限长 28 字节，这里再按输出缓冲截断。
 */
static void disp_fmt_note(char *p_buf, uint32_t cap, const char *p_note)
{
    static const char prefix[] = "note=";
    uint32_t i = 0U;

    if ((NULL == p_buf) || (0U == cap))
    {
        return;
    }

    while ((prefix[i] != '\0') && ((i + 1U) < cap))
    {
        p_buf[i] = prefix[i];
        i++;
    }
    while ((NULL != p_note) && ('\0' != *p_note) && ((i + 1U) < cap))
    {
        p_buf[i] = *p_note;
        i++;
        p_note++;
    }
    p_buf[i] = '\0';
}

/* ============================ 判断/分页小工具 ============================ */

/*
 * 函数名：disp_is_fault
 * 作用：判断本 tick 是否处于"传感器故障"（与 decision.c 的安全侧判据完全一致）。
 * 参数：p_out —— 流水线输出。
 * 返回：true=故障（ADC 超时 / 任一路状态非 OK）。
 * 时序/边界：纯函数。
 * 注意：故障优先于一切显示——即使 state 是 CLEAR 也必须显示"故障"。
 */
static bool disp_is_fault(const pipeline_out_t *p_out)
{
    return p_out->adc_timeout
        || (SENSOR_OK != p_out->tds_status)
        || (SENSOR_OK != p_out->ntu_status);
}

/*
 * 函数名：disp_valve_manual
 * 作用：判断当前阀是否处于"手动覆盖"（V1/V0）状态。
 * 参数：p_valve —— 执行器输出（可为 NULL）。
 * 返回：true=手动；false=自动/无数据/初始化。
 * 时序/边界：纯函数（一次 strcmp）。
 * 注意：request_reason 是静态串（"AUTO"/"MANUAL_RECOVER"/"MANUAL_DRAIN"/"INIT"）；
 *       "INIT" 按自动处理（第一 tick 之前还没请求过）。
 */
static bool disp_valve_manual(const valve_out_t *p_valve)
{
    if ((NULL == p_valve) || (NULL == p_valve->request_reason))
    {
        return false;
    }
    if ((0 == strcmp(p_valve->request_reason, "AUTO")) ||
        (0 == strcmp(p_valve->request_reason, "INIT")))
    {
        return false;
    }
    return true;
}

/*
 * 函数名：disp_manual_tag
 * 作用：手动模式短标签："V1"（强制回收）/ "V0"（强制排空）。
 * 参数：p_valve —— 执行器输出。
 * 返回：静态字符串。
 * 时序/边界：纯函数。
 * 注意：只用于显示；方向以 position/relay 为准。
 */
static const char *disp_manual_tag(const valve_out_t *p_valve)
{
    if ((NULL != p_valve) && (NULL != p_valve->request_reason) &&
        (0 == strcmp(p_valve->request_reason, "MANUAL_RECOVER")))
    {
        return "V1";
    }
    return "V0";
}

/* ============================ 页面内容：P1 水质页 ============================ */

/*
 * 函数名：disp_build_water_page
 * 作用：构建 P1 水质页（沿用 v1.1 的映射与文案，仅多了页码）。
 * 参数：p_out/p_dec —— 输入；p_page —— 输出。
 * 返回：无。
 * 时序/边界：纯计算；每 50 ms tick 调用一次，开销可忽略。
 * 注意：优先级 = 故障 > 无基线 > 判别状态。
 */
static void disp_build_water_page(const pipeline_out_t *p_out, const decision_out_t *p_dec,
                                  disp_page_t *p_page)
{
    p_page->page = 1U;
    p_page->kind = DISP_KIND_BIG;
    disp_fmt_header(p_page->r0, (uint32_t)sizeof(p_page->r0), p_out);

    /* ① 故障：优先于一切（与 decision.c 的 fault 判据一致） */
    if (disp_is_fault(p_out))
    {
        p_page->big0    = (uint8_t)OLED_HZ32_GU;      /* 故 */
        p_page->big1    = (uint8_t)OLED_HZ32_ZHANG;   /* 障 */
        p_page->inverse = false;
        disp_copy(p_page->r1, (uint32_t)sizeof(p_page->r1), "L1 SENSOR_FAULT");
        disp_fmt_note(p_page->r2, (uint32_t)sizeof(p_page->r2), p_out->note);
        return;
    }

    /* ② 无基线：采集中显示进度，否则提示重采 */
    if (!p_out->baseline_valid)
    {
        uint16_t n = p_out->baseline_n;

        if ((n > 0U) && (n < DISPLAY_BASELINE_TOTAL))
        {
            p_page->big0 = (uint8_t)OLED_HZ32_DAI;    /* 待 */
            p_page->big1 = (uint8_t)OLED_HZ32_JI;     /* 机 */
            (void)snprintf(p_page->r1, (size_t)sizeof(p_page->r1),
                           "BASELINE %2u/%u", (unsigned)n,
                           (unsigned)DISPLAY_BASELINE_TOTAL);
            disp_copy(p_page->r2, (uint32_t)sizeof(p_page->r2), "hold probe in water");
        }
        else
        {
            p_page->big0 = (uint8_t)OLED_HZ32_GU;
            p_page->big1 = (uint8_t)OLED_HZ32_ZHANG;
            disp_copy(p_page->r1, (uint32_t)sizeof(p_page->r1), "L1 NO_BASELINE");
            disp_copy(p_page->r2, (uint32_t)sizeof(p_page->r2), "send B in water");
        }
        return;
    }

    /* ③ 正常：按判别状态映射大字/状态串，第三行给数值 */
    disp_fmt_numbers(p_page->r2, (uint32_t)sizeof(p_page->r2), p_out);

    switch (p_dec->state)
    {
        case DEC_STATE_CLEAR:
            p_page->big0 = (uint8_t)OLED_HZ32_QING;   /* 清 */
            p_page->big1 = (uint8_t)OLED_HZ32_SHUI;   /* 水 */
            disp_copy(p_page->r1, (uint32_t)sizeof(p_page->r1), "CLEAR  RECOVER");
            break;

        case DEC_STATE_UNCERTAIN:
            p_page->big0    = (uint8_t)OLED_HZ32_WU;  /* 污 */
            p_page->big1    = (uint8_t)OLED_HZ32_SHUI;
            p_page->inverse = true;
            disp_copy(p_page->r1, (uint32_t)sizeof(p_page->r1), "L1 UNCERTAIN");
            break;

        case DEC_STATE_SOAP:
            p_page->big0    = (uint8_t)OLED_HZ32_WU;
            p_page->big1    = (uint8_t)OLED_HZ32_SHUI;
            p_page->inverse = true;
            disp_copy(p_page->r1, (uint32_t)sizeof(p_page->r1), "L2 SOAP  DRAIN");
            break;

        case DEC_STATE_FLUSH:
            p_page->big0 = (uint8_t)OLED_HZ32_CHONG;  /* 冲 */
            p_page->big1 = (uint8_t)OLED_HZ32_XI;     /* 洗 */
            disp_copy(p_page->r1, (uint32_t)sizeof(p_page->r1), "FLUSH  DRAIN");
            break;

        case DEC_STATE_WAIT:
        default:
            p_page->big0 = (uint8_t)OLED_HZ32_DAI;
            p_page->big1 = (uint8_t)OLED_HZ32_JI;
            disp_copy(p_page->r1, (uint32_t)sizeof(p_page->r1), "WAIT   EV:OFF");
            break;
    }
}

/* ============================ 页面内容：P2 执行器页 ============================ */

/*
 * 函数名：disp_build_exec_page
 * 作用：构建 P2 执行器页：大字显示阀的实际状态（回收/排空/手动/故障/待机），
 *       第二行继电器实际状态，第三行模式/动作次数/本次通电时长。
 * 参数：p_out/p_dec/p_valve —— 输入（p_valve 可为 NULL）；p_page —— 输出。
 * 返回：无。
 * 时序/边界：纯计算；p_valve 为 NULL 时显示 "NO VALVE"（旧固件/异常兼容）。
 * 注意：大字反映"实际执行结果"（position），不是判别结论；二者在手动/故障时可能不同。
 */
static void disp_build_exec_page(const pipeline_out_t *p_out, const decision_out_t *p_dec,
                                 const valve_out_t *p_valve, disp_page_t *p_page)
{
    bool     manual;
    bool     recover;
    char     temp[24];

    p_page->page = 2U;
    p_page->kind = DISP_KIND_BIG;
    (void)p_dec;   /* P2 只反映执行器与传感器故障/基线状态；判别结论在 P1/P3 显示 */

    if (NULL == p_valve)
    {
        disp_copy(p_page->r0, (uint32_t)sizeof(p_page->r0), "P2/3 EXEC NO VALVE");
        p_page->big0 = (uint8_t)OLED_HZ32_GU;
        p_page->big1 = (uint8_t)OLED_HZ32_ZHANG;
        disp_copy(p_page->r1, (uint32_t)sizeof(p_page->r1), "VALVE NO DATA");
        disp_copy(p_page->r2, (uint32_t)sizeof(p_page->r2), "check p_valve arg");
        return;
    }

    manual = disp_valve_manual(p_valve);

    /* 页头：页号 + 执行器 + 模式 */
    if (p_valve->pin_fault)
    {
        disp_copy(p_page->r0, (uint32_t)sizeof(p_page->r0), "P2/3 EXEC  MODE:FAULT");
    }
    else if (manual)
    {
        disp_copy(p_page->r0, (uint32_t)sizeof(p_page->r0), "P2/3 EXEC MODE:MANUAL");
    }
    else
    {
        disp_copy(p_page->r0, (uint32_t)sizeof(p_page->r0), "P2/3 EXEC  MODE:AUTO");
    }

    /* ① 引脚故障（写/回读失败）：安全侧仍是排空，但必须让人看见 */
    if (p_valve->pin_fault)
    {
        p_page->big0 = (uint8_t)OLED_HZ32_GU;
        p_page->big1 = (uint8_t)OLED_HZ32_ZHANG;
        disp_copy(p_page->r1, (uint32_t)sizeof(p_page->r1), "PIN_FAULT");
        (void)snprintf(p_page->r2, (size_t)sizeof(p_page->r2),
                       "check P104 count=%lu", (unsigned long)p_valve->fault_count);
        return;
    }

    /* ② 传感器故障（判别层安全侧：排空） */
    if (disp_is_fault(p_out))
    {
        p_page->big0 = (uint8_t)OLED_HZ32_GU;
        p_page->big1 = (uint8_t)OLED_HZ32_ZHANG;
        disp_copy(p_page->r1, (uint32_t)sizeof(p_page->r1), "SENSOR_FAULT");
        disp_fmt_note(p_page->r2, (uint32_t)sizeof(p_page->r2), p_out->note);
        return;
    }

    /* ③ 无基线：与 P1 一致的两种提示 */
    if (!p_out->baseline_valid)
    {
        uint16_t n = p_out->baseline_n;

        if ((n > 0U) && (n < DISPLAY_BASELINE_TOTAL))
        {
            p_page->big0 = (uint8_t)OLED_HZ32_DAI;
            p_page->big1 = (uint8_t)OLED_HZ32_JI;
            disp_copy(p_page->r1, (uint32_t)sizeof(p_page->r1), "BASELINING");
            disp_copy(p_page->r2, (uint32_t)sizeof(p_page->r2), "hold probe in water");
        }
        else
        {
            p_page->big0 = (uint8_t)OLED_HZ32_GU;
            p_page->big1 = (uint8_t)OLED_HZ32_ZHANG;
            disp_copy(p_page->r1, (uint32_t)sizeof(p_page->r1), "NO_BASELINE");
            disp_copy(p_page->r2, (uint32_t)sizeof(p_page->r2), "send B in water");
        }
        return;
    }

    /* ④ 正常：大字 = 实际执行状态 */
    recover = (VALVE_POS_RECOVER == p_valve->position);

    if (manual)
    {
        p_page->big0    = (uint8_t)OLED_HZ32_HAND;   /* 手 */
        p_page->big1    = (uint8_t)OLED_HZ32_DONG;   /* 动 */
        p_page->inverse = true;
    }
    else if (recover)
    {
        p_page->big0    = (uint8_t)OLED_HZ32_HUI;    /* 回 */
        p_page->big1    = (uint8_t)OLED_HZ32_SHOU;   /* 收 */
        p_page->inverse = true;                      /* 反显抓眼球；排空用正显 */
    }
    else
    {
        p_page->big0 = (uint8_t)OLED_HZ32_PAI;       /* 排 */
        p_page->big1 = (uint8_t)OLED_HZ32_KONG;      /* 空 */
    }

    /* 第二行（8x16，16 字符）：阀位置 + 继电器实际状态 */
    (void)snprintf(p_page->r1, (size_t)sizeof(p_page->r1), "%s%sRLY:%s",
                   recover ? "RECOVER" : "DRAIN",
                   recover ? "  " : "    ",
                   p_valve->relay_on ? "ON" : "OFF");

    /* 第三行（6x8，21 字符）：模式短标签 + 吸合次数 + 本次通电时长
     * （整秒显示；count/秒数都限幅到 4/3 位，保证最坏情况下不超 21 字符） */
    {
        uint32_t cnt = p_valve->switch_count;
        uint32_t sec = p_valve->on_time_ms / 1000U;

        if (cnt > 9999U)
        {
            cnt = 9999U;
        }
        if (sec > 999U)
        {
            sec = 999U;
        }
        disp_copy(temp, (uint32_t)sizeof(temp), manual ? disp_manual_tag(p_valve) : "AUTO");
        (void)snprintf(p_page->r2, (size_t)sizeof(p_page->r2), "%s CNT:%lu ON:%lus",
                       temp, (unsigned long)cnt, (unsigned long)sec);
    }
}

/* ============================ 页面内容：P3 详情页 ============================ */

/*
 * 函数名：disp_build_info_page
 * 作用：构建 P3 详情页（8 行 6x8）：事件/状态/阀/模式/特征/基线/阈值。
 * 参数：now_ms、p_out、p_dec、p_valve —— 输入；p_page —— 输出。
 * 返回：无。
 * 时序/边界：纯计算；事件已持续时间来自 event_active 上升沿（见 display_task）。
 * 注意：事件超时/无事件时显示 EV:OFF；故障/无基线时最后一行改提示行。
 */
static void disp_build_info_page(uint32_t now_ms, const pipeline_out_t *p_out,
                                 const decision_out_t *p_dec, const valve_out_t *p_valve,
                                 disp_page_t *p_page)
{
    char  tbuf[8];
    char  nbuf[8];
    int32_t ec0;
    int32_t sig10;
    int32_t d_ec;
    int32_t g_milli;
    int32_t ntu_x10;
    int32_t d1_ec;
    int32_t d2_ec;
    int32_t d1_ntu;
    int32_t d2_ntu;

    p_page->page = 3U;
    p_page->kind = DISP_KIND_TEXT;

    (void)memset(p_page->rows, 0, sizeof(p_page->rows));

    /* 行 0：页号 + 事件状态/已持续时长 */
    if (g_event_active)
    {
        uint32_t on_x10 = (uint32_t)(now_ms - g_event_start_ms) / 100U;

        if (on_x10 > 999U)
        {
            on_x10 = 999U;   /* 99.9 s 上限：保证行宽 ≤21 字符（事件超时 30 s，正常到不了） */
        }
        (void)snprintf(p_page->rows[0], DISP_ROW_BUF, "P3/3 INFO EV:ON %lu.%lus",
                       (unsigned long)(on_x10 / 10U), (unsigned long)(on_x10 % 10U));
    }
    else
    {
        disp_copy(p_page->rows[0], DISP_ROW_BUF, "P3/3 INFO EV:OFF");
    }

    /* 行 1：判别状态/等级 */
    (void)snprintf(p_page->rows[1], DISP_ROW_BUF, "STATE:%s LEVEL:%s",
                   decision_state_str(p_dec->state), decision_level_str(p_dec->level));

    /* 行 2：阀实际位置 + 继电器实际状态 */
    if (NULL != p_valve)
    {
        (void)snprintf(p_page->rows[2], DISP_ROW_BUF, "VALVE:%s RLY:%s",
                       valve_pos_str(p_valve->position),
                       p_valve->relay_on ? "ON" : "OFF");
    }
    else
    {
        disp_copy(p_page->rows[2], DISP_ROW_BUF, "VALVE:NO DATA");
    }

    /* 行 3：模式 + 吸合次数 */
    if (NULL != p_valve)
    {
        uint32_t cnt = p_valve->switch_count;

        if (cnt > 9999U)
        {
            cnt = 9999U;
        }
        (void)snprintf(p_page->rows[3], DISP_ROW_BUF, "MODE:%s CNT:%lu",
                       disp_valve_manual(p_valve) ? disp_manual_tag(p_valve) : "AUTO",
                       (unsigned long)cnt);
    }
    else
    {
        disp_copy(p_page->rows[3], DISP_ROW_BUF, "MODE:NO DATA");
    }

    /* 行 4：dEC + g */
    d_ec    = disp_round_i(p_out->d_ec_mv);
    g_milli = disp_round_i(p_out->g_ec * 1000.0f);
    if (g_milli < 0)
    {
        g_milli = 0;
    }
    (void)snprintf(p_page->rows[4], DISP_ROW_BUF, "dEC:%+dmV g:%ld.%03ld",
                   (int)d_ec, (long)(g_milli / 1000), (long)(g_milli % 1000));

    /* 行 5：dNTU%（带符号一位小数）+ 水温 */
    ntu_x10 = disp_round_i(p_out->d_ntu_pct * 10.0f);
    if (ntu_x10 > 999)
    {
        ntu_x10 = 999;
    }
    if (ntu_x10 < -999)
    {
        ntu_x10 = -999;
    }
    disp_fmt_signed_dec(nbuf, (uint32_t)sizeof(nbuf), (float)ntu_x10 / 10.0f);
    disp_fmt_temp(tbuf, (uint32_t)sizeof(tbuf), p_out->water_temp_c);
    (void)snprintf(p_page->rows[5], DISP_ROW_BUF, "dNTU:%s%% T:%sC", nbuf, tbuf);

    /* 行 6：基线 EC0 + 噪声 σ（无基线时占位） */
    if (p_out->baseline_valid)
    {
        ec0  = disp_round_i(p_out->ec0_mv25);
        sig10 = disp_round_i(p_out->ec_sigma_mv * 10.0f);
        if (sig10 < 0)
        {
            sig10 = 0;
        }
        (void)snprintf(p_page->rows[6], DISP_ROW_BUF, "EC0:%ldmV s:%ld.%ld",
                       (long)ec0, (long)(sig10 / 10), (long)(sig10 % 10));
    }
    else
    {
        disp_copy(p_page->rows[6], DISP_ROW_BUF, "EC0:----mV s:---");
    }

    /* 行 7：默认显示当前生效的 d1/d2 阈值；故障/无基线时改为提示行 */
    if (disp_is_fault(p_out))
    {
        disp_fmt_note(p_page->rows[7], DISP_ROW_BUF, p_out->note);
    }
    else if (!p_out->baseline_valid)
    {
        disp_copy(p_page->rows[7], DISP_ROW_BUF, "send B in water");
    }
    else
    {
        d1_ec  = disp_round_i(p_dec->d1_ec_mv);
        d2_ec  = disp_round_i(p_dec->d2_ec_mv);
        d1_ntu = disp_round_i(p_dec->d1_ntu_pct);
        d2_ntu = disp_round_i(p_dec->d2_ntu_pct);
        /* 限幅：最坏 "d1:999/99% d2:999/99%" = 21 字符（6x8 一行上限） */
        if (d1_ec < 0) { d1_ec = 0; }
        if (d1_ec > 999) { d1_ec = 999; }
        if (d2_ec < 0) { d2_ec = 0; }
        if (d2_ec > 999) { d2_ec = 999; }
        if (d1_ntu < 0) { d1_ntu = 0; }
        if (d1_ntu > 99) { d1_ntu = 99; }
        if (d2_ntu < 0) { d2_ntu = 0; }
        if (d2_ntu > 99) { d2_ntu = 99; }
        (void)snprintf(p_page->rows[7], DISP_ROW_BUF, "d1:%ld/%ld%% d2:%ld/%ld%%",
                       (long)d1_ec, (long)d1_ntu, (long)d2_ec, (long)d2_ntu);
    }
}

/*
 * 函数名：disp_build_page
 * 作用：按当前页号构建目标内容（不画屏）。
 * 参数：now_ms/p_out/p_dec/p_valve —— 输入；p_page —— 输出。
 * 返回：无。
 * 时序/边界：纯计算；每 50 ms tick 调用一次。
 * 注意：g_page 是内部页索引 0..2，对应 P1/P2/P3。
 */
static void disp_build_page(uint32_t now_ms, const pipeline_out_t *p_out,
                            const decision_out_t *p_dec, const valve_out_t *p_valve,
                            disp_page_t *p_page)
{
    (void)memset(p_page, 0, sizeof(*p_page));

    switch (g_page)
    {
        case DISPLAY_PAGE_EXEC:
            disp_build_exec_page(p_out, p_dec, p_valve, p_page);
            break;

        case DISPLAY_PAGE_INFO:
            disp_build_info_page(now_ms, p_out, p_dec, p_valve, p_page);
            break;

        case DISPLAY_PAGE_WATER:
        default:
            disp_build_water_page(p_out, p_dec, p_page);
            break;
    }
}

/* ============================ 区域重画 ============================ */

/*
 * 函数名：disp_draw_page_no
 * 作用：在大字带右上角画 "n/3" 页码（6x8，3 字符，x=98 起，不压大字）。
 * 参数：page —— 页号 1..3。
 * 返回：无。
 * 时序/边界：只改写显存；调用前大字带已清黑。
 * 注意：页码只是"当前第几页"的提示，不是安全信息。
 */
static void disp_draw_page_no(uint8_t page)
{
    char buf[8];

    (void)snprintf(buf, sizeof(buf), "%u/%u", (unsigned)page, (unsigned)DISPLAY_PAGE_COUNT);
    oled_text_6x8(DISP_PAGENO_X, DISP_PAGENO_Y, buf);
}

/*
 * 函数名：disp_redraw_header
 * 作用：重画页头（先清该 8 行带，再写 6x8 文本，避免旧串尾部残留）。
 * 参数：p_page —— 目标内容。
 * 返回：无。
 * 时序/边界：O(128*8) 显存写，无 I2C。
 */
static void disp_redraw_header(const disp_page_t *p_page)
{
    oled_fill_rect(DISP_HEAD_X, DISP_HEAD_Y, OLED_WIDTH, 8U, false);
    oled_text_6x8(DISP_HEAD_X, DISP_HEAD_Y, p_page->r0);
}

/*
 * 函数名：disp_redraw_big
 * 作用：重画大字带（y=8..39 整带清黑，再画两个 32x32 汉字 + 右上角页码）。
 * 参数：p_page —— 目标内容。
 * 返回：无。
 * 时序/边界：清带 128*32 像素 + 两个汉字各 128 字节，无 I2C。
 * 注意：为什么要整带清：切页/开机页残留都在这 32 行里；不清会留半个旧字。
 */
static void disp_redraw_big(const disp_page_t *p_page)
{
    oled_fill_rect(0U, DISP_BIG_Y, OLED_WIDTH, DISP_BIG_BAND_H, false);
    oled_hz32(DISP_BIG_X0, DISP_BIG_Y, (oled_hz32_id_t)p_page->big0, p_page->inverse);
    oled_hz32(DISP_BIG_X1, DISP_BIG_Y, (oled_hz32_id_t)p_page->big1, p_page->inverse);
    disp_draw_page_no(p_page->page);
}

/*
 * 函数名：disp_redraw_line2
 * 作用：重画第二行（8x16；先清 16 行带，再写文本）。
 * 参数：p_page —— 目标内容。
 * 返回：无。
 * 时序/边界：O(128*16) 显存写，无 I2C。
 * 注意：8x16 文本函数不负责清行尾，必须先 fill_rect。
 */
static void disp_redraw_line2(const disp_page_t *p_page)
{
    oled_fill_rect(DISP_LINE2_X, DISP_LINE2_Y, OLED_WIDTH, 16U, false);
    oled_text_8x16(DISP_LINE2_X, DISP_LINE2_Y, p_page->r1);
}

/*
 * 函数名：disp_redraw_line3
 * 作用：重画第三行（6x8；先清 8 行带，再写文本）。
 * 参数：p_page —— 目标内容。
 * 返回：无。
 * 时序/边界：O(128*8) 显存写，无 I2C。
 */
static void disp_redraw_line3(const disp_page_t *p_page)
{
    oled_fill_rect(DISP_LINE3_X, DISP_LINE3_Y, OLED_WIDTH, 8U, false);
    oled_text_6x8(DISP_LINE3_X, DISP_LINE3_Y, p_page->r2);
}

/*
 * 函数名：disp_redraw_row
 * 作用：重画详情页的一行（6x8；先清该 8 行带，再写文本）。
 * 参数：row —— 行号 0..7；p_text —— 文本。
 * 返回：无。
 * 时序/边界：O(128*8) 显存写，无 I2C。
 */
static void disp_redraw_row(uint8_t row, const char *p_text)
{
    oled_fill_rect(0U, (uint8_t)(row * 8U), OLED_WIDTH, 8U, false);
    oled_text_6x8(0U, (uint8_t)(row * 8U), p_text);
}

/* ============================ 对外接口 ============================ */

/*
 * 函数名：display_init
 * 作用：初始化 OLED 并画开机页（证明 I2C/驱动/字库整条链路可用）。
 * 参数：无。
 * 返回：true=可用；false=不可用（上层只打印一次 WARN）。
 * 时序/边界：约 150 ms（oled_init 上电延时 100 ms + 初始化命令 + 清屏 + 开机页）。
 * 注意：开机页会在屏上保持约 DISPLAY_BOOT_HOLD_MS（800 ms），由 display_task 负责
 *       计时切换，这样上电自检时人能看清 "OLED OK"。
 */
bool display_init(void)
{
    g_shown_once   = false;
    g_first_seen   = false;
    g_first_ms     = 0U;
    g_last_num_ms  = 0U;
    g_last_full_ms = 0U;
    g_fail_count   = 0U;
    g_page         = DISPLAY_PAGE_WATER;   /* 默认 P1 水质页 */
    g_force_full   = true;
    g_shown_page   = 0U;
    g_shown_kind   = DISP_KIND_BIG;
    g_event_active = false;
    g_event_prev_active = false;
    g_event_start_ms = 0U;
    (void)memset(g_shown_r0, 0, sizeof(g_shown_r0));
    (void)memset(g_shown_r1, 0, sizeof(g_shown_r1));
    (void)memset(g_shown_r2, 0, sizeof(g_shown_r2));
    (void)memset(g_shown_rows, 0, sizeof(g_shown_rows));
    g_shown_big0    = 0U;
    g_shown_big1    = 0U;
    g_shown_inverse = false;

    if (!oled_init())
    {
        return false;
    }

    /* 开机页：7 行固定文案，全部 8 像素对齐（字库/文本函数只支持页对齐） */
    oled_clear();                                            /* 全屏黑 + 8 页全脏 */
    oled_text_6x8(0U, 0U,  "RA4M2 WATER JUDGE");
    oled_text_8x16(0U, 8U, "OLED OK");
    oled_text_6x8(0U, 24U, "SSD1306 128x64");
    oled_text_6x8(0U, 32U, "I2C0 0x3C 400kHz");
    oled_text_6x8(0U, 40U, "SENSOR-NODE v1.3");
    oled_text_6x8(0U, 48U, "P1/P2/P3 K2=NEXT");
    oled_text_6x8(0U, 56U, "M=MARK (UART)");

    if (!oled_flush())
    {
        /* 初始化已成功但首帧失败：按"不可用"返回，让 app 打印 WARN（显示不是安全路径） */
        return false;
    }

    return true;
}

/*
 * 函数名：display_page_next
 * 作用：K2 短按调用：循环切到下一页（P1→P2→P3→P1），下一次 display_task 整屏重画。
 * 参数：无。
 * 返回：切换后的页号 1..3；屏幕不可用时返回 0（不改变内部页号）。
 * 时序/边界：O(1)，无 I2C。
 * 注意：显示不是安全路径；切页不影响判别/阀。
 */
uint8_t display_page_next(void)
{
    if (!oled_ready())
    {
        return 0U;
    }
    g_page = (uint8_t)((g_page + 1U) % DISPLAY_PAGE_COUNT);
    g_force_full = true;
    return (uint8_t)(g_page + 1U);
}

/*
 * 函数名：display_page_get
 * 作用：读取当前页号（1..3）。
 * 参数：无。
 * 返回：当前页号。
 * 时序/边界：O(1)。
 */
uint8_t display_page_get(void)
{
    return (uint8_t)(g_page + 1U);
}

/*
 * 函数名：display_task
 * 作用：把当前数据画到当前页（差异刷新 + 200 ms 数值节流 + 1 s 心跳 + 切页整屏重画）。
 * 参数：now_ms —— app 时基；p_out/p_dec —— 流水线与判别输出；p_valve —— 执行器输出（可 NULL）。
 * 返回：true=正常（含本 tick 无需刷新）；false=连续 3 帧失败/屏已丢失。
 * 时序/边界：每 50 ms 调一次；最坏约 25 ms（心跳整屏）；单次失败不阻塞主循环。
 * 注意：本函数不打印——WARN 由 app_main 在第一次收到 false 时打印，避免刷屏。
 */
bool display_task(uint32_t now_ms, const pipeline_out_t *p_out, const decision_out_t *p_dec,
                  const valve_out_t *p_valve)
{
    disp_page_t page;
    bool        need_full;
    bool        need_num;
    bool        big_changed;
    uint8_t     row;

    /* 屏幕不可用/已丢失：直接返回 false，让 app 的一次性 WARN 生效；不占主循环时间 */
    if (!oled_ready())
    {
        return false;
    }

    if ((NULL == p_out) || (NULL == p_dec))
    {
        return true;   /* 防御：上层还没准备好数据，本 tick 不画 */
    }

    /* 开机页保持：第一次调用记录基准时刻，之后 800 ms 内不覆盖开机页 */
    if (!g_first_seen)
    {
        g_first_seen = true;
        g_first_ms   = now_ms;
    }
    if ((now_ms - g_first_ms) < DISPLAY_BOOT_HOLD_MS)
    {
        return true;
    }

    /* 事件计时：event_active 上升沿记录起点（P3 显示已持续时间） */
    g_event_prev_active = g_event_active;
    g_event_active      = p_dec->event_active;
    if (g_event_active && (!g_event_prev_active))
    {
        g_event_start_ms = now_ms;
    }

    /* ① 算目标内容，并与上一屏比较，决定重画哪些区域 */
    disp_build_page(now_ms, p_out, p_dec, p_valve, &page);

    need_full = (!g_shown_once) || g_force_full || (page.page != g_shown_page)
             || (page.kind != g_shown_kind)
             || ((now_ms - g_last_full_ms) >= DISPLAY_HEARTBEAT_MS);
    need_num  = ((now_ms - g_last_num_ms) >= DISPLAY_NUM_PERIOD_MS);

    if (need_full)
    {
        /* 心跳/首帧/切页：整屏重画（顺带清掉旧页残留；也是"屏还活着"的自恢复手段） */
        oled_clear();
        if (DISP_KIND_BIG == page.kind)
        {
            disp_redraw_header(&page);
            disp_redraw_big(&page);
            disp_redraw_line2(&page);
            disp_redraw_line3(&page);
        }
        else
        {
            for (row = 0U; row < DISP_INFO_ROWS; row++)
            {
                disp_redraw_row(row, page.rows[row]);
            }
        }
        g_last_full_ms = now_ms;
        g_last_num_ms  = now_ms;
        g_force_full   = false;

        /* 整屏已画：缓存全部同步 */
        disp_copy(g_shown_r0, (uint32_t)sizeof(g_shown_r0), page.r0);
        disp_copy(g_shown_r1, (uint32_t)sizeof(g_shown_r1), page.r1);
        disp_copy(g_shown_r2, (uint32_t)sizeof(g_shown_r2), page.r2);
        for (row = 0U; row < DISP_INFO_ROWS; row++)
        {
            disp_copy(g_shown_rows[row], DISP_ROW_BUF, page.rows[row]);
        }
        g_shown_big0    = page.big0;
        g_shown_big1    = page.big1;
        g_shown_inverse = page.inverse;
        g_shown_page    = page.page;
        g_shown_kind    = page.kind;
    }
    else if (DISP_KIND_BIG == page.kind)
    {
        /* 大字/状态串变化：现场最关心的信息，立即重画（不等 200 ms 节流） */
        big_changed = (page.big0 != g_shown_big0) || (page.big1 != g_shown_big1)
                   || (page.inverse != g_shown_inverse);
        if (big_changed)
        {
            disp_redraw_big(&page);
        }
        if (0 != strcmp(page.r1, g_shown_r1))
        {
            disp_redraw_line2(&page);
            disp_copy(g_shown_r1, (uint32_t)sizeof(g_shown_r1), page.r1);
        }
        /* 页头（EC0/σ/温度）与第三行（dEC/g/N）是数值行：最快 200 ms 刷一次，
         * 与文档口径一致（v1.3.0 审查 P1-1：此前少了 need_num 门控，每 tick 都刷）。 */
        if (need_num)
        {
            if (0 != strcmp(page.r0, g_shown_r0))
            {
                disp_redraw_header(&page);
                disp_copy(g_shown_r0, (uint32_t)sizeof(g_shown_r0), page.r0);
            }
            if (0 != strcmp(page.r2, g_shown_r2))
            {
                disp_redraw_line3(&page);
                disp_copy(g_shown_r2, (uint32_t)sizeof(g_shown_r2), page.r2);
            }
            g_last_num_ms = now_ms;
        }
        if (big_changed)
        {
            g_shown_big0    = page.big0;
            g_shown_big1    = page.big1;
            g_shown_inverse = page.inverse;
        }
    }
    else
    {
        /* 详情页：前 3 行（事件/状态/阀）立即刷新；数值行 4~7 节流到 200 ms */
        for (row = 0U; row < 3U; row++)
        {
            if (0 != strcmp(page.rows[row], g_shown_rows[row]))
            {
                disp_redraw_row(row, page.rows[row]);
                disp_copy(g_shown_rows[row], DISP_ROW_BUF, page.rows[row]);
            }
        }
        if (need_num)
        {
            for (row = 3U; row < DISP_INFO_ROWS; row++)
            {
                if (0 != strcmp(page.rows[row], g_shown_rows[row]))
                {
                    disp_redraw_row(row, page.rows[row]);
                    disp_copy(g_shown_rows[row], DISP_ROW_BUF, page.rows[row]);
                }
            }
            g_last_num_ms = now_ms;
        }
    }

    /* ② 只刷脏页（oled_flush 内部实现）；连续失败 3 帧才报给上层 */
    if (!oled_flush())
    {
        g_fail_count++;
        if (g_fail_count >= DISPLAY_FAIL_LIMIT)
        {
            return false;
        }
        return true;   /* 前两帧失败先不打扰上层：脏页位保留，下一帧自动重试 */
    }

    g_fail_count = 0U;
    return true;
}

/*
 * 函数名：display_ok
 * 作用：查询显示是否可用。
 * 参数：无。
 * 返回：true=oled 已初始化且未判丢失。
 * 时序/边界：O(1)。
 * 注意：与 oled_ready() 同义，保留此接口是为了让 app_main 不直接依赖 oled.h。
 */
bool display_ok(void)
{
    return oled_ready();
}

5. 行为规格（现场/验收用）
--------------------------------------------------------------------------------
5.1 按键
    K2 短按（松手判定，<1.5 s）：切页 P1→P2→P3→P1；串口打印 "# DISPLAY page=n/3 (K2)"；
    K2 长按（按住 ≥1.5 s，按住期间触发）：重采基线（与串口 B 等效，原有行为不变）；
    K2 不再打 MARK；MARK 只由串口命令 M 发送（# MARK t=... src=UART）。
    注意：这是行为变更——原 00/12 文档写"短按 MARK"，v1.3.0 起以本文为准（00/12 已同步）。

5.2 页面切换时序
    默认 P1（开机页从 display_task 首次调用起保持 800 ms；含上电初始化总约 1.6 s 后进 P1）；
     切页在 K2 松手后的下一个 50 ms tick
    生效；切页后整屏重画一次（清掉旧页残留）。不自动轮播。

5.3 数据来源与一致性
    P1：pipeline_out_t + decision_out_t（与 v1.1 完全相同的映射）；
    P2：valve_out_t（position/relay_on/switch_count/on_time_ms/request_reason/pin_fault）
        + 传感器故障/基线状态（与 P1 同判据）；
    P3：上述 + decision_out_t 的 d1/d2（当前生效阈值）+ 事件计时（display.c 自测）；
    所有数值均为整数格式化（无浮点 printf、无 libm），与 CSV 字段同源/同量级。

5.4 显示失败时的行为
    与 v1.1 相同：oled_init 失败 → 只打印一次 "# WARN: OLED not usable -> UART only"；
    运行中连续 3 帧 I2C 失败 → display_task 返回 false → 只打印一次
    "# WARN: OLED lost at t=... ms -> UART only"，之后不再占主循环时间；
    判别/CSV/LED/阀全部照常（显示不是安全路径）。

5.5 资源占用
    字库 +768 B（6 字 × 128 B）；display.c 代码/字符串约 +4544 B，合计使 text
    从 51724→57036（+5312 B）；
    bss 从 10836→11036（+200 B，三页内容缓存 + 事件计时等静态变量）；无动态内存、无 libm。

7. 验收测试 T1~T8（OLED 专项；不替代 15 文档的执行器验收）
--------------------------------------------------------------------------------
  T1 字库/开机页
     操作：上电；看开机页 7 行（RA4M2 WATER JUDGE / OLED OK / SSD1306 128x64 /
           I2C0 0x3C 400kHz / SENSOR-NODE v1.3 / P1/P2/P3 K2=NEXT / M=MARK (UART)）。
     判据：无花屏/无残字；开机页在 display_task 首次调用后约 800 ms 切到 P1
           （含上电初始化总约 1.6 s）；串口 boot 行版本 v1.3.0-OLED。
  T2 P1 三态
     操作：待机（WAIT）、发 R（FLUSH）、判别 CLEAR/SOAP（按 08 文档流程）。
     判据：大字 待机/冲洗/清水/污水（反显）正确；第二行状态串与串口 state 一致；
           第三行 dEC/g/N 与 P 状态/CSV 同量级。
  T3 K2 切页循环
     操作：连续短按 K2 ≥6 次。
     判据：页面按 P1→P2→P3→P1 循环；P1/P2 右上角页码 1/3、2/3 正确；
            P3 首行行首为 "P3/3"（详情页无右上角页码）；
           串口每次打印 # DISPLAY page=n/3 (K2)；无闪屏/残字。
  T4 P2 执行器语义
     操作：不接 12V，发 V1（强制回收，继电器吸合）→ 切到 P2 看；发 V0（释放）再看；发 VA 回自动。
     判据：V1 时大字"手动"（反显）、第二行 RECOVER RLY:ON、第三行 V1 CNT:n ON:…；
           V0 时 DRAIN RLY:OFF、V0 标签；AUTO 且判别可回收时大字"回收"（反显）、RLY:ON；
           AUTO 排空时大字"排空"、RLY:OFF。大字与继电器实际状态一致。
  T5 P3 字段
     操作：切到 P3；对照串口 P 状态与 CSV。
     判据：STATE/LEVEL/MODE/CNT/VALVE/RLY 与串口一致；dEC/g/dNTU/T 与 CSV 同量级；
           EC0/σ 与 P 状态一致；d1/d2 与 P 状态 thresholds 一致；事件进行中 EV:ON 秒数递增。
  T6 事件计时
     操作：发 R 开始事件，切 P3 观察 ≥5 s；发 E 结束再看。
     判据：EV:ON x.xs 递增（0.1 s 精度、内容变化即刷）；结束后变 EV:OFF。
  T7 长按基线（原有行为保留）
     操作：按住 K2 ≥1.5 s 松开。
     判据：串口 "# KEY: long press -> baseline recalibration" + "# BASELINE start"；
           不切页；短按才切页。
  T8 故障/异常
     操作：① 拔 TDS 模块 AOUT（或断开 TDS 信号）→ 应触发 TDS 故障；
           ② DS18B20 拔出只是温度源退化为 25℃ 兜底（CSV src=FIX），**不是**传感器故障，
              不应期待 P1/P2 显示"故障"（这是常见误判点，见 04 文档）；
           ③ OLED 是板载焊死的，没有排线可拔；想验证"屏丢失降级"须按 10 文档 §7 的
              注入法（临时把 I2C 从机地址改错后重烧），或跳过（v1.1 已验证过）。
     判据：① TDS 故障时 P1/P2 显示"故障"+note=...，CSV note 有故障标记、action 仍 DRAIN；
           ② DS18B20 拔出后 CSV src=FIX、T=25.0，判别/阀按正常逻辑运行；
           OLED 掉线只打印一次 WARN，串口/CSV/阀继续工作。
  记录表：T1__ T2__ T3__ T4__ T5__ T6__ T7__ T8__（通过打 ✓）
          K2 循环次数实测：____   P2 大字与 RLY 一致：是/否   P3 事件计时误差：____s


8. 排障
--------------------------------------------------------------------------------
  现象                          可能原因/处理
  ----------------------------  ----------------------------------------------------
  P2 大字仍是 P1 的画面           K2 没按到位/按下时间 >1.5 s 被当长按（会重采基线）；
                                确认串口有无 # DISPLAY page=…；若 OLED 已判丢失则三页全无，见串口 WARN。
  P2 显示 NO VALVE              显示任务没拿到 valve 数据（旧集成忘了传第 4 个参数）→ 按 §4.4 传
                                valve_get_out(&g_valve)。

                                按 §3.2/§3.3 核对；重新编译。
  切页后残字/花屏               oled_flush 失败或整屏重画被跳过 → 看串口 WARN；检查 I2C 排线/上拉；
                                心跳 1 s 会自动整屏重画自恢复。
  P3 行显示被截断               数据超长（如计数/秒数/note 过长）→ 已限幅；若仍出现，记录 P/CSV 值反馈。
  K2 短按没打 MARK               行为变更：v1.3.0 起 MARK 只由串口 M 发送（见 §9.1）。
  boot 行还是 v1.2.0             烧了旧 hex → 按 §0.2 核对 SHA-256/boot 行。
  OLED 不亮/全黑                 与 v1.1 相同：先查 RASC 的 I2C0 栈与 P407/P408，再查排线；显示不是安全路径。


9. 红线与已知限制
--------------------------------------------------------------------------------
9.1 行为变更（必须在团队内同步）
    - K2 短按：v1.3.0 起 = 切 OLED 页（原 = 打 MARK）；MARK 改用串口 M；
    - 长按 K2 ≥1.5 s：不变（重采基线）；
    - 串口命令集/CSV 17 列：不变；其它硬件接线不变。
9.2 显示口径（红线）
    - P1 是"判别结论"（清水/污水等），P2 是"执行器实际状态"（回收/排空/手动），
      二者在手动 V1/V0、MAX_ON 冷却、故障时可能不同；答辩时以 # VALVE 事件行/串口为准；
    - OLED 只做现场指示，不是数据来源，也不是安全执行路径；屏坏不影响判别/CSV/LED/阀；
    - 不写"识别污染物/达标"；P3 的 dNTU 仍是相对量，不是 NTU。
9.3 已知限制
    - 无自动轮播（刻意）；需要人按 K2 切页；
    - P3 是 6x8 小字，远看不易读（演示让评委看 P1/P2 大字，P3 用近看/调试）；
    - 字库固定 15 字，不能显示任意中文；新增字须改 oled.h + oledfont.h（§3.4）；
    - P2 的"手动"大字只表示"处于手动覆盖"，方向看第二行 RECOVER/DRAIN 与 V1/V0 标签；
    - 事件计时以 display.c 第一次看到 event_active=true 的 tick 为起点，50 ms 量化；
      与 CSV 时间戳对齐时允许 ≤1 tick 误差。

--------------------------------------------------------------------------------
10.1 页号/按键速查
    P1 = 水质页（默认）；P2 = 执行器页；P3 = 详情页；
    K2 短按 = 下一页；K2 长按 ≥1.5 s = 重采基线；串口 M = MARK；
