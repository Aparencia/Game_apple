# HC-SR04 液位扩展计划（2026-11-19，仅液位）

- 基线：`v2.7.6-B3`
- 分支：`sensors-level-flow`
- 目标版本：`v2.8.0-LEVEL`
- 变更：**微型流量计不接入**（30~120 ml/min 量程太小，旁路分流比不稳定）

---

## 1. 目标

只新增 **HC-SR04 液位**：

| 用途 | 说明 |
|---|---|
| 空腔/进水/满水/排水 | 液位状态机 |
| 稳定液位门控 | 稳定才允许 `MEASURE`/标定 |
| 液位变化时冻结 | 禁止分类、禁止 baseline trim |
| 辅助判断泡沫/假回波 | 液位与预期不符时告警 |

**不做**：

- 不接流量计；
- 不测传感器→阀传输时间；
- 不用累积流量替代 `blank_ms`；
- 不改 EC/NTU 判定阈值。

## 2. 硬件

### 2.1 HC-SR04 标准四针

```
VCC   5V
GND   共地
TRIG  3.3V GPIO → 电平转换 → 5V
ECHO  5V 脉冲 → 1k/2k 分压 → 3.3V → GPT 输入捕获
```

- 探头装在最高水位以上，只测空气路径；
- 防水：薄 PE/PTFE 声学窗 + 背面密封，**不要厚灌封探头正面**；
- 加干燥剂/透气阀防冷凝；
- 5V 电流约 15 mA。

### 2.2 引脚（已对照 RA4M2_MINI 排针表）

| 信号 | 引脚 | 排针 | 复用/注意 |
|---|---|---|---|
| TRIG | **P402** | U1-2 | GPIO 输出；3.3V → 需 5V 电平转换 |
| ECHO | **P301** | U1-18 | **GPT4 输入捕获**；5V 必须分压 |
| VCC | 5V | U2-19/20 | 约 15mA |
| GND | GND | U1-1/8/16 | 星形单点共地 |

备选：

- 若 P301 无法映射 GPT4 GTIOC，改用 **P302（U1-19，GPT4）**；
- P409/U2-3、P206/U2-16 保持空闲（未来流量计/蜂鸣器）。

### 2.3 电平

- P301 不是 5V 容忍：ECHO 用 1k 串联 + 2k 对地，节点 ≤3.2V；
- P402 是 3.3V：TRIG 用 74LVC1T45 或 NPN/2N7002 做 3.3→5V；
- 共地，5V 从 U2-19/20 取。

---

## 3. FSP

新增：

1. **GPT4**：1 MHz 自由运行，P301 输入捕获，上升/下降沿；
2. P402 普通 GPIO 输出；
3. 中断优先级：GPT4 捕获高于 50ms 主循环；
4. 不占用 ADC/IIC/SCI。

验证点：

- P301 在 FSP Pin 页能选到 GPT4 的 GTIOC；
- 捕获中断能稳定拿到 Echo 上升/下降沿。

## 4. 软件

### 4.1 `hc_sr04.c/h`

```c
void hc_sr04_init(void);
void hc_sr04_task(uint32_t now_ms);      /* 非阻塞，20~30 ms 一次 */
bool hc_sr04_get_mm(uint16_t *p_mm, bool *p_valid);
uint32_t hc_sr04_age_ms(void);
```

实现：

- Trig 10µs；
- GPT4 捕获 Echo 脉宽；
- `mm = pulse_us × 0.343 / 2`（用 DS18B20 温度修正声速）；
- 限幅 20~2000 mm；
- 3 次中值/多数表决；
- 超时/无回波 → invalid；
- 不阻塞主循环。

### 4.2 液位状态机

```c
typedef enum { LV_EMPTY, LV_FILL, LV_STABLE, LV_DRAIN } level_state_t;
```

| 条件 | 状态 | 动作 |
|---|---|---|
| level < 10 mm | EMPTY | DRY，禁止标定/回收 |
| 上升 >5 mm/s | FILL | 不分类 |
| \|rate\| <1 mm/s | STABLE | 允许 MEASURE |
| 下降 >5 mm/s | DRAIN | 不分类 |

与现有 gate：

- STABLE 才允许 `MEASURE`；
- 标定只在 STABLE 且与实际运行液位一致时做；
- 液位变化时禁止 `app_baseline_trim_task()`；
- 液位无效时退回 v2.7.6 的原有 gate（不阻塞系统）。

### 4.3 日志

先加事件行，不改 17 列 CSV：

```
# LEVEL t=... mm=... state=... valid=...
# SENSOR level=OK/INVALID
```

验证稳定后，再考虑 CSV 追加 `level_mm`。

## 5. 标定

1. **零点**：空腔，记录 HC 距离/偏移；
2. **量程**：用直尺/定容，记录 50/100/150 mm 对应值；
3. **温度补偿**：用 DS18B20 修正声速；
4. **泡沫测试**：记录泡沫层下 HC 是否跳变；
5. 写入常量/命令（先编译常量，后续加 `L` 命令）。

---

## 6. 测试/验收

### 台架

- 液位 0/50/100/150 mm：误差 ≤5 mm；
- 空腔/进水/满水/排水状态切换正确；
- 阀/继电器动作时 GPT4 不误触发；
- 5V/3.3V 电平安全；
- 泡沫层下记录 HC 失效情况。

### 现场

- 清水：液位 STABLE → CLEAR；
- 肥皂冲洗水：不因液位误判；
- 失水：DRAIN/DRY；
- 与 v2.7.6 日志对比，确认无回归。

## 7. 风险

| 风险 | 缓解 |
|---|---|
| HC 泡沫误判 | 液位仅做门控，不单独决定水质；必要时换压力式 |
| 5V Echo 损坏 MCU | 分压+钳位，先测节点电压 |
| P301 GPT4 映射不到 | 改 P302；或换 JSN-SR04T |
| 小腔体多径反射 | 20~2000mm 限幅 + 中值；安装避开壁面 |
| 液位无效 | 回退 v2.7.6 gate，不阻塞系统 |

## 9. 流量计（暂缓）

当前 30~120 ml/min 流量计：

- 量程太小，主路可能 >120 ml/min；
- 旁路分流比随流量/压力/堵塞变化，不能稳定反推主路；
- 不能测传感器→阀传输时间。

后续若需要：

1. 先实测主路流量；
2. 选 0.1~1 L/min 或 1~5 L/min 量程；
3. 串主路，不做旁路；
4. 再考虑累积流量门控。
