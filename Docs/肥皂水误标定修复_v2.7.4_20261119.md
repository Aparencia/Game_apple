# 肥皂冲洗水误当清水基线修复（v2.7.4-B3）

- 日期：2026-11-19
- 固件：`SENSOR-NODE v2.7.4-B3`
- 构建：`text 84684 / data 480 / bss 11440`，0 error / 0 warning
- 基于：`v2.7.3-B3`

---

## 1. 这份日志不是“肥皂没检出”，而是“把肥皂当成了本底”

上电自检时腔内是肥皂冲洗水，自动标定直接把它采成了基线：

```
# BASELINE OK ec0=373.8mV ntu0=2581mV ...
# BASELINE SLOT DRAIN   ec0=373.8mV
# BASELINE OK ec0=553.0mV ntu0=2588mV ...
# BASELINE SLOT RECOVER ec0=553.0mV
```

对照之前清水：

| 水样 | DRAIN EC0 | RECOVER EC0 | ntu0(AO) |
|---|---|---|---|
| 清水（v2.7.3） | 343.5 | 406.5 | 2839 / 2856 |
| 这次肥皂冲洗水 | **373.8** | **553.0** | **2581 / 2588** |

肥皂水 EC 高约 30/147 mV，AO 低约 250 mV，但旧 AO 清洁门槛是 250 mV：

```
AO - AO_DRY ≈ 244 mV < 250 mV
```

只差 6 mV，没拦住，于是肥皂水成了“清水基线”。之后分类器把肥皂水与它自己比较，当然全程 CLEAR：

- `CLEAR` 740 行；
- `SOAP` 只有 20 行，且都出现在失水/探头脱水瞬间；
- 稳定段没有 SOAP。

---

## 2. 修复

`ao_clean_delta_mv`：**250 → 300 mV**

```c
.ao_clean_delta_mv = 300.0f
```

依据：

- 清水 AO-AO_DRY ≈ **500 mV**（2839-2337）；
- 肥皂冲洗水 ≈ **244 mV**（2581-2337）；
- 300 mV 能挡住 244，不会误伤 500。

第一段 DRAIN 的清水确认现在会失败：

```
# AUTOCAL state=DONE reason=base_turbid
# SLOTS DRAIN=INVALID RECOVER=INVALID FULL=INVALID
```

不会再把肥皂水写进槽。

---

## 3. 现场操作

### 正确流程

```
1. 上电时腔内只能是清水（冲洗干净的清水）
2. 完成三段/两段标定
3. 不重新上电，换成肥皂冲洗水
4. 系统应判 SOAP/L2
```

### 如果上电时已经是肥皂水

会看到：

```
# AUTOCAL state=DONE reason=base_turbid
```

此时：

- 倒掉肥皂水，用清水冲 2~3 次；
- 重新上电，或长按 K2 ≥3 s 重新标定；
- 如果只想先跑起来，长按 K2 ≥3 s 跳过标定，使用默认清水基线；
  之后再遇到肥皂水就会判 SOAP。

---

## 4. 为什么不用“EC 高”直接拒绝

不同水样 EC 本身差异很大，不能用一个绝对 EC 上限判断“脏”。
AO/浊度是更直接的清水证据；这次用 AO 差值把肥皂水挡住。
