# 快速启动卡（现场版）· 洗手水选择性回收装置

> 打印 A5 放箱内；评委/现场同学按此操作。串口 **115200 8N1**。
> 适用固件：`SENSOR-NODE v2.8.0-LEVEL-M2j`（湿膜不能作为基线；RECOVER 槽需人工确认；部分标定禁止自动回收）。

## 0. 上电前（30 秒，M2i 必须做）

- [ ] 腔体**排空**、电极**擦干**（不要带水冷启动；M2i 会把湿膜判成 `dry_blocked_wet`，不会自动建基线）。
- [ ] 阀断电→排空位；12 V / 5 V 接好；USB-TTL 接好。
- [ ] 下桶/回收桶放好；回收桶贴**绿色**标签，排空桶贴**灰色**标签。
- [ ] 确认阀方向：`V1`=回收、`V0`=排空、`VA`=自动；方向反了不要演示。

## 1. 上电与自检（M2i 流程）

1. 上电。OLED 出现 `Auto dry n/40`；串口 `# AUTOCAL state=DRY`。**阀不应吸合。**
2. 约 2 s：`# DRY OK` → `# AUTOCAL state=WAIT WATER`；OLED `Auto wait water`。
   若出现 `# AUTOCAL state=DONE reason=dry_blocked_wet`：电极/腔体没擦干，擦干后发 `D`（或断电重来）。
3. 注清水，**淹过电极**。约 1~3 s 后 `# BASELINE start` → `# BASELINE SLOT DRAIN`。
4. **RECOVER 槽确认（M2i 新增闸门）**：
   - 串口 `# CAL RECOVER: divert/disconnect recovery branch...`；OLED `K2 confirm recover`；
   - **先把回收支路断开或改接到排空桶**，再长按 K2 ≥3 s（或串口发 `Y`）；
   - 确认后阀才切 RECOVER；**60 s** 内不确认 → `# CAL RECOVER skipped`，只保留 DRAIN 槽；
  OLED 显示 `Cal partial`，**自动回收被禁止**（阀恒 DRAIN；仅手动 `V1` 可调试）。
5. FULL 段：保持水流/满水。出现 `# BASELINE SLOT FULL` 或等 15 s 超时。
6. `# GATE regime=MEASURE`；清水稳定约 1.2 s 后 `# STATE to=CLEAR`、`# VALVE pos=RECOVER`。
   M2j 起 trim 关闭，进水过程中 EC 上升应判 L1/排空，不要期待“边进水边回收”。
7. 若出现 `# CAL REJECT ao_low`：boot autocal 对低 AO 保守拒绝；目视确认是清水后
   **长按 K2 启动人工标定**（K2 路径允许低 AO），到 RECOVER 提示时再确认。
   单发 `W` 只采 DRAIN 槽，不能启用自动回收。

## 2. 演示（每段 30~60 s，大腔体慢）

| 段 | 操作 | 期望 |
|---|---|---|
| 1 | 清水流过 30~60 s | `CLEAR/L0`，阀回收（绿桶） |
| 2 | 加皂液/搓手 30~60 s | `SOAP/L2`，阀排空（灰桶）；串口 `dEC` 上升 |
| 3 | 清水冲洗 30~60 s | `dEC` 回落，`CLEAR/L0`，阀回收 |
| 4 | 关水 | **手动排空**腔体（拔立管/开阀/按 `V0`）；`DRY` 后阀排空；SOAP 锁存在失水 2 s 后清除 |

> 演示前先跑一遍，确认阀方向：`V1`=回收、`V0`=排空、`VA`=自动。方向反了不要演示，先查继电器极性/换 high/low hex。

## 3. 常用命令

| 命令 | 作用 |
|---|---|
| `H` | 帮助 |
| `G` | 打印工况（regime/valid/浸没/稳定） |
| `P` | 打印实时值（EC/浊度/温度/Δ） |
| `D` | 手动干态指纹（腔体必须空、电极干，60 s） |
| `W` / `B` | 手动水中基线（电极必须浸没，2 s；**必须已有实测 D**；会清槽并强制排空；W 单槽不启用自动回收） |
| `Y` | 确认 RECOVER 标定槽（只在串口提示时有效；先断开/改接回收支路） |
| `Z` | 清基线（需重新 `W` 或上电） |
| `V1` / `V0` / `VA` | 手动回收 / 排空 / 自动；**V1 10 s 自动过期** |
| `R` / `E` | 事件标记（只影响日志） |

## 4. 故障速查

| 现象 | 先做什么 |
|---|---|
| 一直 `DRY`，注水也不变 | 电极没淹到/水位低；抬高水位；检查电极线；确认已有实测 `D`，再按 `W` |
| `Cal partial` / `dry_blocked_wet` | 电极/腔体没擦干，或 RECOVER/FULL 未完成；擦干/排空后发 `D`，或长按 K2 重新完整标定并确认 RECOVER |
| `CAL REJECT ao_low` | boot autocal 保守拒绝低 AO；目视确认清水后长按 K2 启动人工标定（K2 路径允许低 AO） |
| `CAL RECOVER skipped` | 60 s 没确认；确认回收支路安全后重新长按 K2 标定；只保留 DRAIN 槽时**不会自动回收** |
| 一直 `CLEAR`，但已关水 | 腔体存水、电极仍浸没；**手动排空**；这是大腔体的已知限制 |
| 阀方向反 | 断电；检查继电器 high/low 极性；换对应 hex；不要带反方向演示 |
| 串口无输出 | 检查 USB-TTL/波特率 115200；按 `H`；换线 |
| OLED 花屏/无显示 | 检查 I²C 线；不影响串口演示，先保串口 |

## 5. 一句话口径

> **“没有实测干态/水中基线就不回收；拿不准就排空。”** 这是安全侧，也是本作品的底线。
