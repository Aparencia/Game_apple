## 6. 升级与部署流程

### 6.1 构建（重新出 hex 时）

1. e2studio 打开 `Selective_hand_wash_water_recycling_system`，配置选 **Debug**；
2. 编译选项保持项目既定基线：`-O2 -Wall -Wextra -Wconversion -Wshadow -Wfloat-equal`，要求 **0 error / 0 warning**；
3. 产物：`Debug/*.hex`，复制到 `Docs/firmware/v<版本>.hex` 并 `git add -f`；
4. 参考尺寸基线（M2g，重构前源码）：`text 87160 / data 480 / bss 11532`。

> 当前 `src/` 为重构后源码，首次重新构建时请重点核对：编译零告警、`text` 与基线差异 <1%、烧录后 §6.4 验收全过。

### 6.2 烧录

1. 断开 12 V 阀电源（船型开关 OFF）；
2. 用 Renesas Flash Programmer 或 e2studio Debug 烧写 hex，复位；
3. 确认 P104 上有 10 kΩ 下拉（高触发模块）/ 上拉（低触发模块）——软件不能替代该电阻；
4. 上电后先看启动行，确认版本号：

```text
# fw=SENSOR-NODE v2.8.0-LEVEL-M2g tick=50ms
```

### 6.3 首轮清水标定（M2g）

1. 排空腔体、用清水冲洗 2~3 倍腔体；
2. 上电后自动进入自检：空腔干态 3 s → 等水 → 湿态 2 s；或长按 K2 ≥3 s 手动触发三段标定；
3. 三段顺序 **DRAIN → RECOVER → FULL**：
   - DRAIN / RECOVER 段要求 AO 高于干态 ≥250 mV（清水确认）；
   - FULL 段要求 EC ≥ max(DRAIN, RECOVER) + 10 mV，15 s 等不到满水则保留前两槽；
4. 标定完成打印三条槽实际值；中途长按 K2 可跳过（使用默认 EC0=348 / NTU0=2659）；
5. 出现 `# CAL WARN: accept low-AO baseline (LEVEL+EC confirmed water)` 时，**必须人工确认腔内是清水**——这是 M2g 的降级路径，可能把脏水当本底。

## 10. 已知限制与风险

1. **无流量计**：用水位/浸没 + 稳定判工况；R/E 只是日志分段，不控制阀。液位来自 HC-SR04 超声，受泡沫、水面倾斜、温漂影响，只作门控与"腔内有水"确认，不单独作为判据。
2. **基线只在 RAM**：干态指纹与三槽基线掉电丢失，每次上电需自检/标定；Flash 持久化（`r_flash_lp`）尚未接入。
3. **浊度是相对值**：只输出相对基线的变化百分比，不是 NTU；TDS 参考 ppm 仅作过程量。
4. **本固件不识别污染物、不做达标判定**：SOAP/UNCERT 只是"可回收/不可回收"的分类，不能当水质结论。
5. **M2g 降级路径有风险**：AO 偏低时靠液位+EC 放行标定，若腔内实际是脏水会被当成本底——必须人工确认清水。
6. **OLED 不参与安全侧**：连续 3 帧刷新失败只影响显示。
7. **本次重构未经编译验证**（见 §9.3），在重新出 hex 前视为"源码变更待验证"。
8. **公开仓库**：仓库为 public，含决赛材料与报告，注意保密/知识产权与赛程要求。

## 附录 C：术语与缩写

| 术语 | 含义（本文档口径） |
|---|---|
| EC | 电导率代理量。本工程**不用**标定电导率值，而是用 TDS 通道电压（mV）作相对电导率指标 |
| EC0 / NTU0 | 当前基线（清水本底）的 EC / 浊度电压；三槽各自一条 |
| dEC / dNTU | EC 相对基线的偏移（mV）/ 浊度相对基线的变化（%） |
| g | 比值 `g = EC / EC0`，工况门用 `g ≥ 0.30` 初判有水 |
| σ | 基线期 EC 标准差，表示本底噪声；阈值按 σ 自适应 |
| d1 / d2 | 分级阈值：`d1=max(4σ, 8 mV, 4%×EC0)`（可清上限）、`d2=max(8σ, 20 mV, 9%×EC0)`（含皂下限） |
| L0 / L1 / L2 | 判定等级：L0 可回收、L1 不确定（排空）、L2 含皂或明显脏（排空） |
| state | 判别状态：WAIT / CLEAR / UNCERT / SOAP |
| regime | 工况：FAULT / DRY / SETTLE / MEASURE / LOCKOUT |
| DRAIN / RECOVER / FULL | 阀位与液位对应的三个基线槽（排空位 / 回收位 / 满水流动） |
| AO | 浊度模块模拟输出（TS-300B，经 1k+2k 分压进 ADC） |
| hold | 液位冻结标志：`abs(rate)>5 mm/s` 置位，稳定 1 s 释放；只冻结基线槽的 trim |
| trim | 基线慢跟踪（4 mV/s），仅在 `5 mV ≤ abs(dEC) < d1` 区间生效，防止把肥皂学成清水 |
| wet / dry | 电极浸没（有水）/ 空腔（干态）两种物理状态 |
| CAL WARN | M2g 降级标定告警：AO 偏低但液位+EC 已确认有水，继续标定须人工确认是清水 |
| fail-safe | 失效安全：断电/复位/异常时阀回排空，回收支路关闭，主排水路常通 |
